# 达人收入看板

按 2026-11-23 确认的管理端调整，从达人管理进入达人收入。页面、时间段、卡片、明细和流水抽屉复用经营分析的达人排行实现。

| 要求 | 实现 |
| --- | --- |
| 搜索 | 首行时间段。第二行支持达人名称、达人 ID 或完整邮箱搜索，并可选推广中／失效及店铺。 |
| 四张卡 | 依次展示有销售达人／期间有效达人、订单数／销量、净销售额、预估佣金。第四卡使用所选期间已核实订单的历史费率，按「佣金 − 扣回」展示分项。 |
| 达人明细 | 金额退款率后依次为佣金比例、预估佣金。预估佣金按支付期间汇总已核实订单的商品行净佣金。未成交但在所选期间有已确认预付的达人也进入不限定店铺的明细。 |
| 流水抽屉 | 复用达人排行抽屉，传递已应用的日期、店铺和选中达人。订单及退款证据沿用订单查看权限。 |

佣金按所选店铺统计。

## 资金流水标签页

| 要求 | 实现 |
| --- | --- |
| 表头 | 资金类型、方向、订单号、金额、状态、结算单号。金额使用带符号的 CNY。 |
| 当前余额 | 已核实计佣快照按订单和状态汇总，沿用全钱包先进先出的提现资金分配。已占用资金从可提现余额扣除。 |
| 佣金提现与扣回 | 按实际提现申请和对应订单分摊展示已打款佣金，增加为正。已入账的佣金扣回按原账务记录展示，减少为负。 |
| 预付 | 实际打款按预付申请逐笔展示，状态为「已预付」。预付款归属达人，在全部店铺范围展示。 |
| 日期及权限 | 余额取对应订单支付日期，其余按付款或入账业务时间。查询要求佣金查看权限、公司范围和达人可见范围。 |

三条查询已通过本地 PostgreSQL 只读解析检查。

## 累计时间筛选与达人明细

- 达人收入和经营分析四个看板支持「累计」，按当前筛选范围统计截至当天的历史数据。自定义时间段仍按 90 天上限校验。
- 达人收入的「订单商品」和「成功退款」按订单分页，同一订单的首列合并显示订单号和支付时间。第二列显示商品图、商品名和 SKU，成功退款另列退款完结时间。
- 达人排行明细与导出移除「累计佣金」和「佣金支出」。

## 佣金手册复核（2026-11-23）

| 位置 | 复核与调整 |
| --- | --- |
| 达人收入卡片 | 原扣回仅计钱包释放后的负向调整。改用同批订单商品行的分摊实付、成功退款与支付费率，汇总释放前后的成功退款佣金扣减。 |
| 达人收入、达人排行与导出 | 同名「预估佣金」统一为支付期间净计佣。整单缺商品行快照时待核实。当前配置费率与历史订单快照分别使用。 |
| 达人端我的订单 | 成功退款按实退统计，基数与预估总佣金取商品行快照。售后中保留计提，缺快照时金额待核实。 |
| 管理端佣金和结算明细 | 佣金扣回使用已确认退款前后计佣差额。售后中提示同步为保留佣金、暂停释放。 |
| 订单链路、钱包、提现和预付 | 核对了按行计提、整单释放、申请占用和实际付款。资金流水继续按已记录的资金事件取值。 |
