## 4. 后台启动与接口

按执行报告的方式启动 `backend/target/*.jar`（加载 `deploy/.env` 中的环境变量），然后：

```bash
# 登录
curl -s -X POST http://localhost:<后台端口>/admin-api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"<初始化管理员>","password":"<初始化密码>"}'
# 当前用户（替换令牌请求头名称与值）
curl -s http://localhost:<后台端口>/admin-api/auth/me -H "<令牌头>: <令牌>"
# 健康检查
curl -s http://localhost:<后台端口>/actuator/health
```

- [ ] 首次启动 Flyway 建出 `sys_user`、`sys_oper_log` 两张表，没有其他业务表
- [ ] 超级管理员按环境变量创建；未设置变量时只打印警告
- [ ] 登录成功返回令牌，响应中不含密码哈希
- [ ] 连续 5 次错误密码后被锁定
- [ ] 新建一个 `OPERATOR` 账号，用它访问 `/admin-api/system/user` 被拒绝
- [ ] 响应中的 ID 为字符串，时间为 ISO 8601 带时区
- [ ] `sys_oper_log` 有登录与用户管理操作记录，请求参数中的密码已脱敏
- [ ] `/actuator/health` 返回 UP，且没有暴露其他端点

## 5. 跳转服务运行验证

启动 `redirect/target/*.jar`，然后：

```bash
docker compose -f deploy/docker-compose.dev.yml exec redis \
  redis-cli HSET link:KOL0001 P000001 "1|https://example.com/item?id=1|1"
curl -i http://localhost:<跳转端口>/t/KOL0001/P000001
curl -i http://localhost:<跳转端口>/t/KOL0001/P999999
curl -i http://localhost:<跳转端口>/t/BAD/P000001
curl -i http://localhost:<跳转端口>/healthz
docker compose -f deploy/docker-compose.dev.yml exec redis redis-cli XRANGE stream:click - +
```

- [ ] 有效链接：302，`Location` 正确，含 `Cache-Control: no-store`
- [ ] 未命中：302 到 fallback
- [ ] 非法路径：404
- [ ] 健康检查：200
- [ ] `stream:click` 有一条记录，`ipHash` 不是明文 IP
