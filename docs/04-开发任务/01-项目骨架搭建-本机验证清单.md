
## 4. 后端管理端启动与登录

按执行报告的启动方式启动管理端（例如在 `backend/` 下运行启动模块），然后：

```bash
curl -i -X POST "http://localhost:<端口>/<登录接口路径>" \
  -H "Content-Type: application/json" \
  -d '{"username":"<管理员账号>","password":"<密码>"}'
```

- [ ] 应用启动无报错，日志中无工作流、SnailJob、多租户相关的启动失败
- [ ] 登录返回成功并拿到令牌
- [ ] 启动日志中能看到 `ruoyi-crm` 模块被加载、定时任务已启用

## 5. 跳转服务运行验证

启动 `redirect/target/*.jar`（环境变量按 `.env`），然后：

```bash
docker compose -f deploy/docker-compose.dev.yml exec redis \
  redis-cli HSET link:KOL0001 P000001 "1|https://example.com/item?id=1|1"
curl -i http://localhost:<跳转服务端口>/t/KOL0001/P000001
curl -i http://localhost:<跳转服务端口>/t/KOL0001/P999999
curl -i http://localhost:<跳转服务端口>/t/BAD/P000001
curl -i http://localhost:<跳转服务端口>/healthz
docker compose -f deploy/docker-compose.dev.yml exec redis redis-cli XRANGE stream:click - +
```

- [ ] 有效链接：302，`Location` 为 `https://example.com/item?id=1`，含 `Cache-Control: no-store`
- [ ] 未命中：302 到 fallback 地址
- [ ] 非法路径：404
- [ ] 健康检查：200
- [ ] `stream:click` 中有一条记录，含 `kolItemId`、`ipHash`（不是明文 IP）等字段
