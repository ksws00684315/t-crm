## 2. 实现

**后端**

- `integration`：
  - `crm_google_credential`：服务账号密钥，私钥用 `SecretCipher` 加密；
  - `GoogleAccessTokens`：服务账号 JWT 由 JDK `SHA256withRSA` 签名，换取访问令牌，按公司缓存，到期前 5 分钟刷新；
  - `GoogleSheetsClient`：调用 `spreadsheets.get`，按列请求范围，并用 `fields` 只取所需字段；
  - 接口：`GET/PUT /admin-api/integration/google-credential`（超管）。
- `product`：
  - `crm_sheet_source` 存源表配置与最近一次读取结果，`crm_sheet_source_item` 存每次读取看到的商品；
  - `SheetLinkParser`：链接与价格解析，规则与客户脚本 3.0.5 一致；
  - `SheetSourceService`：负责配置、读取和「已不存在」列表；
  - 接口：`/admin-api/product/sheet-sources/**`。
  - 读取接口 `SourceSheetReader` 定义在 `product.api`，由 `integration` 实现，原因见 ADR-021 §3：避免模块循环依赖。
- `task`：`ImportTaskApi.submitRows`。读到的行写成工作簿后，走与 Excel 上传相同的导入任务，校验、进度和错误文件完全一致。
- 原商品增加 `priceCurrency`。导入处理器增加货币参数：Excel 上传传入空值，新建时为 CNY，更新时不改货币。

**管理端**

- 「商品 → 商品源表」（`/product/sheet-sources`，需要 `product:view`，数据范围为「本人」的账号不显示）：
  - 超管：Google 服务账号卡片（上传 JSON 密钥，显示服务账号邮箱和分享提示），源表的新增、编辑、启停、删除；
  - `product:edit`：「立即读取」（显示读到的行数、导入进度、错误文件、跳过的行）和「已不存在」抽屉。
  - 最近一次读取的错误码按语言包显示为中文说明。
- 原商品列表与编辑表单显示价格货币（`$60.00`、`¥12.50`）。
- 新增 9 个错误码，中英文文案齐全。

## 3. 解析规则相对客户脚本的差异

- **识别淘宝、天猫、1688**：只按域名或代购平台路径里的 `/taobao/`、`/1688/` 判断。客户脚本只要 URL 中出现「1688」字样就判为 1688，会把包含 1688 这几个数字的微店商品 ID（如 `7716882345`）误判，系统不这样做。
- **找不到 `itemID=` 时的回退**：取第一个 10 位数字之前，先排除 `shop{ID}.v.weidian.com` 中的店铺 ID。
- **短链接**：不跟随跳转，因为系统不向表格里的任意地址发请求。这类行作为「无法识别商品 ID」跳过并报告。
- **单元格开头为 `=`、`+`、`-`、`@` 的名称**：内部工作簿和 Excel 导出一样，会加 `'` 防止被当成公式执行，导入后的名称会带上这个 `'`。商品名以这些字符开头的情况很少见，记为遗留。

## 5. 本地运行验证

- **环境**：单独起了一套 PostgreSQL 与 Redis（项目名 `tcrm-07`，验证后已删除），不碰平时的验证库：新迁移的版本号比第三批的 18、20、16b 都大，跑在平时的库上会打乱它们的迁移顺序。Google 用 Python 本地桩模拟，提供样表结构：分类标题行、3 个代购平台包装的微店链接、1 个淘宝链接、「¥145 | $21.13」这样的多币种价格。
- **配置**：用界面新建源表，列字母输入小写「e」也能被接受。
- **第一次读取**：读到 3 行商品并导入成功；分类行计为空行，淘宝行作为「非微店商品」跳过并列出。原商品显示为 `$60.00`、`$93.00`、`$21.13`，店铺取自链接中的 `shop1856156775`。
- **删除一行后再读**：「已不存在」抽屉列出被删的商品，状态仍为「在售」。
- **模拟 403**：「最近读取」列显示「表格没有分享给服务账号……」。
- **布局修正**：在 1366px 宽度下发现「最近读取」列被挤到横向滚动区域，收紧各列宽度后不再出现横向滚动。

## 6. 遗留与上线前事项

- **真实 Google 尚未接通**：本地验证用的是模拟的 Google 接口。上线前需要客户创建服务账号、启用 Sheets API、把源表分享给服务账号，然后用真实源表读取一次，核对链接与价格的解析结果。
- **名称以 `=`、`+`、`-`、`@` 开头**：见第 3 节。
- **源表页没有「下架」按钮**：「已不存在」列表只负责列出，下架到原商品页操作。
- **迁移顺序**：版本号 `V202610172200` 比第三批的 18（`…1900`）、20（`…2000`）、16b（`…2100`）都大。本 PR 要排在它们之后合并；如果要先合并，合并前需要把版本号改小。
