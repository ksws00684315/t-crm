## 做了什么

- `deploy/docker-compose.preview.yml`：与生产相同的五个服务和镜像版本（nginx 1.30.5-alpine、postgres 17.11、redis 7.4.5，后台与跳转服务用现有 Dockerfile）。内存限制小于生产，以便和别的栈一起跑。Redis 仍要密码，`maxmemory-policy` 为 `noeviction`。网段 `172.30.0.0/24`，`TCRM_TRUSTED_PROXIES` 与之相同。
- `deploy/nginx/preview/preview.conf`：仅 HTTP，三个端口，反向代理与登录限流跟生产模板一致。不挂证书，不挂 Cloudflare 回源配置。
- `deploy/scripts/preview.sh`：`up` / `down` / `reset`。`up` 检查 docker、compose、pnpm、node、openssl；`deploy/.env.preview` 不存在才生成（权限 600），已存在不覆盖；用绝对路径调用 `build-static.sh`；`docker compose -p tcrm-preview -f deploy/docker-compose.preview.yml --env-file deploy/.env.preview up -d --build`；最多等 300 秒直到后台和跳转服务健康。平台管理员密码只在刚生成该文件时打印一次。`down` 保留数据卷。`reset` 必须输入 `yes`，然后 `down -v` 并删除 `.env.preview`。
- `.gitignore` 增加 `deploy/www-preview/` 与 `deploy/.env.preview`。
- `deploy/README.md` 增加「本地预览」。

## 偏离与原因

- 本机 Node 是 v22.23.1，不是提示词里的 Node 24。两个前端的 `engines` 接受 `^22.13.0 || >=24.0.0`，构建已通过，因此没有另装 Node 24。
- 本机没有 shellcheck，用 `bash -n` 检查脚本。脚本按 bash 3.2 编写。
- 预览内存限制小于生产（nginx 128m、crm-admin 1536m、crm-redirect 384m、postgres 768m 且 `shared_buffers=128MB`、redis 320m 且 `maxmemory 192mb`）。Docker Desktop 内存约 8GB，生产限制加在一起放不下，任务 3.4 允许缩小。Redis 密码和 `noeviction` 保留。
- 增加了 `TCRM_REDIRECT_FALLBACK_URL=https://fallback.preview.invalid`。提示词第 3.2 节没有列出它，但跳转服务没有带主机名的 http(s) 回退地址会拒绝启动。没有改跳转服务代码。
- 达人注册验证码默认不进日志。验证时用未提交的 Compose 覆盖临时设置 `CRM_MAIL_LOG_LINKS=true`，完成后已去掉。提交的预览配置保持关闭，与「生产禁止打开该开关」一致。
- 第一次 `up` 因 Maven 依赖下载中断失败，`reset` 后重试成功。不是预览配置的错误。
- 未改 `.github/workflows/deploy.yml`。任务没有要求把预览放进 CI，且 Actions 已暂停。
- 单独对预览 Nginx 配置执行 `nginx -t` 会报上游 `crm-redirect` 找不到主机。容器内有 Docker DNS，栈启动后 Nginx 正常。没有改成变量式 `proxy_pass`。
