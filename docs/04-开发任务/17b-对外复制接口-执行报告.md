## 接口

| 方法 | 路径 | 认证 |
|---|---|---|
| GET | `/admin-api/external/product-links/templates` | 无 |
| POST | `/admin-api/external/product-links/convert` | body `token` |
| POST | `/admin-api/external/product-links/jobs/{jobCode}/items/resolve` | body `token`（须属任务达人） |
| GET | `/admin-api/external/product-links/jobs/{jobCode}` | 任务编号 |
| GET | `/admin-api/external/product-links/jobs/{jobCode}/items` | 任务编号 |
| PUT/DELETE | `/admin-api/product/shops/{id}/copy-target` | `SUPER_ADMIN` |

`msg` 对上述外部接口使用中文（设计 §6.5 例外）。错误码含 `COPY_TARGET_SHOP_MISSING`、`PRODUCT_LINK_RATE_LIMITED`。

## 复制流程

1. `convert`：认证令牌 → 解析目标店铺（令牌指定 / 默认复制店铺）→ 校验启用且已授权 → 去重写入任务与明细 → 立即返回 `jobCode` → 提交有界线程池。
2. 工人（公司作用域、任务内顺序）：查原商品（库中或对各启用店铺 `item.get` 探测并登记）→ 已有对应关系则直接成功不扣额度 → 否则 `consume` → 微店 get/detail/add/saveItemDetail（原价）→ 写 `crm_kol_item` + 链接索引事件。
3. 重启：`CopyJobWorker` 作为 `ApplicationRunner` **继续处理**仍为 `processing` 且明细 `pending` 的任务。
