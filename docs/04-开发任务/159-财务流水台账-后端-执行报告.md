# 任务 159 执行报告：财务流水台账（后端）

## 结论

按《财务流转口径规则》（任务 158）实现财务流水台账：新增 `crm_finance_flow` 只追加分录表（科目、带符号金额、业务时间、幂等来源键），在订单同步事件、计佣修订、佣金释放、提现付款四个触发点按六段口径记账；订单链「财务流水」板块改为科目化台账行（`subject` 字段），派生流水（SR/SRF/CA/CR/WS/CL/WA）不再返回。佣金余额与状态仍以钱包与计佣快照为唯一事实源，台账只作记录与呈现。

## 接口与表结构变更

- 新表 `crm_finance_flow`（见上）。
- `GET /admin-api/order/orders/{id}/chain`：`financeFlows[]` 元素增加 `subject`，`flowNo` 改 `FF{台账ID}`，`orderItemId` 可空（收入侧订单级），`type` 为 `SHOP_RECEIVABLE`/`KOL_COMMISSION` 分类，`orderStatus`/`commissionStatus`/`settlementAt`/`settlementNo` 恒为 null（保留字段）；在途提现分配不再出现在流水（付款才入账），行级 `withdrawals[]` 不变。权限规则不变（任务 72 契约）。
- `order.api.OrderItemsCommissionEvent` 增加订单事实载荷（模块内事件契约）。
