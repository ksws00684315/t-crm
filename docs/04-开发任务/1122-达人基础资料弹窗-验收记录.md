# 达人基础资料弹窗验收记录

| 需求 | 验收结果 |
| --- | --- |
| 桌面查看布局 | 左上展示达人名和编号，左下展示邀请人及其 Discord、WhatsApp 账号。右侧合并邮箱、WhatsApp、手机号与核心社媒字段。所有资料在同一弹窗可见，缺失值以「—」显示。 |
| 查看与编辑 | 使用项目现有文案、边框、间距和控件。邮箱保持只读并支持复制，普通编辑与审核使用单列字段，底部操作按各自流程显示。 |
| 窄屏适配 | 查看态和编辑态均单列展示。弹窗标题和底部操作保持可见，中间内容可独立滚动。 |

在 Edge 以示例达人验证了桌面分组、邮箱复制、必填校验、编辑请求和 390 × 650 像素下的滚动。31 项相关测试、类型检查、静态检查和预览构建通过。
