## 发现的问题

无阻断性问题。以下为观察项（不影响验收结论，供参考）：

1. **观察项 A（非缺陷，Element Plus 标准行为）**：1280x800、en-US 下订单表格列最小宽度合计 1058px，超过表格容器 998px，表格内部出现约 60px 横向滚动（页面级无横向滚动，zh-CN 1280x800 下表格恰好铺满无内部滚动）。原因是英文列头（Order Status / Paid amount 等）与列 min-width 共同作用。验收标准（无横向页面滚动）满足。
2. **工具层面说明**：el-table 在视口尺寸变化后异步重排有数秒延迟，本次截图均在表格宽度与容器宽度一致（布局稳定）后拍摄，不影响产品结论。
