## 1. 结论

按负责人 2026-10-25 的两条决定完成：

1. **每位达人统一一个佣金比例，不设单商品覆盖**——`CommissionItemSnapshotService` 不再读取商品级比例，比例只取支付时刻生效的推广配置（`crm_kol_promotion_record` CONFIG 的 `defaultRate` 与 `version_no`）；`ProductAccessApi.listRates` 与 `ProductRateDTO` 已删除（无其他调用方）。来源版本指纹保持 v1、字段不变，存量行不会产生无意义修订。
2. **店铺获利 = 微店结算净额 − 净达人佣金**——`CommissionSettlementDetailService` 的 `retained` 改为恒 `null`（待核实），留出取数位置并注明待 M0 核实（Q-1017-1/2）后接入；`POSTED`/`UNVERIFIED` 判定不变。

ADR-032 与设计说明书同步修订。后端 CI 四步全部通过（单测 2003、集成 260，0 失败，覆盖率达标）。无前端改动、无新增迁移。
