## 店铺表现卡片与排行补充要求

店铺表现以所选期间的成交店铺数／总店铺数开头，统计期内已建档的店铺纳入总数，含停用店铺。支付订单数小字显示销量及成交 SPU，净销售额小字显示销售额及同批成功退款。结算金额按微店流水入账时间统计应收增加减应收减少，流水按人民币元，排除手续费和利润。排行分别显示 SPU／SKU、达人数，增加可排序的金额退款率。卡片、对账区、排行和店铺抽屉中的销售、订单、财务指标支持鼠标悬停和键盘聚焦查看口径。

## 畅销商品、邀请人业绩与达人排行补充要求

畅销商品和邀请人业绩在共用筛选区增加等宽的商品名／SPU ID 搜索。商品名包含匹配，SPU ID 精确匹配。筛选传到卡片、排行、详情及导出。邀请人业绩参考确认图改为有效邀请人／总邀请人、订单数／销量、净销售额、预估总佣金四卡，每张卡保留一行指标小字。预估总佣金按已核实的订单佣金，未结算取预估、已结算取实际，已提现仍保留原订单归属，按当前权限显示。邀请转化改为三个阶段和两段比例，历史累计和当前关系状态标明时间口径。排行保留既有表头和详情入口，增加最佳达人及净销售额，按当前筛选范围内的支付归属计算。畅销商品、邀请人业绩和达人排行的销售、订单、财务口径说明由文字悬停或键盘聚焦触发，移除说明图标。

## 时间筛选即时应用

四个经营分析页共用的时间筛选在切换预设、确认单日及月份、选完整自定义区间或前后翻期后自动更新结果。时间筛选使用已生效的其他条件。抽屉随正在查看的排行行更新，详情各标签使用新的生效日期。

## 店铺排行详情抽屉

按三张参考图更新店铺资料卡、概览、订单商品、成功退款和结算流水。顶部显示店铺编号、微店 ID、状态、更新时间，并可按本期跳转同店铺畅销商品。概览用「客单价」，在「成交商品」卡内同一行展示成交 SPU 数和成交 SKU 数。订单商品、成功退款标签显示按对应事件日期去重的订单数，明细仍按订单商品行或退款记录分页，商品位置显示图片和规格。结算流水按微店入账时间明细化显示店铺应收增加和减少，沿用公司、店铺及订单查看权限。仅在能明确关联到商品行时展示商品，整单多商品保留整笔流水。

店铺详情的明细标签固定店铺卡、标签栏和表头，明细行在抽屉内独立滚动。

店铺详情概览把金额退款率移到净销售额之后。订单商品和成功退款去掉店铺与渠道，保留 SPU 列，说明源链接商品 ID 与订单商品 ID 的回退规则。

店铺详情顶部编号只展示 CRM 店铺编号。
