## 4. 实现要点

- 组件对外只有 `modelValue: string`，值为规范 E.164（`+491716422826`）或空串；父级表单写法不变，管理端 `validateWhatsapp` 与注册页内联校验都接收规范值
- 组件内部维护选中国家（ISO 代码）和本地号码（纯数字）；号码变化时重新拼装并 emit
- 区号分段用 `el-input` 的 prepend 插槽承载一个无自带边框的 `el-select`：触发器经 `#label` 插槽只渲染 `+区号`，下拉选项仍用国家名称，搜索走 `filterCountries` 按名称或区号过滤；分段内只在获得焦点时显示焦点环
- 默认国家取浏览器语言里的地区子标签，取不到时留空；编辑已有值时按最长区号前缀解析，`+1` 归美国、`+7` 归俄罗斯这类共用区号按数据文件里的优先表取
- 提交前去掉空格、横线、括号；总位数按 8～15 校验，与后端一致
- 遵守规范 13：组合组件只做组合，不覆盖 `.el-select__popper`、`.el-select-dropdown*` 的颜色、圆角、内边距、字号或高度；控件高度、字号沿用现有令牌；标签在上、错误在下由 `el-form-item` 承担
- 国家名放在数据文件（负责人 2026-11-27 确认），不铺到语言包
