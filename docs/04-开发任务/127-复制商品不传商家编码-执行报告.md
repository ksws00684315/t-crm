# 127 复制商品不传商家编码：执行报告

- 分支：`task/127-copy-item-drop-merchant-code`
- 日期：2026-11-07
- 类型：缺陷修复（后端，无迁移）

## 1. 背景

正式环境 2026-11-07 16:37（北京时间）表格脚本提交的复制任务 `A1Fc8TGWt4QEgw0tY4PRTw`
3 条全部失败：

| 来源商品 ID | 失败点 | 记录原因 |
|---|---|---|
| 7895568922 | `vdian.item.add` 返回非 0 | Weidian API error 200056 |
| 7892473233 | `vdian.item.add` 返回非 0 | Weidian API error 200056 |
| 7849640325 | `vdian.item.get` 后缺名称/价格 | 来源商品信息不完整 |

`vdian.item.get`、`vdian.item.getItemDetail` 都成功，只有新增被拒。排查发现复制时把源商品的
商家自定义编码（`merchant_code` / `merchantCode`）原样带进了 `vdian.item.add`，商品级和 SKU
级各一处。微店对同一店铺内的 merchantCode 不允许重复，接口会直接拦截；本次是同一家店复制到
自己（源店 = 目标店 = XD），源商品编码在店里已存在，必然冲突。

10-24 的 M0 单店实测之所以通过，是那个测试商品没有商家编码。

负责人 2026-11-07 决定：**复制时一律不传 merchantCode**。

## 2. 改动

| 文件 | 改动 |
|---|---|
| `backend/.../integration/service/WeidianItemCopyService.java` | `buildAdd()` 不再读取源商品的 `merchant_code` / `merchantCode`，商品级 `merchantCode` 传 `null`；`skus()` 中 SKU 级 `merchantCode` 同样传 `null`，两处都写明了原因 |
| `backend/.../integration/service/WeidianItemCopyServiceTest.java` | 新增 `shouldNotSendMerchantCode_whenCopyingItem`：源商品带商品级 `SRC-001` 与 SKU 级 `SKU-001`，断言 `AddItemRequest` 两处都为 `null` |

其它字段（名称、价格、库存、划线价、类目、图片、SKU 价格与库存）仍按原逻辑透传，没有改动。
`AddItemRequest` 的字段定义保留（微店接口本身支持该字段，只是复制链路不发送）。

## 3. 影响范围

| 对象 | 影响 |
|---|---|
| 复制新增商品 | 新增商品不再带商家自定义编码；同店复制、把同一源商品复制到多个店都不会再因编码冲突被拒 |
| 目标店铺商品 | 复制出来的商品 `merchantCode` 为空，客户若用该编码对接 ERP/发货需另行约定 |
| 源商品 | 不受影响，只读；未修改店内任何已有商品 |
| 对外接口（`/external/product-links/*`） | 请求/响应结构不变，表格脚本无需改动 |
| 已有复制任务与达人商品对应关系 | 不受影响 |

## 6. 偏离与遗留

- **200056 尚未拿到微店 `status_reason` 证实**：当前结论基于“同店复制 + 编码重复”的调用链
  证据与负责人对微店接口规则的确认。发布后请客户用新令牌重试一次，复制成功即可确认。
- **错误信息仍不可诊断**：非 0 状态码只保留数字（`Weidian API error 200056`），微店返回的
  `status_reason` 被丢弃。建议另开任务把它带进失败原因与日志。
- **探测误判**：7849640325 的「来源商品信息不完整」来自 `probe()` 只判断 `itemid` 是否存在；
  对不存在的商品可能误报。与本次编码问题无关，未在本任务处理。
- **额度**：本次失败任务已按规则扣 2 次复制额度，不退还。
- **更正（2026-11-07，任务 130）**：任务 134（原登记为 128）上线后日志里有了 `status_reason`，200056 的真实原因是
  「SKU标题不能为空」：复制时没有带源商品的规格（`attrList` / `attrIds`），与商家编码无关。修复见
  [130 执行报告](130-复制商品带上规格-执行报告.md)。不传商家编码的改动保留。
