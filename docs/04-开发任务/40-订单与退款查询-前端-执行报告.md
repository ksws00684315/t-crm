## 主要改动

### 1. 订单查询（`views/order/index.vue` 改造）

- 筛选区首行新增：订单号（精确）、渠道（下拉，现仅微店）、店铺（下拉，保留）；「展开」保留支付时间范围、达人编号、订单状态、归因状态。查询、重置由 `ListSearch`，刷新由 `DataTable` 工具栏承担。
- 列表列按 09.04 原文重排：订单号（`CopyText`）、渠道、店铺「名称（编码）」、达人「名称（编号）」（未归属显示「-」）、订单状态、订单状态旁独立退款状态列（无退款 / 退款中 / 部分退款成功 / 全额退款成功，标签着色）、支付金额、运费、支付时间、创建时间、操作。
- 操作列用 `RowActions` 直显「查看」「链路」：查看打开订单详情抽屉；链路在新标签页打开 `/order/orders/{id}/chain`，未归属达人的订单禁用并给出提示（09.04）。
- 行展开的商品行明细（`OrderLines`）与达人链接（打开达人详情抽屉）、同步状态 / 手动同步 / 导入订单 / 导入退款入口全部保留。
- 订单详情抽屉（`OrderDetailDrawer.vue`，新）：商户号、商品金额、运费、订单总额、支付金额、下单时间、支付时间、来源（接口同步 / 导入）、最后同步时间；商品行表格：图片（可预览）、名称、商品 ID、SKU、达人、数量、单价、实付、退款金额、状态。

### 2. 退款查询（`views/order/refund/`，新页面）

- 替换「订单管理—退款查询」占位路由（`/order/refunds`），页面 `OrderRefundPage`。
- 筛选：退款单号、订单号、渠道（首行）；退款状态、退款类型在「展开」中。查询、重置、刷新、分页齐备。
- 列表列：退款单号（`CopyText`）、原订单号（`CopyText`，点击打开订单详情抽屉）、渠道、店铺「名称（编码）」、达人、退款类型、退款状态两列分列（08.02）；「退款中」显示为进行中的警告色，绝不显示为成功退款。退款金额右对齐、申请时间、成功时间。
- 退款详情抽屉（`RefundDetailDrawer.vue`）：基础信息 + 商户号；退款商品表格：图片、名称、商品 ID、SKU、达人、数量、退款金额。

### 3. 订单链路（`views/order/chain/index.vue`，新路由页）

- 路由 `/order/orders/:id/chain`，标题「订单链路」，`hideInMenu`，从订单列表「链路」`window.open` 新标签页进入。
- 顶部订单头（订单号可复制、渠道、店铺、达人），按商品行分块：商品创建任务（任务编号，跳转 `/product/tasks?jobNo=…` 带筛选；无则「-」）→ 达人商品链接（链接编码、来源商品 ID、目标商品 ID、达人）→ 订单商品行（数量、实付）→ 退款（单号、类型、状态、金额、成功时间；无退款显示「无退款」）。
- 「账务流水」「提现占用」两块显示「开发中」（`common.developing`），不造假数据（佣金结算不在本任务范围）。

### 4. 同步监控与导入（`SyncStatesDialog.vue` 扩展、`ImportDialog.vue` 扩展）

- 同步状态弹窗改双页签。「同步状态」页签：每个店铺分「订单」「退款」两行，列为店铺（含启用/授权标签）、类型、来源（接口 / 导入）、最后成功同步时间、最近错误、24 小时失败次数、缺字段记录数、最近一次导入的数据截止时间；「立即同步」保留在订单行（`POST /order/syncs` 沿用现有接口与权限）。后端未返回分类型行时（合并前）回退为单订单行。
- 「失败任务」页签（新）：店铺、类型、时间、错误、关联导入任务（跳转 `/system/tasks?taskId=…`）。
- 订单导入、退款导入弹窗新增必填「数据截止时间」：`ImportDialog` 增加 `requireDataCutoff` 开关（仅订单/退款导入启用），日期时间选择默认当前时间，未来日期不可选（日级禁用 + 提交校验时分），随上传表单以 ISO-8601 提交 `dataCutoffTime`；其余导入（达人、商品等）流程不变。

### 5. 人工匹配池证据（`unmatched.vue` + `MatchEvidenceDrawer.vue` 新）

- 匹配池每行新增「查看依据」操作（行操作改用 `RowActions` 直显：查看依据、指定达人、标为非达人订单、重新匹配）。
- 抽屉内选择订单商品行后展示：微店商品 ID、所在店铺、支付时间、未匹配原因（未匹配 / 缺规则 / 证据冲突）；同一商品 ID 的达人商品对应关系表（达人、链接编码、生效起止、是否覆盖支付时间——覆盖的高亮描边并加「覆盖」标签）；原商品（名称 + ID）；已有人工处理记录表。
- 抽屉底部「指定达人」直接进入现有指定达人弹窗。

### 6. 其他

- 路由：`refunds` 从占位改为真实页面；新增 `orders/:id/chain`。`component-names`、`guard` 路由表测试同步更新。
- 语言包：订单模块新增渠道、退款状态/类型、来源、详情、链路、同步监控、匹配证据等键，中英文同步（`messages.spec` 校验键一致）。
- API 层（`api/order/order.ts`、`api/types.ts`）：按后端提示词第 3、4 节契约新增 `getOrder`、`getOrderChain`、`listRefunds`、`getRefund`、`listSyncFailures`、`getMatchEvidence`，扩展订单列表筛选与 `OrderVO` 新字段（`channel`、`shopCode`、`refundStatus`、`freight`、`createTime`，合并前可缺省）；上传导入增加 `dataCutoffTime` 参数。
