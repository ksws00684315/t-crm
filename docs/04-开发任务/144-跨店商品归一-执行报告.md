# 任务 144 · 跨店商品归一

业务依据为项目共享文件 `4、开发文件/跨店商品销售统计规则.md` 和 `outputs/经营分析-商品归一修改提示词.md`。本轮使用测试数据核对。正式历史成交的映射覆盖率需用正式数据另行验证。

| 看板位置 | 变更和复核 |
| --- | --- |
| 畅销商品主榜和卡片 | 按唯一来源商品跨店聚合，以分销销售额确定名次。订单、达人和成交商品按各自范围去重。测试覆盖净销售额低于第二名时仍按销售额排名。 |
| 商品搜索和详情 | 原商品ID取源店微店原链接商品 ID。按原商品键访问详情，保留已选成交店铺和数据权限。原链接直接成交及达人归属待确认成交各有独立明细，实际成交链接另列。浏览器样例已核对表头、搜索提示、店铺贡献和两个订单明细页签。 |
| 店铺与达人看板 | 分别在单店和全筛选范围按来源商品去重。达人实际成交链接仍独立计数。SKU 缺少可核实的原规格映射时按店铺、链接和规格区分。 |
| 邀请人看板 | 按原商品ID匹配商品行，再汇总邀请人支付期表现和下钻明细。 |
| 退款、结算和导出 | 成功退款通过原成交行归集，净销售额沿用 30 个自然日窗口。整单结算流水只有能确认唯一来源商品时展示原商品ID，商品结算金额和退款件数继续按可靠数据可用性展示。导出使用相同的筛选、排名和原商品ID。 |

多级复制沿用现有复制流程记录的根原商品 ID。无法唯一解析来源的成交保留实际店铺及链接，原商品ID留空。前端的浏览器验证使用接口样例，数据库口径由 `OrderStatsIT` 的独立 PostgreSQL 测试数据验证。

定向后端单测 20 项、PostgreSQL 集成测试及前端看板测试 3 项通过。前端 ESLint、类型检查和生产构建通过。数据库样例中原商品 7890 跨店分销合计 900 元，筛选分店后为 400 元，原链接直接成交 100 元在专页展示。核对了实际成交链接、退款和店铺贡献。200,000 商品行的本地集成样例中，总览查询约 0.36 秒，达人分组约 3.82 秒。
