# 任务60 资金概览 V3 补充执行提示词

2026-10-26，负责人在本会话明确要求先改图、再改前端，取代前版顶部已到账总收入展示定义。

## 负责人原文

“资金明细显示：总收入（总收入包括预估总佣金和预付金额），右边放 累计提现金额、当前可提现金额和冻结中的金额，预付仅计入已收到款项记录在累计提现金额中；佣金概览下面加小字说明 预估总总结=已提现+当前可提现+冻结中+提现中；资金说明部分不需要单独出现了。”

## 已授权实现口径

- 总收入 = 后端 `income.estimated` + `income.prepayPaid`。预付只取已收到款项，不含申请中、未收到或未付款的预付。
- 右侧累计提现金额 = `income.cumulativePaid`，后端定义为 `commissionPaid + prepayPaid`；当前可提现 = `income.available`；冻结中 = `income.frozen`。
- 佣金概览的已提现仍只取 `income.commissionPaid`，不把预付重复计入佣金。
- “预估总总结”结合上下文按“预估总佣金”呈现。标题下小字为“预估总佣金 = 已提现 + 当前可提现 + 冻结中 + 提现中”。后端各金额原样呈现，不通过公式反算。存在抵扣时保留负数抵扣小字，不伪造对平金额。
- 删除独立资金说明区；原先抵扣金额放在佣金卡片下的小字中。
- 沿用五入口、现有资金历史/提现流程、共享令牌和中英文。
- 图先生成并展示，再实现；[V3 效果图](assets/task-60/funds-summary-visual-v3.png)。
