# 管理端体验 P0：列表导出 / 批量操作 / 锁屏 —— 执行报告

依据：`tcrm-admin-ux-research-2026-10-12`（管理后台 UX 调研报告，§6 P0-1～P0-3，附 designeer.xyz 附录）。分支 `feat/admin-ux-p0`，只改 admin-ui，**无后端、无迁移、无新依赖**。

## 1. 列表导出（P0-1）

- 页面：达人、商品、对应关系、用户。DataTable 工具栏新增「导出」按钮（`exportable`），描边按钮 + 下载图标（参考 Tremor 的幽灵筛选 + Export）。
- 实现：前端复用现有列表接口按 `size=100`（后端 `@Max(100)`）逐页拉取，生成 CSV（UTF-8 BOM，Excel 可直接打开中文）。不新增后端接口，因此鉴权、租户隔离与数据范围（OWN/ALL）和屏幕上一致。
- 查询条件取**已应用的查询快照**（`applied`），不是表单里未提交的输入。
- 上限 5000 行（50 次请求）；超出时只导出前 5000 行并提示缩小筛选。更大量需服务端异步导出（未做）。
- 安全：以 `= + - @ Tab CR` 开头的单元格前加 `'`，防 CSV 公式注入。
- 列为业务列（不含操作列），值与表格显示一致（状态、时间、费率均已格式化）；不随列设置隐藏而变化。
- 对应关系页仍需精确条件才能查询，导出同样只在有结果时可用。

## 2. 批量操作（P0-2）

- 达人：批量启用/停用（需 `canWrite`）；商品：批量上架/下架（需 `canWriteProduct`）；用户：批量启用/停用（当前登录账号不可选，与行内按钮禁用一致）。
- 只选**当前页**：选中后工具栏变为「已选 N 项 · 仅限当前页」+ 动作 + 取消选择；翻页、改条件、刷新都会清空选择。**没有跨页全选**。
- 执行：二次确认后**逐行串行**调用已有单行接口（`runBatch`），每行仍走后端权限校验和操作日志；已是目标状态的行自动跳过。部分失败时提示成功/失败数并列出前 3 个失败原因，结束后刷新列表。
- 未做：批量更换商务（需选择目标商务，交互更复杂）、批量删除（系统无删除）。

## 3. 锁屏（P0-3）

- 入口：顶栏锁形按钮、用户菜单「锁定屏幕」；用户菜单「空闲自动锁屏」可选 关闭 / 5 / 15 / 30 / 60 分钟，**默认关闭**（本机 localStorage 保存）。
- 锁定后全屏遮罩（毛玻璃，z-index 高于 Element 弹窗），页面、标签和未保存输入保持挂载；锁定状态写入 localStorage，刷新页面仍是锁定；多标签页通过 storage 事件同步。
- 解锁 = 用同一账号重新登录（密码 + 图形验证码，遵循 ADR-017），失败计入账号锁定次数；验证码错保留密码；账号被锁（`AUTH_ACCOUNT_LOCKED`）时提示并退出到登录页。也可直接「退出登录」。
- 解锁成功会顺带关闭可能挂着的重新登录弹窗（登录已续期会话）。退出登录 / 会话清除时同时解除锁定。

## 5. 未验证 / 待定

1. 浏览器未实测：导出文件在 Excel/WPS 中的显示、批量条在深色模式和窄屏下的样式、锁屏遮罩深色效果。
2. 解锁通过登录接口签发**新 token**，旧 token 仍有效到自然过期（与 ReauthDialog 一致，Sa-Token 允许并发登录）。如需严格单会话，可加后端 `/auth/unlock` 或解锁后注销旧 token。
3. 锁屏是前端遮罩：有本机浏览器权限的人仍可在开发者工具里拿到 token，它防的是"离开工位被人看/点"，不是替代会话超时。
4. 导出 5000 行上限、自动锁屏默认关闭、批量串行无并发——均为默认取舍，待负责人确认。
5. 导出未写入操作日志（读操作，现有列表查询也不记录）；如需审计导出行为需后端接口。
