- `backend/.../security/api/PostTemplate.java`：`OPERATOR` 去掉 `KOL_EDIT`，删除过时注释。`BD` 模板不变。

- `WithdrawalService.requireKolScope`、`PrepayService.requireKolScope`：OWN 越范围由 `COMMON_NOT_FOUND` 改为 `AUTH_FORBIDDEN`。

## 偏离与遗留

1. **L-004 不需要迁移（审查结论）**。`sys_post_template` 只在超管保存模板时写入行，没有种子数据，行里也没有「是否默认」标记，带 `kol:edit` 的行无法区分是定制还是原样保存，所以首轮没有写迁移并提请决定。架构审查确认共享库 `sys_post_template` 为 0 行，没有可改的数据。代码层面新建账号的默认已不含 `kol:edit`，已有账号的授权不变。
2. **同类 OWN 越权写法已在返工中处理**。首轮未改的 `CopyTokenService`、`CopyJobQueryService`、`KolItemService#detail` 已统一为 403，依据是负责人 2026-10-29 的决定和架构审查的必须改项。设计说明书同步。
3. **超出清单的扩展已被审查接受**：`CommissionIncomeService.requireVisibleKol`、`PayoutAccountService.requireAdminAccount` 改为 403，符合负责人决定。
4. **预付打款不校验达人范围，已被审查接受，不改**：`PrepayService.pay` 只校验 `prepay:pay`，持该权限按财务权限处理，与详情一致。因此不存在 OWN 越范围返回 403 的路径，也没有对应测试。
5. 遗留清单 L-004、L-020、L-022、L-027、L-039 的状态由架构负责人合并时更新，本次未改。`docs/04-开发任务/README.md` 未改。
