## 2. 达人列表（按 1018 表第 7～15 行 + 提示词 §2.2）

- **页签**：超管见「达人列表」「达人管理」两个页签；商务只有「达人列表」；无「邀请链接」「清理记录」页签。
- **查询区（03.02）**：达人ID、达人名称、邮箱三个条件 + 查询/重置（ListSearch）+ 刷新/分页（DataTable）。后端为单一 `keyword`（OR 模糊），一次只能用一个条件，多填时提示「一次只能填写一个查询条件」（见遗留 §6.1）。
- **列（04.01 顺序，13 列）**：达人ID、达人名称（纯文本不可点击）、Phone/WhatsApp（有手机号显示手机号，否则 WhatsApp，否则「-」）、邮箱、核心社媒平台及社媒ID、佣金比例、预付金额（「开发中」）、邀请时间、邀请人、审核状态、登录状态、关系状态、操作（固定右侧）。不显示国家/地区、自动清理等列。
- **行操作（固定 6 个）**：资料编辑、审核（仅待审核可用）、佣金信息（仅已通过可用；「待推广」标签也可点开）、预付金额（一律置灰，悬停「开发中」）、清理配置、冻结/解冻。
- **资料编辑 / 审核共用弹窗**：可编辑达人名称、WhatsApp、手机号（含国际区号占位与校验）、核心社媒平台、核心社媒ID；邮箱与达人ID只读。审核走 `POST /review`，保存后状态更新为已通过、不可再审。
- **佣金信息弹窗**：必填佣金比例、达人邀请码、代购平台（多选可搜索）、每平台地址（逐行增删）、备注（必填）、达人推广表格地址；无「跳转平台」；只有「保存」，保存成功提示关系状态更新为推广中（33 §3.9 后端置 PROMOTING）；页签「修改记录」列版本号、生效时间、修改人、改动内容。
- **清理配置弹窗（按达人）**：自动清理「关闭 / N 天（1～365）」→ `PUT /kol/kols/{id}/auto-cleanup`；「立即清理」二次确认、原因必填，确认文案写明会删除微店关联商品链接无法恢复。
- **邀请达人弹窗**：商务专属邀请码（8 位）+ 复制、注册链接 + 复制、二维码「开发中」占位、「重新生成」（二次确认）；超管打开时提示注册达人不绑定商务。显示条件：超管或满足任务 28 商务条件（33 §3.1 后端放行超管）。
- **「达人管理」页签（仅超管）**：选择范围（某商务名下全部 / 指定达人按 ID/名称/邮箱搜索多选）、目标商务（在职或未分配）、生效（立即/预约）、原因；提交 `POST /kol/bd-transfers`；页签下方注明转移记录到操作日志查询。
- **商务数据范围**：列表由后端只返回名下达人 + 精确搜索到的未绑定达人；未绑定行只有资料编辑与审核可用，其余置灰（33 §3.8）。
- **达人商品页**（原对应关系）：新增「上传推广表」（先选达人再上传）、「佣金信息」（点击拉取达人后打开弹窗，满足 04.03「达人列表及达人商品详情可查看当前佣金比例并关联配置记录」）、「链接」（打开链接抽屉）。

### 8.5 联调中的后端观察项（已在 PR #83 评论，未改后端）

1. **跳过的转移仍写审计行**：`toBdUserId` 等于当前归属时转移被跳过（不生成转移记录、归属不变），但仍写一条 `Create BD transfer` 审计，摘要失真（达人编号缺失、from 显示「未分配」、to 与实际动作不符）。建议后端跳过时不记审计，或摘要写明「无变化，跳过」。复现：对同一达人连续两次转移到同一目标。
