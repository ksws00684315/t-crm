## 主要改动

- 两端统一系统字体栈和 CSS 字体、行高、间距及控件高度 token；全局覆盖 Element Plus 与 body 挂载浮层。加入双端 token 一致性测试。
- 清除表格 `mono` 字段及所有调用，编号、邮箱和日期回归正文字体；保留金额对齐与 tabular 数字。
- 管理端表格将默认/紧凑/宽松映射为 12/8/16px 单元格纵向间距，控件字号固定为 14/22px；搜索筛选按统一间距换行。
- 达人列表保留 13 列及六个操作，列宽合计超过 2,000px；通过内部横向滚动保持字号和表头可读，并移除原 11px 邀请时间与 12px 操作文字。
- 统一认证页、导航、页面标题、卡片留白、手机控件高度和响应式横向溢出约束。
