## 修改与逐项复核

| 复审要求 | 实现及核验 |
|---|---|
| 两个页签使用公共列表卡片、表头和分页 | 付款记录与预付流水均使用 `DataTable`；分别以 `id`、`entryId` 为行键，使用独立 `tableId` 保存列设置及分页条数。同一预付单的多条流水可以同时显示。 |
| 页签放入卡片工具栏 | 保留 `el-radio-group`，通过可选 `toolbar` 插槽放入公共工具栏；两端 `DataTable` 同步修改并增加同样的插槽测试。未传插槽的页面继续显示总条数，刷新、列设置、密度、全屏和内置分页保留。 |
| 编号与行操作使用公共组件 | 两个表格、付款详情及小屏卡片的业务单号均用 `CopyText`；付款记录的查看、凭证下载使用 `RowActions`，保留下载中的禁用状态。接口关联 ID 保持字符串，不作为列表内容展示。 |
| 金额右对齐 | 实付、钱包余额、已冲抵、待抵扣和流水金额列使用 `amount: true`，保留 CNY 和金额字符串，不作浮点计算；缺失抵扣余额继续显示占位，不描述为“钱包不变”。 |
| 时间按统一格式 | 达人端新增 `utils/format.ts` 的 `formatInstant`，与管理端保持相同的当前语言、浏览器时区和秒精度规则，供两个页签及付款详情使用。 |
| 刷新、分页、空态及错误反馈 | 使用表格内置刷新和分页，变更条数只请求一次第一页；切换页签回到第一页并恢复该页签条数。保留刷新失败清除旧数据、错误提示及成功恢复。无新增查询条件，不增加空的搜索表单。 |
| 长列表与宽屏 | 页面提供实际高度约束供 `DataTable` 测量，长列表仅表体滚动，分页保持可见；横向溢出使用公共滚动条和固定操作列。少量流水行按内容收缩。 |
| 小屏兼容及令牌 | 保留 ≤767px 卡片和分页，使用同一工具栏切换页签；工具栏及工具按钮可换行。所有新增样式使用现有令牌，没有新增原始颜色或像素间距；管理端 `tokens.spec.ts` 包含在完整测试中通过。 |
| 中英文 | 补齐预付单号、实付金额、流水类型、流水金额、入账时间文案；实际支付结果不再使用申请金额作为表头。 |

`DataTable` 的插槽改动同步到 `admin-ui/src/components/DataTable.vue` 与 `kol-portal/src/components/DataTable.vue`；调用方为达人端预付结果页的付款记录、预付流水两个列表。没有新增公共组件，也没有修改其他列表的调用方式。
