## 4. 组件兜底为什么不伤及左对齐、操作列和多个行内元素

选择器是 `td.is-center` 里 `.cell` 的 `:only-child`，并排除选择列和 `.actions-cell`。

- 左对齐列的 `td` 是 `is-left`，外层 `AccessibleCell` 根本不匹配。
- 多个行内元素都不是唯一子节点，中间空格仍由 `text-align` 保留。
- 操作列的 `RowActions` 带 `.actions-cell`，规则不打到它。选择列同样排除。
- `inline-flex` 上水平 `margin: auto` 按规范是 0，单个标签和 `NameCode` 仍靠原来的 `text-align` 居中。`justify-content: center` 只在元素本身已经是 flex、而且盒子比内容宽时才起作用。

jsdom 不把组件样式注入文档。单测从 `DataTable.vue` 源码里取出这条规则的选择器（并确认规则里有 `width: fit-content`），再对渲染出的节点用 `element.matches(selector)` 断言：居中列的 flex 根命中；两个并排 `span`、左对齐列的 flex 根、居中操作列的 `.actions-cell` 都不命中。选择器以后改坏了，测试会失败。
