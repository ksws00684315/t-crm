## 3.1 指定店铺生成复制令牌返回 500

- **现象**：管理端生成复制令牌时指定目标店铺 → 500；不指定正常。
- **原因**：`CopyTokenService.requireEnabledShop` 用空的 `TenantScope.companyId()`，且 `JdbcTemplate` 直查 `crm_shop`，违反模块边界。
- **修法**：在 `kol.api` 新增窄接口 `CopyTargetShopApi`；`product.ShopService` 实现「本公司、未删除、已启用」判断（租户插件隔离）；`CopyTokenService` 改为调用该接口。停用店铺 → `SHOP_DISABLED`。
- **测试**：`CopyTokenServiceTest`；`CopyTokenIT#shouldCreateWithTargetShop_andRejectDisabledOrForeign`（成功 / 停用 / 他公司）。
- **浏览器**：未做（见遗留）。

## 3.2 推广配置与跳转数据不一致

- **决定落地**：推广配置为佣金比例、跳转平台、邀请码、推广表格地址的**唯一**修改入口。
- **修法**：
  - 普通编辑请求/命令去掉费率、邀请码、跳转模板、表格地址、邮箱（邮箱见 3.3）；对话框同步。
  - 推广配置新增 `jumpTemplateId`（写入 `crm_kol.link_template_id`）：须为已选平台之一；单选自动取；多选未指定 → 校验失败。
  - `missingConfigFields` 增加 `jumpTemplateId`；管理端缺项提示可处理。
  - 保存时邀请码或跳转平台变化 → 同事务 `KolLinkTargetChangedEvent`；快照含 `jumpTemplateId`；中英文字段名。
- **测试**：`KolPromotionServiceTest`（跳转规则、事件）；`LinkIT` 邀请码变更经 `PUT …/promotion-config` 触发索引刷新；管理端抽屉/表单/状态组件测试。
- **浏览器**：未做。

## 3.3 邮箱只读、审核不可回退
