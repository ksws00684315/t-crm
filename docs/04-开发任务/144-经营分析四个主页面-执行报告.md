# 任务 144｜经营分析四个主页面

基于 `task/144-analytics-foundation` 和已经确认的店铺表现稿实施。四个路由都接入生产 API。共用北京时间筛选、已生效条件、指标卡、排行、当前页导出和五分钟刷新。四个排行详情沿用原系统的抽屉和页签。页面使用管理端导航、样式令牌、列表组件和权限检查。新增详情使用现有数据表。

| 范围 | 复核结果 |
| --- | --- |
| GG-01 日期 | 默认 7 天。时间条提供实时、7 天、30 天、日、月和自定义，支持前后切换；实时按北京时间当天查询。自选日期上限为 90 天，前期取等长前一周期。 |
| GG-02 条件及刷新 | 筛选编辑和已提交条件分离。摘要展示生效条件、数据范围和更新时间。手动刷新和五分钟刷新沿用已提交条件。离开页面停止轮询，旧请求不会覆盖新结果。 |
| GG-03 指标 | 四页提供业务摘要，订单和交易指标环比在上期分母为零时显示横线。 |
| GG-04 权限 | 经营分析使用原菜单权限。查询按登录租户过滤。OWN 交易按支付时的商务快照约束，退款沿原订单归属。 |
| GG-05 排序 | 各可用数值列支持双向排序，默认净销售额降序。店铺 SPU、SKU、达人数合并展示。该组合列按后续确认取消排序。商品业务名次固定在最左列，改变排序不会重算名次。 |
| GG-06 导出 | 四页各自导出当前筛选、排序、页码和条数对应的 XLSX。额外要求 `data:export`，并记录审计。 |
| GG-07 缺失值 | 分母为零显示横线。待接入的商品退款件数、结算和两个人员排行财务字段显示开发中，导出留空。没有佣金查看权限的账号在达人排行显示无权限。 |
| GG-08～12 数据底座 | 延续任务 144 底座。退款完结期与同批订单退款分开，使用已归属的事实和原归属快照。 |
| DP 店铺表现 | 四张卡、交易与结算对照及店铺排行。对照区按最终参考截图采用横向条带，浅蓝交易账和浅绿结算账等宽，窄幅对账标识居中，右侧暖色区说明口径差异。净销售额用大字号，销售额与同批退款在下方同一行。移动端纵向排列。结算净应收显示开发中。卡片提示和结算栏说明其口径为所选期间店铺应收增加减去应收减少，依赖微店结算流水。 |
| SP 畅销商品 | 店铺与 SPU 粒度，商品行实付不分摊运费，跨商品订单去重。商品排行按确认顺序展示排名、订单商品、渠道／源链接商品 ID、店铺、成交达人数、销量、订单数、退款件数、销售额、退款金额、净销售额和结算金额。表头可悬停或聚焦查看口径。当前页导出使用相同字段顺序。 |
| SP 退款可用范围 | 退款金额需要关联商品行，整单退款继续计入订单粒度。商品订单退款率分子为选定支付期内同批订单的成功退款去重数。现有退款源未提供件数，商品级结算流水也待接入，退款件数和结算金额显示开发中。 |
| SP 分阶段内容 | 风险消息推送、TOP10 分析图、订单与退款对比图及退款四象限沿交接稿独立排期。 |
| DR 达人排行 | 表头和当前页导出按确认顺序排列。达人名后附主社媒平台，邀请人旁复用达人列表关系状态。成交链接数按已支付订单归属到该达人的专属链接去重。佣金比例取当前推广配置，需 `commission:view`，预估佣金、佣金支出和累计佣金待接入看板。 |
| YQ 邀请人业绩 | 当前有效达人和累计邀请达人同列，分别取当前启用且归属该商务的达人和历史首次商务归属的达人。周期交易按原订单快照归属。表头和当前页导出按确认顺序排列，预付支出、预估总佣金和总支出待接入看板。 |
| 下钻 | 四个排行的详情入口打开对应对象抽屉，沿用生效日期、店铺和交易归属。经营概览展示排行指标与每日销售、成功退款金额。订单商品与成功退款明细需要 `order:view`。 |
| 商品下钻 | 同一店铺和订单商品 ID 下，按 SKU 或交易达人分组，分别展示支付订单数、销量、销售额、完结退款金额、净销售额。不同 SKU 可能出现在同一订单，SKU 订单数应分别阅读。 |
| 邀请人下钻 | 有 `kol:view` 时展示当前归属达人及其期间交易。归属名单使用当前商务关系，交易仍按支付归属快照。OWN 账号只可查看本人归属达人。 |
