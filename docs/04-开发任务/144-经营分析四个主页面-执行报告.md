| GG-03 指标 | 四页提供业务摘要，订单和交易指标环比在上期分母为零时显示横线。 |

| GG-06 导出 | 四页各自导出当前筛选、排序、页码和条数对应的 XLSX。额外要求 `data:export`，并记录审计。 |
| GG-07 缺失值 | 分母为零显示横线。待接入的商品退款件数、结算和两个人员排行财务字段显示开发中，导出留空。没有佣金查看权限的账号在达人排行显示无权限。 |

| DP 店铺表现 | 四张卡、交易与结算对照及店铺排行。对照区按最终参考截图采用横向条带，浅蓝交易账和浅绿结算账等宽，窄幅对账标识居中，右侧暖色区说明口径差异。净销售额用大字号，销售额与同批退款在下方同一行。移动端纵向排列。结算净应收显示开发中。卡片提示和结算栏说明其口径为所选期间店铺应收增加减去应收减少，依赖微店结算流水。 |
| SP 畅销商品 | 店铺与 SPU 粒度，商品行实付不分摊运费，跨商品订单去重。商品排行按确认顺序展示排名、订单商品、渠道／源链接商品 ID、店铺、成交达人数、销量、订单数、退款件数、销售额、退款金额（完结时间）、净销售额和结算金额。表头可悬停或聚焦查看口径。当前页导出使用相同字段顺序。 |
| SP 退款可用范围 | 退款金额需要关联商品行，整单退款继续计入订单粒度。商品订单退款率分子为选定支付期内同批订单的成功退款去重数。现有退款源未提供件数，商品级结算流水也待接入，退款件数和结算金额显示开发中。 |
| SP 分阶段内容 | 风险消息推送、TOP10 分析图、订单与退款对比图及退款四象限沿交接稿独立排期。 |
| DR 达人排行 | 表头和当前页导出按确认顺序排列。达人名后附主社媒平台，邀请人旁复用达人列表关系状态。成交链接数按已支付订单归属到该达人的专属链接去重。佣金比例取当前推广配置，需 `commission:view`，预估佣金、佣金支出和累计佣金待接入看板。 |
| YQ 邀请人业绩 | 当前有效达人和累计邀请达人同列，分别取当前启用且归属该商务的达人和历史首次商务归属的达人。周期交易按原订单快照归属。表头和当前页导出按确认顺序排列，预付支出、预估总佣金和总支出待接入看板。 |
| 下钻 | 四个排行保留详情入口，下钻单独定稿实施。 |
