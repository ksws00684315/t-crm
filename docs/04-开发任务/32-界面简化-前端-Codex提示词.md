### 2.2 达人列表（照原系统版式）

- **页签**：「达人列表」「邀请链接」。去掉「清理记录」。
- **筛选**：默认只显示「达人编码」「达人名称」「邮箱」三项，加「重置」「查询」；点「展开」后再显示审核状态、关系状态、登录状态、商务。
- **工具栏**：「+ 邀请达人」主按钮，点击切到「邀请链接」页签。另外：
  - 商务账号有「认领达人」；
  - 超管有「转移达人」，打开现有的转移对话框，可以按商务全部转移，或者按勾选的达人转移。
  - 去掉批量启用、批量停用和其他按钮。
- **列**（顺序参照原系统）：
  - 达人编码、达人名称（点击打开详情）、邮箱、手机号（没有手机号时显示 WhatsApp）、国家/地区、主要平台、社交账号；
  - 审核状态、登录状态、关系状态（三个彩色标签）；
  - 佣金比例；
  - 当前月薪：预付功能未做，统一显示「未配置」；
  - 自动清理：`autoCleanupDays` 为空时显示「关闭」，否则显示「N 天」；
  - 邀请人、邀请时间。
- **行操作固定 6 个，位置不变，不可用时置灰**（照原系统）：
  1. **编辑资料**：弹窗字段同原系统：达人名称、手机号（区号下拉 + 号码）、国家/地区、主要平台、社交账号；另外保留 WhatsApp 一项。邮箱、编码只读，不放在弹窗里。
  2. **审核**：只有「待审核」时可用，其他情况置灰。弹窗字段按 04.02。
  3. **佣金**：就是现在的「推广配置」，改名为「佣金」，只有「已通过」时可用。关系状态的修改并入这个弹窗：底部按钮为「保存」「保存并开始推广」「设为无效」（已无效时显示「恢复为待推广」）。推广记录在弹窗内以页签显示。
  4. **设置月薪**：预付功能未做，**一律置灰**，悬停提示「预付功能开发中」。
  5. **清理配置**：弹窗内容为「自动清理：关闭 / N 天」（`PUT /auto-cleanup`）和「立即清理」（原因必填，确认文案说明会删除微店专属商品）。
  6. **冻结 / 解冻**：沿用账号启停。
- 原来的「详情」「链接」「上传推广表」「关系状态」「换商务」「手动清理」等行操作全部去掉：详情由点名称打开；链接和上传推广表移到「达人商品」页；关系状态并入「佣金」；换商务用工具栏「转移达人」；手动清理并入「清理配置」。
- 删除公司级的清理配置界面（33 中删除了对应接口）。
- **邀请链接页签**：显示 8 位商务邀请码与注册链接，各带复制按钮，另有「重新生成」。超管打开时加提示：「通过此链接注册的达人不绑定商务，注册后显示为待更新，请通过认领或转移分配给商务。」显示条件：超管，或满足商务条件的账号（任务 28 的条件）。
- 列多时允许横向滚动，但操作列固定在右侧。

### 2.3 新页面

- **权限设置**（仅超管可见）：两张卡片「商务」「运营」，每张显示默认数据范围和权限码勾选（按权限分组，沿用账号管理中的权限勾选组件），可以保存、恢复默认。顶部写明：「只影响之后新建的账号，不会修改已有账号的权限。」
- **上传文件**：导入任务列表。列：文件名、类型、状态、总行数 / 成功 / 失败、提交人、提交时间、完成时间；有错误文件时显示「下载错误文件」。筛选：类型、状态。
- **操作日志**：增加筛选（模块、关键字、操作人、时间范围）；列显示 `summary`。可以提供一个「转移记录」快捷筛选（模块 = KOL，关键字 = 转移）。

### 2.4 页头与改名

- 删除页头的刷新、全屏、锁屏、深浅色切换按钮，以及对应代码；不再使用的组件和语言包键一并删除。
- 两个前端所有用户看得到的地方（浏览器标题、左上角 Logo 文字、登录页、注册页、语言包中的系统名）改为 SparkTrack。代码内部名称不改。

### 2.5 达人端

- 注册页照原系统截图（`达人注册` 目录）的版式：单列卡片，邀请码在最上方（通过链接进入时只读）；其余字段沿用任务 30（含邮箱验证码）。
- `bdUserName` 为空时显示「Invited by {tenantName}」。
- 改名 SparkTrack。
