### 2.2 达人列表（逐条按 1018 表第 7～15 行的功能说明）

**以 1018 表「功能说明」列的原文为准**，原系统截图只作版式参考。两者不一致时按功能说明做，并在报告中列出差异。负责人 2026-10-20 第二轮的修改已经写进下面各条。

**页签**
- 超管：「达人列表」「达人管理」两个页签。「达人管理」页签用于转移达人，见本节末尾。
- 商务：只有「达人列表」。
- 不要「邀请链接」页签，也不要「清理记录」页签。

**查询区（03.02）**
- 条件：达人ID、达人名称、邮箱；
- 按钮：查询、重置、刷新；列表分页。
- 不加其他筛选条件。

**工具栏（01.01）**
- 只有「+ 邀请达人」按钮。显示条件：超管，或满足商务条件的账号（任务 28 的条件）。
- 点击后弹出「达人邀请链接」弹窗，内容：
  - 商务专属邀请码（8 位），带复制按钮；
  - 注册链接，带复制按钮；
  - 二维码：**显示「开发中」占位**；
  - 「重新生成」；
  - 超管打开时加提示：「通过此链接注册的达人不绑定商务，注册后显示为待更新，由管理员转移给商务。」
- **不要**「认领达人」，也不要其他按钮。

**列表列（04.01）**，按顺序：
1. 达人ID
2. 达人名称（纯文本，**不可点击**）
3. Phone/WhatsApp：显示手机号；没有手机号时显示 WhatsApp；都没有时显示「-」
4. 邮箱
5. 核心社媒平台及社媒ID
6. 佣金比例
7. 预付金额：预付功能未做，显示「开发中」
8. 邀请时间
9. 邀请人
10. 审核状态（待审核 / 已通过）
11. 登录状态（正常 / 冻结 / 异常）
12. 关系状态（待推广 / 推广中 / 待更新 / 无效）
13. 操作

不显示国家/地区、自动清理等功能说明以外的列。列多时可以横向滚动，操作列固定在右侧。

**行操作（04.01），固定 6 个，按此顺序，位置不变，不可用时置灰**：

1. **资料编辑**：弹窗字段与审核页相同：
   - 可编辑：达人名称、WhatsApp/手机号（含国际区号，各一项）、核心社媒平台、核心社媒ID；
   - 只读：邮箱、达人ID。
2. **审核（04.02）**：
   - 只有审核状态为「待审核」时可用；
   - 弹窗展示：达人名称、WhatsApp/手机号（含国际区号）、核心社媒平台、核心社媒ID、邮箱、达人ID；邮箱与达人ID只读；
   - 保存后返回列表，审核状态更新为「已通过」；不可再次审核。
3. **佣金信息（04.03）**：
   - 只有审核状态为「已通过」时可用；关系状态为「待推广」时，点击关系状态标签也打开这个弹窗；
   - 必填：佣金比例、达人邀请码、代购平台（下拉多选，可搜索，支持 100 个以上的平台），每个已选平台对应一个代购平台地址（逐行可增删）、备注、达人推广表格地址；
   - **没有「跳转平台」选项**（后端默认取第一个平台）；
   - 只有一个「保存」按钮：保存成功后，关系状态自动变为「推广中」，**不要**「保存并开始推广」「设为无效」等按钮；
   - 弹窗内用页签显示「修改记录」：版本号、生效时间、修改人、改动内容。
4. **预付金额（05.01）**：预付功能未做，**一律置灰**，悬停提示「开发中」。
5. **清理配置（04.01）**：弹窗内容：
   - 自动清理：「关闭」或「X 天未出单自动清理」（`PUT /auto-cleanup`）；
   - 「立即清理」：二次确认，原因必填，确认文案写明「会删除该达人在微店的关联商品链接，无法恢复」。
6. **冻结 / 解冻**：沿用账号启停。冻结后登录状态为「冻结」，关系状态显示「无效」。

**商务的数据范围（03.02）**
- 列表只显示已绑定本人的达人；
- 没有绑定商务的达人，只能按达人ID或邮箱**精确**搜索找到，找到后可以做「资料编辑」和「审核」，其他操作置灰；
- 不再有「认领」。

**「达人管理」页签（仅超管）：转移达人**
- 表单：
  - 选择范围：「某商务名下全部达人」，或「指定达人」（按达人ID / 名称 / 邮箱搜索后多选）；
  - 目标商务：在职商务，或「未分配」；
  - 生效：立即，或预约时间；
  - 原因。
- 提交调用现有的 `POST /admin-api/kol/bd-transfers`。
- 页签下方说明「转移记录请到 系统管理 → 操作日志 查询」。

**其他**
- 删除旧的「详情」「链接」「上传推广表」「关系状态」「换商务」「手动清理」「认领」等入口，以及公司级的清理配置界面。其中「上传推广表」和「链接」移到「达人商品」页。
- 功能还没齐全的地方（二维码、预付金额等），在页面上标注「开发中」，不要做成可点击的假功能。

### 2.3 新页面

- **权限设置**（仅超管可见）：两张卡片「商务」「运营」，每张显示默认数据范围和权限码勾选（按权限分组，沿用账号管理中的权限勾选组件），可以保存、恢复默认。顶部写明：「只影响之后新建的账号，不会修改已有账号的权限。」
- **上传文件**：导入任务列表。列：文件名、类型、状态、总行数 / 成功 / 失败、提交人、提交时间、完成时间；有错误文件时显示「下载错误文件」。筛选：类型、状态。
- **操作日志**：增加筛选（模块、关键字、操作人、时间范围）；列显示 `summary`。可以提供一个「转移记录」快捷筛选（模块 = KOL，关键字 = 转移）。

### 2.4 页头与改名

- 删除页头的刷新、全屏、锁屏、深浅色切换按钮，以及对应代码；不再使用的组件和语言包键一并删除。
- 两个前端所有用户看得到的地方（浏览器标题、左上角 Logo 文字、登录页、注册页、语言包中的系统名）改为 SparkTrack。代码内部名称不改。

### 2.5 达人端注册（02.01，逐条按功能说明）

- 字段严格按 02.01：
  - 商务邀请码：通过链接进入时自动填写、只读；从登录页点「注册」进入时为空、必填；
  - 必填：账户名、邮箱、密码、二次填写密码；
  - 选填：手机号、WhatsApp、核心社媒平台、核心社媒ID。
- **不要邮箱验证码这一步**（功能说明没有列出；后端在 33 中同步取消）；也不显示国家/地区。
- 版式参照 1018 表第 8 行的图片：单列卡片，邀请码在最上方。
- 登录页有「注册」入口。
- `bdUserName` 为空时显示「Invited by {tenantName}」。
- 改名 SparkTrack。
