| 列 | 显示 |
|---|---|
| 店铺编码 | `CopyText` 可复制 |
| 店铺名称 | |

| 源店铺 | 是源店铺显示「源店铺」标签，否则「-」 |

| 商品容量 | 「当前 / 最大」，满额（剩余为 0）标红；旁边刷新图标调用刷新容量，刷新中显示加载，失败提示错误 |
| 状态 | 启用 / 停用 |
| 操作 | `RowActions`，**全部直接显示，不使用「更多」**（负责人 2026-10-21，ADR-029）：去授权、拉订单、拉退款、编辑、启用 / 停用、设为 / 取消源店铺、加入 / 退出复制池、检查接口；操作列按中英文实测宽度设定，表格内横向滚动 |

- 去授权：调用授权接口取得授权地址后新窗口打开；授权回调回到本页时（地址带 `weidianAuth=success|failed`）提示结果并刷新列表（现有逻辑如已有则沿用）。
- 拉订单、拉退款：调用 `POST /order/syncs` 并传 `type`，提示「已开始同步，可在订单页查看同步状态」；按钮权限与订单同步一致（`order:manage`），无权限隐藏。
- 店铺不能作为复制目标时（`copyEligible=false`），在复制池列旁用提示图标说明原因（停用、未授权、授权过期、源店铺、已退出复制池、容量已满）。
- 源店铺不能加入复制池：对应操作禁用并提示原因。
- 写操作按现有权限只对公司超级管理员显示；其他角色只读。

**新建 / 编辑店铺弹窗**：店铺名称（必填）、店铺渠道（下拉，必填，目前仅微店）、最大商品数量（必填，默认 20000，1～1000000）、微店店铺标识、备注。店铺编码由系统生成，编辑时只读显示。

## 3. 令牌（`views/product/copy-token/`）

**生成令牌弹窗**，字段顺序：

1. 达人（必填，按名称、编码或邮箱搜索，沿用现有搜索）；
2. 目标渠道（必填，下拉，选项显示「微店（自动池剩余 N）」，数据来自 `GET /product/shops/copy-channels`）；
3. 目标店铺（选填，下拉列出该渠道可作为目标的店铺及各自剩余容量；占位文字「不指定时从该渠道的自动复制池分配店铺」）；
4. 商品数量（必填，默认 1）；
5. 有效分钟（必填，默认 1440）。

- 商品数量超过所选店铺（或渠道）剩余容量时，前端即时提示，后端错误码也要映射到文案。
- 默认值读后端返回或系统配置，不在前端写死。
- 渠道没有可用容量时，目标渠道选项禁用并说明原因。

**令牌列表**：按令牌、达人、目标渠道筛选；列为令牌（可复制）、达人、目标渠道、目标店铺（未分配显示「自动分配」，已分配显示「名称（编码）」）、使用量「已用 / 总量」、有效分钟、过期时间、状态（有效 / 已用尽 / 已过期）。核对现有实现，缺的补齐。
