# 达人库周数据与导入模板验收

| 项目 | 验收内容 |
|---|---|
| 达人档案 | 建联与寄样展示入库日期及样品类型。新增、编辑和跟进支持样品类型。年龄与性别支持录入占比。 |
| 内容基础信息 | 右侧抽屉先展示只读信息，点编辑进入表单。链接、标题、发布日期和内容形式必填。销售指标在数据明细中维护。 |
| 周数据 | 周一至周日为一个自然周，新增范围为本周及前九周。新增和编辑均按行保存，重复周、非整数计数和超过两位小数的 GMV 会被拒绝。 |
| 累计指标 | 内容表格与抽屉显示单条内容累计，页面顶部汇总所有内容。旧版手动录入的累计继续计入总数，修改某周只应用该周差值。图表按已保存的周展示。总成本显示佣金、样品和坑位费组成。 |
| Excel 导入 | 字段集中在 A 列，B 列起每位达人一列。必填高亮，附说明和示例。受众性别下拉为女性、男性，样品类型为送样、寄拍。支持读取旧版横向表格。已有档案返回重复提示。 |

新增四个 Flyway 迁移，分别增加受众占比、视频标题与周数据、内容样品状态与备注、达人样品类型。历史视频标题可空，编辑时需补填。历史销售累计缺少周度归属，因此继续计入指标卡，周趋势按已录入的数据绘制。

验证以关联 PR 的前端全量检查、后端构建和四组 Docker 集成测试为准。浏览器使用本地演示数据核对界面与下载，数据库导入和周数据写入由集成测试覆盖。
