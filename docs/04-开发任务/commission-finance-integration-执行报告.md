# 佣金管理端页面集成报告

日期：2026-10-25（Asia/Shanghai）。PR：#112。分支：`task/commission-finance-integration`。

## 当前范围

本分支已同步到 `origin/main` `914a55a`，包含任务61契约、任务62佣金结算后端（#124）和任务64达人门户支撑（#123）。PR #112 仅保留管理端前端；PR #116 负责达人端前端。管理端使用现有 CRM 导航、组件和登录权限，不创建独立网站。提现后端任务63（#121）尚待合并，真实提现联调及最终合入仍按负责人确定的顺序等待该任务。

达人预付继续由已合并的独立版块负责；佣金收入页读取其已支付金额及抵扣结果，不新增“记预付金额”入口。当前 PR 不修改后端，不新增数据表或迁移。

## 财务页面

- 达人收入：展示预估总佣金、冻结佣金、可提现及已付金额（拆分佣金付款与预付款），期间订单/件数与收入流水。
- 提现任务：按申请编号、达人ID、商务名、状态筛选；提供详情、状态操作和按权限导出。
- 提现详情：采用负责人确认的居中信息表和订单明细样式；订单编号复制，长商品名换行、SKU独立显示，同订单商品合并，每页10笔不同订单；展示申请占用和申请后订单剩余快照，不展示底部占用合计。
- 结算配置与订单结算明细：沿用 CRM 表格、筛选和分页组件，金额来源不明时显示待核实。

## 接口及生产开关

页面 API 适配层按任务61的 ADR-032 契约实现，包括统一财务任务列表和提现详情/订单接口。提现流程实现及真实联调等待任务63（#121）；#112 中原先新增的只读投影表、迁移和接口已经删除。

佣金收入、结算配置和结算明细按任务61契约接入任务62后端；提现相关接口等待任务63（#121）合并并联调。生产模式的 `VITE_COMMISSION_API_ENABLED` 仍默认关闭；关闭时各佣金页面显示“开发中”且不会发出佣金请求。待提现后端部署后完成负责人要求的浏览器验收，再决定是否启用该变量。

显式本地预览仍由 `MODE=commission-preview`、`VITE_COMMISSION_DEMO=true` 及 localhost 域名门控。演示引擎移至 `admin-ui/preview/commission/`，由该构建模式动态导入；生产构建检查需确认预览代码和种子字符串均未进入任何输出文件。演示申请、审核与付款不接触真实财务写接口。

## 等待架构任务

负责人确认的真实提现流程为“达人申请—运营审核—财务审核—财务支付”。前端依照任务61的设计规格和字段契约实现；任务63（#121）合并后进行真实提现端到端联调。
