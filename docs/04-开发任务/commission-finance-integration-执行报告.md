# 佣金管理端页面集成报告

日期：2026-10-26（Asia/Shanghai）。PR：#112。分支：`task/commission-finance-integration`。

## 当前范围

本分支已同步到 `origin/main` `0a472a1`，包含任务62（#124）、63（#121）和67（#125）的全部后端实现及契约修正。PR #112 仅保留管理端前端；PR #116 负责达人端前端。管理端使用现有 CRM 导航、组件和登录权限。下一步由审查人使用真实后端进行浏览器验收，通过后再合入。

达人预付继续由已合并的独立版块负责；佣金收入页读取其已支付金额及抵扣结果，不新增“记预付金额”入口。当前 PR 不修改后端，不新增数据表或迁移。

## 财务页面

- 达人收入：展示预估总佣金、冻结佣金、可提现及已付金额（拆分佣金付款与预付款），期间订单/件数与收入流水。
- 提现任务：按申请编号、达人ID、商务名、状态筛选；提供详情、状态操作和按权限导出。
- 提现详情：采用负责人确认的居中信息表和订单明细样式；订单编号复制，长商品名换行、SKU独立显示，同订单商品合并，每页10笔不同订单；展示申请占用和申请后订单剩余快照，不展示底部占用合计。
- 结算配置与订单结算明细：沿用 CRM 表格、筛选和分页组件，金额来源不明时显示待核实。

## 接口及生产开关

页面 API 适配层按任务61的 ADR-032 契约实现，包括统一财务任务列表和提现详情/订单接口。后端任务62、63、67均已合并；#112 中原先新增的只读投影表、迁移和接口已经删除。

生产模式的 `VITE_COMMISSION_API_ENABLED` 仍默认关闭；关闭时各佣金页面显示“开发中”且不会发出佣金请求。按最新审查意见，保留该开关，由审查人使用真实后端完成浏览器验收后决定其去留。

显式本地预览仍由 `MODE=commission-preview`、`VITE_COMMISSION_DEMO=true` 及 localhost 域名门控。演示引擎移至 `admin-ui/preview/commission/`，由该构建模式动态导入；生产构建检查需确认预览代码和种子字符串均未进入任何输出文件。演示申请、审核与付款不接触真实财务写接口。
