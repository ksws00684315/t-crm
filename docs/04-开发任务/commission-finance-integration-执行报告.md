# 佣金管理端页面集成报告

日期：2026-10-24（Asia/Shanghai）。PR：#112。分支：`task/commission-finance-integration`。

## 当前范围

本分支已同步到 `origin/main` `e2f010a`，遵循负责人最新评论：架构任务61–64负责ADR-032、字段契约、佣金/提现后端和达人端支持；PR112仅管理端前端，PR116仅达人端前端。两端等待任务61合并后才按契约接入，真实端到端联调等待任务62/63完成。管理端使用现有 CRM 导航、组件和登录权限，不创建独立网站。

达人预付继续由已合并的独立版块负责；佣金收入页读取其已支付金额及抵扣结果，不新增“记预付金额”入口。当前 PR 不修改后端，不新增数据表或迁移。

## 财务页面

- 达人收入：展示预估总佣金、冻结佣金、可提现及已付金额（拆分佣金付款与预付款），期间订单/件数与收入流水。
- 提现任务：按申请编号、达人ID、商务名、状态筛选；提供详情、状态操作和按权限导出。
- 提现详情：采用负责人确认的居中信息表和订单明细样式；订单编号复制，长商品名换行、SKU独立显示，同订单商品合并，每页10笔不同订单；展示申请占用和申请后订单剩余快照，不展示底部占用合计。
- 结算配置与订单结算明细：沿用 CRM 表格、筛选和分页组件，金额来源不明时显示待核实。

## 接口及生产开关

当前页面保留适配层，但未按既有分支接口定稿。任务61合并前，任何已有路径和 DTO 均不视为最终契约；管理端接口清单仅作为待字段对照表核实的候选项。#112 中原先新增的只读投影表、迁移和接口已经删除。

任务61契约及任务62/63后端能力尚未完成前，生产模式的 `VITE_COMMISSION_API_ENABLED` 默认关闭。关闭时各佣金页面显示“开发中”且不会发出佣金请求。按任务61契约完成前端适配，且后端能力部署联调通过后，才允许设置该变量为 `true`。

显式本地预览仍由 `MODE=commission-preview`、`VITE_COMMISSION_DEMO=true` 及 localhost 域名门控。演示引擎移至 `admin-ui/preview/commission/`，由该构建模式动态导入；生产构建检查需确认预览代码和种子字符串均未进入任何输出文件。演示申请、审核与付款不接触真实财务写接口。

## 等待架构任务

负责人确认的真实提现流程为“达人申请—运营审核—财务审核—财务支付”。任务61交付设计规格和字段对照表前，不根据旧分支推断审核状态、商务筛选、分阶段备注、申请余额快照或订单级剩余快照。契约合并后再按对照表适配；任务62/63完成后再开展真实端到端联调。
