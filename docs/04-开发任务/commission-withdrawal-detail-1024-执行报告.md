## 尚待 #116 接口契约确认

当前拉取到的 #116 分支仍为 OPEN。管理页已按其 controller 路径和基本 DTO 接入，但其当前 withdrawal query 只支持 `applicationNo/kol/type/status/page/size`，尚无独立商务名筛选；当前状态也没有 `PENDING_FINANCE_REVIEW` 阶段及详情中的运营/财务分阶段备注、预估总额/当前可提现快照字段。为避免生产页面提前请求这些尚未落地的契约，API 开关保持默认关闭。#116 完成接口表及字段后，管理端再据最终契约做联调并开启开关。

负责人要求的提现流程为“达人申请—运营审核—财务审核—财务支付”。#112 本地预览仍呈现该流程；真实流程需由 #116 的权威服务状态机支持。不得用预览状态宣称真实审批链路已完成。
