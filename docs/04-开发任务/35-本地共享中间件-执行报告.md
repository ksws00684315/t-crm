## 变更结构

```text
本机开发后端 ── localhost:55432 / 46391 ──┐
                                           ├── tcrm-local 网络
预览 crm-admin / crm-redirect ─────────────┘      ├── PostgreSQL 17.11（命名卷）
       │                                          └── Redis 7.4.5（密码 + AOF，命名卷）
       └── 预览网络 ── Nginx :8890/:8891/:8892
```

默认共享项目、网络为 `tcrm-local`，卷为 `tcrm-local_pgdata`、`tcrm-local_redisdata`。共享环境配置由 `deploy/.env.local` 提供；脚本生成随机数据库/Redis 凭证、`TCRM_SECRET_KEY`、`TCRM_IP_HASH_SALT` 和平台管理员凭证，并设权限 `600`。预览和本机后端使用相同凭证、密钥与数据库。

主要命令：

```bash
deploy/scripts/local-infra.sh up|status|down|backup|restore <文件>|psql|migrate-from-preview
deploy/scripts/preview.sh up|down|reset
```

自测通过 `TCRM_LOCAL_ENV_FILE`、`TCRM_LOCAL_INFRA_PROJECT`、`TCRM_LOCAL_INFRA_NETWORK`、`TCRM_LOCAL_INFRA_DB_PORT`、`TCRM_LOCAL_INFRA_REDIS_PORT`、`TCRM_PREVIEW_PROJECT`、`TCRM_PREVIEW_SUBNET` 和三个 `TCRM_PREVIEW_*_PORT` 覆盖变量隔离。预览 `down` 只停预览容器；`reset` 只删预览容器与本地镜像，不操作共享卷。`local-infra.sh` 没有删除卷的子命令。

## 负责人环境切换步骤

合并后由架构负责人在持有旧预览 `deploy/.env.preview` 与旧卷的工作目录执行。命令会先备份已存在的共享卷（若有）和旧预览数据库/RDB，迁移 `.env.preview` 的数据库/Redis凭证、加密密钥、IP 哈希盐、管理员账号与外部地址，然后停止旧预览容器、复制数据卷并启动共享中间件：

```bash
TCRM_ALLOW_OWNER_PREVIEW_MIGRATION=yes deploy/scripts/local-infra.sh migrate-from-preview
deploy/scripts/local-infra.sh status
deploy/scripts/local-infra.sh psql
deploy/scripts/preview.sh up
```

负责人需核对迁移前后达人/用户数量、登录和主要页面，再确认旧数据可由共享服务读取。旧卷必须先保留；确认切换完成并再次备份后，才可手动删除：

```bash
docker volume rm tcrm-preview_pgdata tcrm-preview_redisdata
```
