# 124 表格脚本接口地址容错：执行报告

- 分支：`task/124-sheet-script-url-sanitize`
- 日期：2026-11-07
- 类型：交付脚本缺陷修复（`deploy/sheet-script/`）

## 1. 问题

客户在新表格里加载模板时失败：

```
模板加载失败：Exception: 错误请求：
https://admin.sparktr%20ackcrm.com/admin-api/external/product-links/templates?channelCode=WEIDIAN
```

`%20` 出现在域名中间（`sparktr ackcrm.com`），说明传给 `UrlFetchApp` 的 base URL
本身含一个空格。`productLinkApiBaseUrl_()` 只做了 `String(...).replace(/\/+$/, "")`，
把带空格的配置值原样拼进请求，Google 直接以“错误请求”拒绝。

空格来自配置值本身：脚本属性 `TALENT_CRM_API_BASE_URL` 在粘贴长地址时被断行，
换行变成了空格。脚本默认常量（`https://admin.sparktrackcrm.com/admin-api`）本身正确。

## 2. 改动

| 文件 | 改动 |
|---|---|
| `deploy/sheet-script/SparkTrack-3.0.5.gs` | `productLinkApiBaseUrl_()` 先去掉所有空白再去掉末尾斜杠；结果不是 `http(s)://主机` 形式时抛出「接口地址格式不正确，请检查脚本属性 TALENT_CRM_API_BASE_URL：<原值>」，不再发出坏请求 |
| `deploy/sheet-script/README.md` | 安装步骤第 4 步提示粘贴时不要带换行/空格，说明脚本会自动去除空白与格式错误的提示 |
