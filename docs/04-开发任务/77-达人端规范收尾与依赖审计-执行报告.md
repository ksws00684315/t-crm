## 本轮解决的问题

### 1. 依赖安全审计（任务 60 起记为「不满足」）

`pnpm audit --prod` 在两端各命中 1 个高危：`axios → follow-redirects 1.16.1`，`GHSA-mrwp-f3q8-3g9p`（跨 realm 的 `sensitiveHeaders` 数组被丢弃，自定义凭证可能跟随重定向），影响范围 `>=1.16.0 <=1.16.1`，补丁版 `>=1.16.2`。

处理：用 `pnpm update follow-redirects --depth 9999 --lockfile-only` 只提升传递依赖的解析版本到 `1.16.2`，`axios` 的直接依赖声明不动（其版本范围本就允许 1.16.2），因此不涉及规范 07 的「新增依赖」流程。`THIRD-PARTY-NOTICES` 同步重生成为 1.16.2。

复核：

```
kol-portal  pnpm audit --prod  → No known vulnerabilities found
admin-ui    pnpm audit --prod  → No known vulnerabilities found
```

修复前两端均为 `1 vulnerabilities found / Severity: 1 high`。

### 2. 表格行操作字重（规范 10 第 1 节「表格操作链接 400」）

`#app .el-button { font-weight: 600 }` 是全局规则，把表格行内的操作链接也抬到 600。管理端 `admin-ui/src/style/index.css` 早有一条对冲规则 `#app .actions-cell .el-button { font-weight: 400 }`，达人端移植组件时漏了这条。

处理：`kol-portal/src/style/index.css` 补同一条规则，与管理端写法一致。

### 3. 手机端触控目标不足 44px（规范 10 第 2 节「小于 768px 时交互目标至少 44px」）

| 位置 | 原值 | 现值 |
|---|---|---|
| 页头账户菜单 `summary` | `min-height: 32px` | 767px 以下 `44px` |
| 账户菜单面板内链接 | `min-height: 32px` | 767px 以下 `44px` |
| 我的商品卡片「复制链接」 | 无最小高度（实际约 40px） | 767px 以下 `44px`，并改为 `inline-flex` 垂直居中 |

统一取 `--tcrm-control-height-mobile`（44px），不新增数值。

### 4. 我的商品手机卡片列表缺空态（规范 10 第 3 节「空态在卡片内居中」）

桌面表格的 `#empty` 插槽随表格在 767px 以下一起 `display: none`，而卡片列表 `v-for` 在无数据时不渲染任何内容，手机上整页空白。

处理：卡片列表改为 `v-if="items.length"`，无数据且不在加载中时渲染独立空态（`data-test="items-empty-mobile"`），仅在手机断点显示；文案复用 `items.empty` / `items.emptyHint`，不新增语言键。补单元测试 1 条（第 4 项），覆盖「空态存在 + 卡片列表不渲染」。
