## 2. 供管理端沿用的约定（重要）

> 任务 06d 管理端执行时应照搬本节结构，管理端差异：默认语言 `zh-CN`、localStorage 键换为管理端自己的键（如 `tcrm.admin.locale`）、Element Plus 默认语言包用中文。

1. **目录结构**：
   - `src/locales/en-US.ts`：基准语言包（管理端可用 `zh-CN.ts` 作基准，约束方向相反）；
   - `src/locales/zh-CN.ts`：受类型约束的翻译文件；
   - `src/locales/index.ts`：创建唯一 i18n 实例（`legacy: false`、`globalInjection: true`、默认语言、`fallbackLocale` 同默认语言），并导出 `translate(key: string)` 供动态键使用；
   - `src/stores/locale.ts`：语言状态（见下）；
   - `src/utils/locale.ts`：`SUPPORTED_LOCALES`、`DEFAULT_LOCALE`、`LOCALE_STORAGE_KEY`、`isSupportedLocale`、`loadStoredLocale`、`saveStoredLocale`（读写都包 try/catch）。
2. **键名规则**："区域.含义"分层（`common.*`、`route.*`、`errors.*`、各页面区域如 `login.*`）；错误码直接作 `errors` 下的键（UPPER_SNAKE_CASE）；语言自称放 `locale.<id>`；不用原句做键。
3. **语言状态的用法**：组件从 `useLocaleStore()` 读 `locale`、调 `setLocale`；模块级代码（`http` 拦截器、标题设置）同样引用该 store 或 `locales/index.ts` 的实例。`setLocale` 负责：更新 store → 写 localStorage → 更新 `i18n.global.locale.value` → 更新 `document.documentElement.lang`。store 创建时即应用已保存语言（`main.ts` 在挂载前创建一次，首屏即正确）。
4. **错误码写法**：保持 `api/error-codes.ts` 的函数式接口（`messageForErrorCode` 等），内部经 `translate` 取 `errors.*`；已知码集合从基准语言包 `errors` 下 UPPER_SNAKE_CASE 键过滤得出（小写的 `generic`/`network`/`field` 是兜底文案，不算码）；`ApiError.displayMessage` 在读取时解析文案，语言切换即时生效；后端 `msg` 永不展示。
5. **路由标题处理**：`meta.title` 存键（`route.xxx`）；`router/title.ts` 的 `applyDocumentTitle(meta)` 翻译并拼接 `app.title`；`guard.ts` 的 `afterEach` 调用它；`App.vue` watch `locale` 变化用当前 `route.meta` 重设，保证不导航也能切标题。
6. **类型约束写法**：基准包 `export type MessageSchema = typeof enUS;`，翻译包 `const zhCN: MessageSchema = {...}; export default zhCN;`——缺键、多键（对象字面量多余属性检查）都会导致 `pnpm typecheck` 失败。注意：`createI18n` **不要**传显式泛型 `createI18n<[MessageSchema], LocaleId>`（vue-i18n 11.4 下会退化为 Legacy 类型，`i18n.global.locale` 变成普通字符串）；直接内联 options 即可得到正确的 Composer 类型。
7. **测试写法**：
   - 键一致性：递归展平两包键集合比较（`locales/__tests__/messages.spec.ts`），另断言每个 `meta.title` 键存在；
   - store 行为：`setActivePinia(createPinia())` 后建 store（新 pinia 模拟刷新重载），断言 `locale`、`i18n.global.locale.value`、`document.documentElement.lang`、`localStorage` 四处一致；
   - 组件：`mount(Component, { global: { plugins: [ElementPlus, i18n, pinia] } })`，切 `setLocale("zh-CN")` 后 `await nextTick()` 断言中文文本；el-select 的标签在 nextTick 后出现在 `.el-select__placeholder`，选项文本在 teleported 的 `document.body`；
   - ElConfigProvider：`findComponent(ElConfigProvider).props("locale")` 与直接 import 的 element-plus 语言包对象做 `toBe` 比较；
   - 请求头：给 `createHttp` 传受控 `getLanguage`，断言 adapter 收到 `Accept-Language`。
8. **Element Plus 语言包**：`import en from "element-plus/es/locale/lang/en"`、`import zhCN from "element-plus/es/locale/lang/zh-cn"`，在 `App.vue` 里按当前语言映射后传给 `ElConfigProvider`；`app.use(ElementPlus)` 不再传 `locale`。
