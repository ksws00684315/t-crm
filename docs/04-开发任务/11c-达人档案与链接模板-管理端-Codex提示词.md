## 1. 背景

任务 11、12a 已在后端提供了下列能力，但管理端还没有界面：

- **达人档案新字段**：WhatsApp、代购平台（链接模板）、邀请码、推广表格地址、主阵地；
- **链接模板**：各代购平台的商品链接模板，由超级管理员维护；
- **重发邀请**：后台录入的达人通过邀请邮件激活账号，可以重发。

任务 12c 将提供达人自助注册：商务把自己的注册链接发给达人，达人自己注册。管理端需要一个地方，让商务看到和复制自己的注册链接。

客户要求：资料尽量由商务维护，达人操作越少越好（2026-10-14 会议）。

## 4. 已定的设计决定（不要自行改变）

### 4.1 达人表单与详情

1. 新建 / 编辑对话框新增一组字段，标题为「联系与推广」，包括：
   - **WhatsApp**：提示格式 `+8613800000000`；
   - **代购平台**：下拉，选项来自 `GET /admin-api/link/templates`。只列启用的模板；如果当前值已停用，仍显示为「名称（已停用）」。可以清空。
   - **邀请码**；
   - **推广表格地址**：校验以 `https://docs.google.com/spreadsheets/` 开头。

   以上字段都可选，前端格式校验与后端一致（见 11 的执行报告 2.1）。
2. **国家**改为可选。
3. **社媒账号**每行增加「主阵地」单选：同一时间最多一行被选中；可以都不选。
4. **详情抽屉**显示上述字段：
   - WhatsApp、邀请码用 `CopyText`；
   - 推广表格地址显示为可点击的外链（新窗口打开、`rel="noopener noreferrer"`），旁边也用 `CopyText`；
   - 主阵地在社媒列表中加「主」标签；
   - 另显示「来源」（后台录入 / 自助注册）和「账号状态」（见 4.3）。
5. **达人列表**新增两列：「代购平台」和「表格」（有地址时显示一个图标链接，点击新窗口打开），默认显示，可在列设置中隐藏。

### 4.2 链接模板管理（超管专属）

1. 新页面「系统 → 代购平台模板」，路由 `/system/link-templates`，`meta.superAdmin: true`。
2. 列表列：编码、名称、模板地址（等宽字体，溢出提示）、排序、状态、操作；不分页（`paged=false`）。
3. 新建 / 编辑对话框：
   - 编码只在新建时可填，规则为 `^[a-z0-9-]{2,32}$`；
   - 名称；
   - 模板地址：https，必须含 `{PRODUCT_ID}`，可含 `{INVITE_CODE}`；
   - 排序：0～9999。
4. 对话框里有「预览」：输入示例商品 ID（默认 `7849640325`）和示例邀请码（默认 `ABC123`），实时显示代入后的地址。
   - 规则与后端一致：邀请码做 URL 编码；
   - 如果模板含 `{INVITE_CODE}` 而示例邀请码为空，提示「该达人未设置邀请码时，链接会回退为微店商品页」。
5. 启用 / 停用使用确认框。停用的提示文案：「停用后，使用该模板的达人链接将改为跳转到微店商品页。」
6. 错误码 `LINK_TEMPLATE_CODE_EXISTS`、`LINK_TEMPLATE_NOT_FOUND`、`LINK_TEMPLATE_INVALID`、`KOL_MULTIPLE_PRIMARY` 已有文案，确认显示正确即可。

### 4.3 账号状态与重发邀请

1. 达人列表新增「账号」列，取 `accountStatus`（由 12c 加到 `KolVO`）：0 显示「未激活」（灰色标签），1 显示「已激活」。
2. 操作列在「未激活」且来源为「后台录入」时显示「发送邀请」（权限 `kol:edit`），调用 `POST /admin-api/kol/kols/{id}/invite`：
   - 成功提示「邀请邮件已发送」；
   - 返回 409 `KOL_ALREADY_ACTIVATED` 时提示对应文案，并刷新该行。
3. 详情抽屉同样提供该按钮。

### 4.4 我的注册链接（`kol:register-link`）

1. 在「达人管理」页的工具栏放一个「我的注册链接」按钮（有 `kol:register-link` 时显示），点击后打开对话框：
   - 显示完整链接：`{达人端地址}/register?c={code}`，用 `CopyText`；
   - 一段说明：「把链接发给达人，达人注册后自动归属到你名下。」
   - 「作废并生成新链接」按钮：确认后调用 `POST`，旧链接立即失效。
2. 达人端地址由后端在响应中给出（字段 `url`），前端不拼接域名。

- 达人端页面（12c）。

### 4.6 接口约定（与 12c 共用，不得改动）

```text
GET  /admin-api/kol/kols、/{id}       → KolVO 新增 accountStatus: 0|1（12c 补）
GET  /admin-api/kol/register-code     → data: { code, url, status }       （kol:register-link；没有时自动生成）
POST /admin-api/kol/register-code     → data: { code, url, status }       （作废旧码并生成新码）
POST /admin-api/kol/kols/{id}/invite  → data: null；已激活 409 KOL_ALREADY_ACTIVATED（已在 main）
```

| 场景 | 期望 |

| 表单 | 新字段的格式校验；代购平台下拉只列启用模板，已停用的当前值显示「（已停用）」；主阵地只能选一行 |
