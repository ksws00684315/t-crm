### 4.4 表格

公共组件 `src/components/DataTable.vue`，列偏好 `src/utils/table-prefs.ts`，键 `tcrm.admin.table.<id>`。

工具栏：总数、密度（默认 / 紧凑 / 宽松，对应 Element Plus 的 default / small / large）、刷新、列设置、表格区域全屏。列设置用勾选和上移 / 下移，不用拖拽。重置只恢复列，不动密度和每页条数。第一列和 `actions` 列始终显示并置灰。隐藏列时按钮写「已隐藏 N 列」。解析失败或版本不符时回到默认。新出现的列按默认位置插入并默认显示。

列表页用纵向 flex：搜索区自然高度，表格卡片 `flex: 1; min-height: 0`。`el-table` 设 `height="100%"`，由表头固定与横向滚动条落在可视区底部；不再覆盖 sticky。分页文案是「第 1–10 条 / 共 N 条」，可选 10 / 20 / 50 / 100。每页条数由页面在创建时用 `readPageSize(tableId, fallback)` 读出。有筛选条件且没有数据时，空状态提供「清除筛选」。

`plain` 用于抽屉和对话框：不显示工具栏，也不占满视口高度。`tooltip` 打开单元格溢出提示。表格全屏是铺在主内容区上的遮罩，左边距为 `--layout-aside-width`，不是浏览器全屏。

店铺和公司列表接口一次返回全部。这两个表格 `paged` 为 false，不向接口发分页参数，只显示总数。

### 4.5 搜索

公共组件 `src/components/ListSearch.vue`。常显条件放第一行，其余放「展开」。展开状态是组件内的 ref，随 KeepAlive 保留，不写入存储。表单在 `@keyup.enter` 上查询（排除 textarea 与按钮），避免「多个文本框且无 submit 按钮时 Enter 不提交」的 HTML 行为。查询按钮仍是 `type="button"` 并监听点击。芯片和空状态的 `filter-count` 来自「上次点查询时」的条件快照，不是正在输入的值。

### 4.6 菜单搜索

`src/layout/MenuSearch.vue`，由布局挂载，所以登录页不会打开。`Ctrl+K` 与 `⌘+K` 在 window 的捕获阶段监听，并 `preventDefault`。候选项只来自 `buildMenu`。匹配当前语言的菜单名和分组名，不区分大小写。空查询最多显示 6 条最近访问，键 `tcrm.admin.recent`，按用户 id 分开；当前用户无权的路径会丢掉。方向键在两端停住，不循环。Enter 打开或切换到该标签。Esc 关闭。关闭后焦点回到打开前的元素。最近访问在选中结果时记录，侧栏点进一个菜单项时也记录。分组标题本身不是结果。

### 4.7 复制

`src/utils/copy.ts`：先用 Clipboard API，失败再用 `document.execCommand("copy")`。成功提示「已复制 {text}」，超过 32 个字符截断并加 `…`。失败提示「复制失败，请手动复制」。`src/components/CopyText.vue` 的按钮带 `data-test="copy"`；空值不显示按钮。

### 4.8 登录过期

`src/utils/reauth.ts` 的 `decideUnauthorized` 决定动作，`src/api/setup.ts` 执行，`src/layout/ReauthDialog.vue` 展示。

| 情况 | 行为 |
|---|---|
| 已登录，401 且 `AUTH_UNAUTHORIZED`，对话框未开 | 留在当前页，保留会话和表单，打开一个对话框，不自动重发失败的请求 |
| 同时多个 401 | `useReauthStore().open()` 重复调用不新开 |
| 对话框里密码正确且账号相同 | 关闭对话框，留在原页 |
| 对话框里密码错误（`AUTH_INVALID_CREDENTIALS`） | 忽略，保留会话，列表页不再弹错误条；错误显示在对话框里 |
| `AUTH_ACCOUNT_DISABLED` | 清空会话，回到登录页，带上 `redirect` |
| 对话框打开时登录接口返回 `AUTH_ACCOUNT_LOCKED` | 清空会话，回到登录页 |
| 当前不是已登录，或人在登录页 | 按原逻辑处理；登录页的 401 仍由登录页自己显示 |
| 「切换账号」 | `tabs.reset()`，再 `user.clearSession()`，再进入 `/login`。这里不调用 `user.logout()`：服务端会话已经失效，logout 会再收到 401，对话框会再次打开 |
| 对话框登录返回的账号与原账号不同 | 保留新登录会话，`tabs.reset()`，进入 `/`。守卫再把平台管理员送到公司管理，把其他角色送到首页。不清掉新会话，否则守卫会把人送回登录页 |

对话框不能点遮罩、按 Esc 或点关闭按钮关掉。用户名只读。密码只校验空白和超长。

### 4.9 新版本提示

Vite 内联插件 `appVersionPlugin`（`admin-ui/vite.config.ts`）在配置加载时生成一次构建标识（时间的 36 进制加一段随机串），同一字符串写入 `define.__APP_VERSION__` 和构建根目录的 `version.json`（`{"version":"..."}`）。提示词允许用构建时间加内容哈希；这里不用内容哈希，是因为 `define` 在打包完成之前就要定下来，不能等产物算完再回头替换。

`src/utils/version.ts`：生产环境每 5 分钟，以及页面从隐藏变为可见时，请求 `/version.json?t=<时间戳>`，`cache: "no-store"`。与当前构建标识不同，且不在「稍后」窗口内，就显示 `src/components/VersionNotice.vue`。文案是「系统已更新，刷新页面以使用新版本。已打开的标签会保留。」「立即刷新」调用 `location.reload()`，标签存在 `sessionStorage`，刷新后会恢复。「稍后」写入 `tcrm.admin.version-snooze`，30 分钟内不再提示。`import.meta.env.DEV` 为真时不发请求。开发服务器上看不到这张卡片，由单元测试覆盖。

### 4.10 水印

`el-watermark` 包住布局主内容区里的 `RouterView`，不包侧栏、页头，也不出现在登录页。文案是 `昵称 · 用户名 · YYYY-MM-DD`，日期用本地日历（`getFullYear` / `getMonth` / `getDate`）。颜色读取 `--tcrm-color-text`，再用 `watermarkInk` 转成 alpha 0.08 的 rgba，因为画布不能用 CSS 变量。主题切换后立刻重读。旋转 −20°，间距 `[140, 120]`，字号 14。间距和字号是提示词未写死的实现取值，透明度保持很低。Element Plus 的水印层 `pointer-events: none`，并用 MutationObserver 在层被删掉时画回来。界面上没有关闭入口。

### 4.11 其他

页头刷新和标签菜单的刷新都调用 `tabs.refresh`。路由守卫里的 NProgress 保留。页面切换加了 150ms 透明度过渡，类名 `tcrm-page`；样式不带 scoped，否则匹配不到运行时类名。`prefers-reduced-motion: reduce` 时关掉过渡。主题、侧栏、语言、表格偏好都只在浏览器本地。新增文案在 `zh-CN.ts` 与 `en-US.ts`，键集合测试和残留中文测试通过。

## 2. 后续页面必须使用的公共件

新的列表页使用 `ListSearch` + `DataTable`，可复制的业务编号用 `CopyText`。不要再直接铺一套 `el-table` 加手写分页。

```vue
<ListSearch :chips="chips" has-more @search="search" @reset="reset" @remove="removeChip">
  <template #primary>
    <el-form-item :label="t('common.keyword')">
      <el-input v-model="query.keyword" clearable />
    </el-form-item>
  </template>
  <template #more><!-- 收进「展开」的条件 --></template>
</ListSearch>

<DataTable
  table-id="example"
  row-key="id"
  :columns="columns"
  :rows="rows"
  :total="total"
  :page="query.page"
  :size="query.size"
  :loading="loading"
  :filter-count="chips.length"
  @update:page="onPage"
  @update:size="onSize"
  @refresh="load"
  @clear-filters="reset"
>
  <template #cell-code="{ row }"><CopyText :value="row.code" /></template>
</DataTable>
```

`query.size` 在 setup 里用 `readPageSize("example", 20)` 初始化。`DataTable` 改每页条数时会先发出 `update:size`，再发出 `update:page` 为 1；父组件的 `onSize` 只赋值，`onPage` 赋值并请求。

抽屉里的表格加 `plain`。一次返回全部数据的接口加 `:paged="false"`。

可复用的状态与函数：

| 名称 | 用途 |
|---|---|
| `useThemeStore()` | 读取 `mode` / `resolved`，`cycle()` 切换主题 |
| `useTabsStore()` | `open`、`close`、`refresh`、`include`、`keyFor` |
| `useMenuSearchStore()` | 页头按钮调用 `open()` |
| `useReauthStore()` | 401 处理里调用 `open()`，页面不要自己弹登录框 |
| `copyText` / `CopyText` | 复制业务编号、邮箱、链接 |
| `readPageSize` / `loadTablePrefs` | 每页条数和列偏好 |
| `watermarkText` | 只在布局里使用；新页面不要各自再铺一层水印 |

路由如果要进标签和 KeepAlive，在 `meta.componentName` 写上与 `defineOptions({ name })` 相同的名字。登录、403、404 继续留在布局外或标 `noTab`。

## 5. 与视觉稿的差异

未使用视觉稿里的 IBM Plex 或任何网页字体。规范 07 的许可证白名单没有 OFL，国内访问 Google Fonts 不稳定，内容安全策略也只允许同源字体。界面使用系统字体：中文优先 PingFang SC、微软雅黑，西文接系统界面字体。等宽字体是 SFMono-Regular、Consolas、Menlo。编号、单号、时间用 `.tcrm-mono`。金额列右对齐并使用 `tabular-nums`（`.tcrm-amount`）。

水印间距 `[140, 120]`、字号 14、透明度 0.08 是在「很低、不挡阅读、旋转约 −20°」下取的值。构建标识是时间加随机串，见 4.9。
