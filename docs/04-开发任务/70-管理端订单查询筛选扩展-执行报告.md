## 主要改动

### 契约（提交 1）

- `docs/03-设计/系统详细设计说明书.md` §6.2 `GET /admin-api/order/orders` 一行：写明 `orderTimeFrom`（含头）/`orderTimeTo`（不含尾）为 UTC ISO 8601、作用于 `crm_order.order_time`、可与支付区间同时使用；`kolKeyword`（≤128）编号不分大小写精确、姓名不分大小写包含（`%`/`_` 转义）、经 `kol.api` 解析、无匹配返回空页、`kolCode` 保留；`refundState`=`REFUNDING`（存在 `refund_status='PROCESSING'` 记录）/`REFUNDED`（存在 `'SUCCESS'` 记录，含部分与整单），`EXISTS` 按 `crm_refund.order_id` 关联、不重复计数、`CLOSED`/`UNKNOWN` 不命中、同一订单可同时命中两个筛选、不并入 `orderStatus`；`abnormal=true`＝`order_status='UNKNOWN'` OR `attribution_status IN ('UNMATCHED','CONFLICT')` 的并集再与其他条件取交集。
- 机读目录 `backend/openapi-order.yaml`：`listOrders`/`listUnmatchedOrders` 增加 `orderTimeFrom`/`orderTimeTo`/`kolKeyword`/`refundState`/`abnormal` 参数定义与说明，版本 1.1.0→1.2.0。

### 后端（提交 2）

- `OrderQuery`/`OrderFilterDTO`：新增 `orderTimeFrom`、`orderTimeTo`、`kolKeyword`（≤128，strip 归一化）、`refundState`（`REFUNDING|REFUNDED` 白名单）、`abnormal`；下单时间区间校验含头不含尾（from < to）。
- `OrderService.page()`：
  - `order_time` ge/lt 过滤，与 `pay_time` 过滤互相独立、可叠加；
  - `kolKeyword` 经 `KolApi.findIdsByKeyword`（姓名包含 + 编号/邮箱精确，已转义，租户隔离由拦截器保证）解析为 ID 集合后 `kol_id IN`，与原 `kolCode` 同样按主单达人过滤，命中范围一致；无匹配直接返回空页；
  - `refundState` 用 `EXISTS (SELECT 1 FROM crm_refund r WHERE r.order_id = crm_order.id AND r.refund_status = …)`，一单多条退款只计数一次；`REFUNDING→PROCESSING`、`REFUNDED→SUCCESS`；
  - `abnormal` 用 `and(w -> w.eq(order_status,'UNKNOWN').or().in(attribution_status, UNMATCHED/CONFLICT))` 作为一个整体并集，再与其他条件 AND。
  - 全部在服务端分页之前生效，`total` 与结果集同一条件。
- 迁移 `V202610261000__index_crm_order_tenant_order_time.sql`：`CREATE INDEX idx_crm_order_tenant_order_time ON crm_order (tenant_id, order_time)`，与既有 `(tenant_id, pay_time)` 索引对称（**超出「原则上不新增迁移」的默认，使用了任务分配的版本号区间，特此报告**；`crm_refund(order_id)` 已有索引，EXISTS 无需新增）。该迁移已随本地联调启动进入共享库。

### 前端（提交 3，只接线，不改 #122 布局）

- `admin-ui/src/api/order/order.ts`：`OrderQuery` 增加 `orderTimeFrom`/`orderTimeTo`/`kolKeyword`/`refundState`/`abnormal`；`api/types.ts` 新增 `RefundFilterState`。
- `admin-ui/src/utils/order.ts`：新增 `orderTimeRangeToQuery`（与 `payRangeToQuery` 同构，含头不含尾）。
- `admin-ui/src/views/order/index.vue`：达人编号输入框改为 `kolKeyword`（maxlength 128，去掉「开发中」tooltip）；下单时间 `datetimerange` 启用（去掉 disabled 与 tooltip）；状态下拉 9 项全部可选（去掉 disabled/「开发中」角标与样式）；`appliedQuery` 映射：6 种标准状态→`orderStatus`，「退款中」→`refundState=REFUNDING`、「退款成功」→`refundState=REFUNDED`、「异常订单」→`abnormal=true`；chips 同步（达人关键词、下单时间区间）。
- 语言包：删除 `kolNameFilterDeveloping`、`createTimeFilterDeveloping`、`createTimeFilterLabel`；新增 `order.kolKeyword`（达人编号/姓名 / Creator code or name）、`order.orderTime`（下单时间 / Order time）。
