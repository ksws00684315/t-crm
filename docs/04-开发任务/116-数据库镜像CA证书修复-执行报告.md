# 116 数据库镜像 CA 证书修复：执行报告

- 分支：`task/116-postgres-ca-certificates`
- 日期：2026-11-06
- 类型：生产上线阻塞缺陷修复（部署）

## 1. 问题

正式环境首次发布（v0.1.0）后，pgBackRest 连接 S3 备份仓库失败：

```
ERROR: [095]: unable to verify certificate presented by
'prod-backup-594711655566.s3.us-east-1.amazonaws.com:443 (…)' : [20] unable to get local issuer certificate
```

`postgres:17.11` 基础镜像（Debian 13）没有安装 `ca-certificates`，镜像内不存在
`/etc/ssl/certs/ca-certificates.crt`，pgBackRest 无法验证 S3 的 TLS 证书。因此 S3 备份与 WAL
归档在 v0.1.0 上不可用（应用本体运行正常）。

## 2. 改动

`deploy/postgres/Dockerfile`：安装 pgBackRest 时一并安装 `ca-certificates`，并加一段注释说明原因。
没有其他代码、配置或依赖变更。

```dockerfile
RUN apt-get update \
    && apt-get install -y --no-install-recommends "pgbackrest=${PGBACKREST_VERSION}" ca-certificates \
```
