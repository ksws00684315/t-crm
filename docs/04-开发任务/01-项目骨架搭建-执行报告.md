### 手动启动的必要配置

因中止前尚未创建 `deploy/`，现有验证清单中第 3 步 Compose 启动、第 6 步前端联调暂不可执行；请先验证现有两个工程，待恢复任务后再补全整个清单。不要假定不存在的 Compose 配置已可使用。

后台配置：`backend/src/main/resources/application.yml`；跳转配置：`redirect/src/main/resources/application.yml`。验证机需自行准备 MySQL 8.4 和 Redis 7，并通过环境变量提供：

| 环境变量 | 用途/默认值 |
|---|---|
| TCRM_DB_HOST | 后台数据库地址，默认 localhost |
| TCRM_DB_PORT | 数据库端口，默认 3306 |
| TCRM_DB_NAME | 数据库名，默认 tcrm；需提前创建数据库 |
| TCRM_DB_USERNAME / TCRM_DB_PASSWORD | 必须自行设置，无默认账号密码 |
| TCRM_REDIS_HOST / TCRM_REDIS_PORT | 两个工程的 Redis 连接，默认 localhost:6379，DB 0 |
| TCRM_REDIS_PASSWORD | Redis 密码，默认空（连接无密码的开发 Redis） |
| TCRM_BOOTSTRAP_ADMIN_USERNAME / TCRM_BOOTSTRAP_ADMIN_PASSWORD | 仅后台首次无超管时使用；不设则警告且不创建 |
| TCRM_ADMIN_PORT | 后台 HTTP 端口，默认 8080 |
| TCRM_REDIRECT_PORT | 跳转 HTTP 端口，默认 8081 |
| TCRM_REDIRECT_FALLBACK_URL | 跳转服务必须设置的 HTTP(S) 提示页 URL |
| TCRM_IP_HASH_SALT | 跳转服务必须设置的非空 IP 哈希盐值 |

在环境变量已加载后用 `java -Duser.timezone=UTC -jar backend/target/crm-admin-0.1.0.jar` 和 `java -Duser.timezone=UTC -jar redirect/target/crm-redirect-0.1.0.jar` 启动。应用 main 本身也设为 UTC，JDBC 强制连接会话 UTC。

登录路径是 `POST http://localhost:8080/admin-api/auth/login`，JSON 为用户名、密码；令牌请求头 `X-Admin-Token`，默认有效期 28800 秒（配置可改）。修改本人密码、重置密码会注销原会话；停用通过踢下线及每请求数据库状态检查使令牌失效。创建/初始化的新密码约束为 10～72 个 ASCII 可打印字符，避免 BCrypt 72 字节截断；验证机自行使用满足条件的密码，不使用任何仓库默认密码。

Compose 语法校验未执行：虽然发现 Docker CLI，但中止后尚不存在两个待校验 Compose 文件。未执行任何容器启动命令。
