## 逐条根因与改动

### 序号 1：报错文字与输入框重叠（P2）

- 根因（改前实测）：`#app .el-form-item__error` 为规范 13 的帮助文字规格 14/22px，但 `.el-form-item__error` 仍是 Element Plus 的绝对定位、行高 24px（22 + 2 padding），而表单项间距沿用 Element Plus 默认 18px。「新增用户」弹窗里每条错误都压住下一个输入框 6px（错误底 308.5，下一项顶 302.5）。
- 改动：`admin-ui/src/style/index.css` 新增 `.el-form-item__error { position: static; width: 100%; }`，错误文字进入文档流并占满整行，表单项自动增高。
- 首版只写了 `position: static`，审查（PR #223 R-1）实测发现非满宽控件（预付「从后续佣金抵扣」单选组）的错误会挤到控件右侧同一行，因为 `.el-form-item__content` 是 `flex-wrap` 容器；补 `width: 100%` 后错误回到控件下方，已在本 PR 修复并补披露。
- 影响面：全部使用 Element Plus 表单校验的地方；错误提示「紧跟所属字段」的规范 13 §4.6 要求因此成立。
- 验收：1440 / 1280 / 390 三档宽度，逐项测量错误底边与下一项顶边，均为 **-18px（不重叠）**；见 `account-create-error-*.png`。
