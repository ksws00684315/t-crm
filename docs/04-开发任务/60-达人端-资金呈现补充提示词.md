# 任务 60：资金明细呈现调整

日期：2026-10-24。负责人在本任务对话中授权调整资金明细页，并确认额外保留独立“提现中”卡片。

参考：[负责人提供的资金明细示意](assets/task-60/funds-reference-20261024.png)。示意图中的重复金额仅作排版示例。

1. 顶部采用蓝色圆角收入汇总区，显示总收入、佣金收入、预付收入及等号/加号。总收入复用 `/commissions/overview` 的 `income.paid`，佣金收入用 `income.commissionPaid`，预付收入用 `income.prepayPaid`；只统计已到账款项，不把预计佣金作为已到账收入。
2. 下方采用蓝色描边圆角卡片，依次显示预计总佣金、已提现、当前可提现、冻结中、提现中。负责人明确选择独立保留“提现中”卡片；预计总佣金复用 `income.estimated`，不从截图数字或不完整状态猜算。只有各状态展示金额严格相等时才显示等号/加号；存在预付抵扣等差异时以状态卡片展示，不绘制错误等式。
3. 保留此前“总佣金金额＝已提现＋提现中＋冻结中”的核对项以及佣金抵扣负数展示；可提现负余额不得截为零。未收到预付为 0。
4. 金额显示小数两位及 CNY；保留中英文、项目字体/间距变量和手机适配。桌面按参考图横向呈现；窄屏重排卡片并隐藏会引起误读或溢出的算符。
5. 保留历史资金记录六列、提现记录、提现申请、账户维护等既有细节。本轮复用既有数据接口和唯一资金模型，不修改后端计佣或提现规则。
6. 在本任务隔离工作树完成类型检查、金额映射回归、双语和多视口浏览器检查，更新截图、执行报告及现有 PR。
