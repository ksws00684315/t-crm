## 2. 逐项结果

### 4.1 订单明细唯一键只约束有效行

- 迁移：`V202610181000__order_item_identity_live_rows.sql`
  - `DROP CONSTRAINT uk_crm_order_item_identity`
  - `CREATE UNIQUE INDEX ... (order_id, sub_order_id) WHERE is_deleted = FALSE`
  - `COMMENT ON INDEX` 中文说明
- **锁表风险**：`DROP CONSTRAINT` / `CREATE UNIQUE INDEX` 在 PostgreSQL 上对表加 `ACCESS EXCLUSIVE`（删约束）与 `SHARE`/`SHARE UPDATE EXCLUSIVE`（建索引，无 `CONCURRENTLY`）。生产窗口建议低峰执行；当前表规模为业务初期，可接受。未使用 `CONCURRENTLY`（Flyway 事务内不便）。
- 集成测试：`OrderImportIT.shouldAllowReinsertingSoftDeletedIdentity_whenPartialUniqueIndexApplies`（导入 → API 同步软删 → 再用软删键插入应成功）。本地无 Docker，以 CI `Backend verify` 为准。

### 4.2 请求格式错误不再返回 500

- 新增 `ErrorCode.COMMON_UNSUPPORTED_MEDIA_TYPE`（415）
- `GlobalExceptionHandler`：`HttpMediaTypeNotSupportedException` → 415；`MissingServletRequestParameterException` 与既有 `HttpMessageNotReadableException` / `MethodArgumentTypeMismatchException` → 400 `COMMON_VALIDATION_FAILED`
- 语言包：`admin-ui` / `kol-portal` 的 zh-CN、en-US 已补文案
- 测试：`GlobalExceptionHandlerRequestFormatTest`（先确认原会落到 500 的路径，再断言新行为）
- 日志不输出请求体

### 4.3 导入模板编号列文本格式

- `ExcelFiles.write(..., Collection<Integer> textColumns)` + `SheetWriteHandler` 设置列默认样式 `@`
- `ImportTaskApi.template(headerKeys, textColumns)` 重载
- 各 `*ImportColumn.textColumnIndexes()`；订单/退款/原商品/对应关系/达人导入服务已接线
- 测试：`ExcelFilesTest.shouldMarkSelectedColumnsAsText_whenWritingTemplate`

### 4.4 集成测试去掉 Thread.sleep

- 新增 `TestWait.until`（测试源码，无新依赖）
- 异步等待（任务完成、邮件到达、锁等待、审计行）改为条件等待
- **保留的 sleep**（旁注原因）：
  | 位置 | 原因 |
  |---|---|
  | `CaptchaLoginIT` Redis TTL 20ms | 必须等过期时间点 |
  | `WeidianIntegrationIT` state/cooldown TTL 20ms | 同上 |
  | `WeidianIntegrationIT` 并发刷新 100ms | 给被动刷新进入冷却等待的时间窗口 |
  | `KolAuthIT` 邮件预算 500ms | 静默限流窗口，无可轮询条件 |
