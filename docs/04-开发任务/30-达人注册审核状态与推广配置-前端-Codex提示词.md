## 2. 管理端

### 2.1 达人列表（04.01、03.02）

- **列**：
  - 达人编号、达人名称、WhatsApp / 手机号、邮箱；
  - 核心社媒平台及 ID；
  - 佣金比例：后面带配置版本号，点击打开推广配置记录；
  - 邀请时间、邀请人（商务）；
  - 审核状态、登录状态、关系状态，分三列显示，各自使用不同颜色的标签。
- **筛选**：关键字（编号 / 名称 / 邮箱）、审核状态、关系状态（含「待更新」）、登录状态（冻结 / 未冻结），以及查询、重置、刷新、分页。
- **行操作**（按权限与状态显示）：
  - 资料编辑；
  - 审核：仅审核状态为「待审核」时显示；
  - 推广配置：仅审核状态为「已通过」时可用；
  - 关系状态；
  - 冻结 / 解冻：沿用账号启停接口，文案改为「冻结 / 解冻」；
  - 手动清理；
  - 上传推广表（26）与认领（25b）保留。
- 点击状态标签的跳转规则：
  - 审核状态为「待审核」→ 审核对话框；
  - 关系状态为「待推广」→ 推广配置；
  - 「推广中 / 无效」→ 推广记录。
- 删除所有对 `promotionStatus`、`displayStatus`、`landingUrl`、`platformTemplateIds` 的使用。

### 2.2 邀请达人（01.01）

- 列表工具栏的入口改名为「**邀请达人**」，显示条件不变（任务 28：商务条件，加上 `kol:register-link` 权限码）。
- 弹窗分两行展示「商务邀请码」（8 位）和「注册链接」，各带复制按钮；保留「重新生成」。

### 2.3 审核对话框（04.02）

- 展示并可编辑：达人名称、手机号与 WhatsApp（都带国际区号）、核心社媒平台、核心社媒 ID、国家、备注。
- 只读：邮箱、达人编号。
- 保存：调用 `POST /review`，成功后提示并返回列表，审核状态变为「已通过」。
- 409 `KOL_REVIEW_ALREADY_DONE` 时提示「该达人已审核」，并刷新列表。

### 2.4 资料编辑

- 沿用任务 28 的字段，增加手机号。
- 邮箱、编号只读。

### 2.5 推广配置（04.03）

- **字段**：
  - 佣金比例（百分比输入，提交时换算成小数）；
  - 达人邀请码：标签写成「达人邀请码（代购平台）」，与商务邀请码区分；
  - 代购平台与地址：多行可增删，每行一个平台下拉框（可搜索，支持 100 个以上选项）和一个地址输入框（https）；同一平台不能重复选择；
  - 跳转平台：只列出已选的平台，只选一个平台时自动选中；
  - 推广表格地址；
  - 备注。
  - 必填规则以 29 提示词 3.4 为准。
- **按钮**：「保存」和「保存并开始推广」。后者依次调用推广配置接口和 `PUT /relation-status`（`PROMOTING`）。
- 422 `KOL_PROMOTION_CONFIG_INCOMPLETE` 时，按 `data` 中的字段名列出缺项（包括 `platformAddress`、`review`），每项都有「去填写」的定位。
- 409 `KOL_REVIEW_REQUIRED` 时提示先审核。
- **推广记录**：显示版本号、生效时间、修改人、改动内容（沿用 25b 的字段对照写法，新增字段要有中英文名称）。

### 2.6 关系状态对话框

- 选项只有「待推广 / 推广中 / 无效」。
- 改为「推广中」的缺项处理与 2.5 相同。

### 2.7 清理（04.01）

- 清理配置页保留现状。
- 新增「清理记录」页签或页面：
  - 列：达人编号、店铺、微店商品 ID、状态（待处理 / 成功 / 失败）、触发方式（自动 / 手动）、原因、失败原因、清理时间、完成时间；
  - 筛选：达人编号、状态；
  - 「失败」行显示「重试」。
- 手动清理：列表行操作打开确认对话框，原因必填，最多 200 字。确认文案写明「会删除该达人在微店的专属商品，无法恢复」。

## 3. 达人端（01.01、02.01）

- **注册页**：
  - 通过链接进入（`/register?code=XXXXXXXX`）时，顶部显示「Invited by {商务显示名}」，商务邀请码自动填入且只读；
  - 从登录页点「Sign up」进入时，没有 `code`，邀请码输入框为空且必填；输入 8 位后调用预览接口校验，无效时提示；
  - 必填：邀请码、账户名、邮箱（含验证码）、密码、确认密码；
  - 选填：手机号、WhatsApp（都带国际区号）、核心社媒平台、核心社媒 ID；
  - 社媒平台与 ID 只填了其中一项时，在前端就提示补全；
  - 429 时提示稍后再试。
- **登录页**：增加「Sign up」入口。
- **个人资料页**：如果展示联系方式，增加手机号。
- 删除「WhatsApp 必填」的前端校验。
