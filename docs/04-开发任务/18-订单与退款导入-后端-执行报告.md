## 3. 订单导入模板与规则

表头键 `import.order.header.*`（中英文）：微店店铺 ID、订单号、子订单号、订单状态、下单时间、支付时间、订单实付（元）、运费（元）、商品 ID、SKU ID、商品名称、型号、数量、明细实付（元）。

处理要点：

1. 逐行按「订单头 + 本行明细」调用 `OrderWriter.save`；同订单多行最终状态与归属以最后一次写完为准。
2. 已存在且 `source = 1`：行失败（`import.order.error.sync-owned`）；`source = 2`：更新；`import_batch_id` 写当前任务 ID。
3. 子订单号为空：稳定键 `line-` + SHA-256(商品 ID + `:` + SKU + `:` + 本文件同订单行序号)，与任务 13 一致。
4. 状态：中文或英文标准名；`raw_status = IMPORT:` + 英文名；时间按北京时间解析存 UTC。
5. 归因与商务快照与任务 13 相同；模板无买家列，`buyer_hash` 为空。
6. 同订单在文件中订单头不一致时，以后出现的行为准。

## 4. 退款导入模板与规则

表头键 `import.refund.header.*`：微店店铺 ID、退款单号、订单号、子订单号、退款金额（元）、发起时间、完成时间。

1. 只写已完成退款：`raw_status = 10`。
2. 退款号已存在：行失败，不覆盖。
3. 订单不存在：行失败。
4. 子订单号能唯一对应明细时写 `order_item_id`，否则为空；写入后重算明细 `refund_amount`。
