## 主要改动

- 店铺页增加编码、名称、渠道筛选及重置、分页、刷新；补充店铺编码复制、源店标记、复制池状态、授权信息、商品/订单/退款接口状态、商品容量及启停状态。
- 增加新建/编辑店铺表单、容量刷新、微店授权入口、源店管理、复制池加入/退出和接口检查操作；源店的加入复制池操作禁用并说明原因。
- 店铺行增加订单与退款同步操作，并按 `ORDER` / `REFUND` 类型调用现有同步 API；相关入口受 `order:manage` 权限控制。店铺写操作只对公司超级管理员开放。
- 令牌生成弹窗按 `copy-channels` 响应显示渠道与容量、可选目标店、商品数量和有效分钟；本地即时检查容量，未指定目标店时省略目标店 ID 以触发自动分配。
- 令牌列表补充目标店名称与编码展示；未分配时显示自动分配。
- 新增/调整 shop、令牌弹窗和列表相关测试，补齐中英文语言包。

## 接口与数据变更

- 新增/扩展管理端 API 封装：店铺分页、复制渠道、复制池状态维护、容量刷新、接口检查、微店授权地址；订单同步支持同步类型；创建复制令牌支持目标渠道、可选目标店、商品数量和有效分钟。
