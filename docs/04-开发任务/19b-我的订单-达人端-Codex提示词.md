## 4. 已定的设计决定（不要自行改变）

### 4.1 接口 `GET /kol-api/orders`

1. **身份**：达人登录（`X-Kol-Token`），达人 ID 与公司只从登录态取。
2. **范围**：`crm_order.kol_id = 本人` 且 `attribution_status = 'ATTRIBUTED'` 的订单。
   - 冲突和未匹配的订单（包括暂存了本人 ID 的 `UNMATCHED`）不显示，等人工确认后再出现；
   - 后续人工改归属到别人后，订单从本人列表消失。
3. **筛选与分页**：支付时间区间（`payFrom` 含、`payTo` 不含，UTC）、标准订单状态；按支付时间倒序；分页 `{items,total,page,size}`，`size` 最大 50。
4. **每行字段**：
   - `orderNo`：脱敏的订单号，前 4 位 + `****` + 后 4 位；8 位及以下只保留最后 2 位；
   - `payTime`、`orderStatus`；
   - `payAmount`（本人明细实付合计，不含运费）、`refundAmount`（本人明细已完成退款合计）；
   - `items`：`itemName`、`skuName`、`quantity`、`payAmount`、`refundAmount`。
5. **不返回**：订单 ID、买家任何信息、店铺、所属商务、归因方式、人工原因、明细的商品 ID。
6. 只读，不写审计。

### 4.2 达人端页面「我的订单」

1. 路由 `/orders`，需要登录。
2. **筛选**：时间（最近 7 天 / 30 天 / 90 天 / 自定义区间，默认最近 30 天；按浏览器本地时区换算成 UTC）、状态。
3. **展示**：
   - 宽屏用表格，可展开明细；
   - 宽度小于 768px 时改用卡片列表，每张卡显示订单号、支付时间、状态、实付、退款，点击展开明细；
   - 375px 宽度下不能横向溢出。
4. **金额**：人民币，前缀 `¥`，两位小数。参考汇率换算不在本任务范围。
5. **状态文字**：中英文语言包，七种标准状态都要有文案。
6. **空状态**：「还没有订单。把你的专属链接分享出去后，订单会显示在这里。」（英文同步翻译）

### 4.4 导航约定（与 15b 共用，不得改动）

达人端顶部导航的菜单项集中定义在 `kol-portal/src/layout/nav.ts`：

```ts
export interface NavItem {
  name: string; // route name
  path: string;
  title: string; // locale key
}

export const NAV_ITEMS: NavItem[] = [
  { name: "Home", path: "/", title: "nav.home" },
  { name: "PayoutAccounts", path: "/payout-accounts", title: "nav.payoutAccounts" }, // 15b
  { name: "Orders", path: "/orders", title: "nav.orders" } // 19b
];
```

- `layout/index.vue` 在页头用水平菜单渲染 `NAV_ITEMS`，375px 宽度下不溢出（窄屏可以只显示图标，或改为下拉菜单）。
- 开工时如果 15b 尚未合并，按同一约定创建这个文件和渲染逻辑，只放「首页」和本任务的一项；合并冲突时保留双方的条目。
- 语言包键 `nav.home`、`nav.payoutAccounts`、`nav.orders` 中英文都要有。

## 6. 测试要求

| 场景 | 期望 |
|---|---|
| 范围 | 只返回本人且 `ATTRIBUTED` 的订单；冲突、未匹配、别人的订单不返回；其他公司同邮箱账号的订单不返回 |
| 字段 | 订单号脱敏规则（含 8 位及以下）；没有买家、店铺、商务、订单 ID；金额只算本人明细 |
| 筛选与分页 | 时间区间边界；状态；`size` 超过 50 被拒或截断（选一种，写进报告） |
| 鉴权 | 未登录 401；管理端令牌不能访问 |
| 页面 | 默认最近 30 天；时区换算；宽屏表格、窄屏卡片；空状态；中英文 |
| 导航 | 菜单项来自 `NAV_ITEMS`；当前路由高亮 |
