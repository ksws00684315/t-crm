## 4. L-079 方案说明

**前提不变**：全列默认显示 + 容器内横向滚动，不重排默认可见列、不取消/延迟固定列、不改横滚口径。

**做法**：

1. 右固定列左侧投影从 10px/16% 加强到 18px/22%，并加 1px 内阴影分隔线，默认位置即可看出右侧还有内容；横向滚动条保持常显（既有）。
2. 固定列左缘增加 24px 渐隐层：背景从透明渐变到卡片底色（表头用表头底色），末端显示「…」。只在 `is-scrolling-left`／`is-scrolling-middle` 时显示；滚动到最右或表格无溢出时隐藏。被遮住的 `¥1000.00` 不再呈现为完整的 `¥1000`，而是在边界处渐隐并带省略号，明确表示仍有内容。
3. 配合 U-007 的悬停全文 tooltip 与 L-080 的金额列最小宽度，减少金额在自身列内被裁。

实测（1440/1280）：`admin-fund-prepays` 被遮的申请时间显示为「2…」，`admin-kol-income` 英文表头显示「Froz…」，不再出现干净的数字前缀。截图见 §7。

## 10. 偏离与原因

- U-043 只做到「表头 Permissions 不再被宽度裁切」；该列仍在 1280 英文首屏之外，需要横向滚动。这与 L-079 的「全列默认 + 横滚」口径同源，不在本任务内通过隐藏列解决。
- legacy 订单列表样式（`legacyOrderStyle`）的 tooltip 保持原行为，未套用「非交互列默认开启」。当前 `admin-ui/src` 内没有页面使用该 prop（仅组件测试覆盖），保留分支是为了不改动 PR #138 独立批准的行为。
- L-079 的边界省略号按行显示，空白单元格在右侧有隐藏内容时也会出现「…」，这是「仍有内容可横向滚动」的统一提示，非数据错误。
- 失败态只在表格没有数据时可见。多数接入页在刷新失败时保留旧行并弹 toast（未清空数据），此时不显示失败块；提示词的目标是「失败落到空态」的场景，保留旧数据的刷新失败不在本任务改变其行为。
