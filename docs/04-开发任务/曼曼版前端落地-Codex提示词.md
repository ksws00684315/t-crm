# 曼曼版已确认规范：前端落地任务

## 目标和边界

按照负责人已确认的曼曼版规范调整管理端与达人端的现有页面。规范见 [PR #137](https://github.com/ksws00684315/t-crm/pull/137) 中的第 13 份规范及相关 ADR；看板规则暂缓。保留 [PR #138](https://github.com/ksws00684315/t-crm/pull/138) 的订单列表呈现，并整合主线新增的达人和商品图片内容。不得修改后端、接口契约、数据库或现有 8890 预览。

## 实施要求

- 从最新主线与订单列表变更建立独立工作树，保留现有工作树和预览。
- 应用已确认的文字层级、颜色、柔和边框、状态和禁用态；适配笔记本时收紧留白但不缩小文字。
- 表格长内容左对齐，其他内容居中，表头与内容对齐；保留订单列表的已确认例外。长文本可通过鼠标和键盘查看，交互元素保持可操作。
- 以卡片组织列表标题、筛选及页面操作；全页表单按组分卡并单列；详情抽屉宽屏双列、窄屏单列，长内容不溢出；长弹窗内容滚动而底部操作固定。
- 保持中英文、权限及业务行为；只处理已有界面，不实现看板。

## 验证与交付

运行两端 lint、类型检查、构建和测试；用独立服务与模拟数据在浏览器验证中英文、桌面与窄屏、键盘及关键页面；记录未覆盖的真实设备及真实接口。检查差异范围、`git diff --check`，记录实施报告并提交 PR，明确规范和订单列表的依赖。
