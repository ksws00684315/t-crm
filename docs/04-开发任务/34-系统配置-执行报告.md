# 任务 34：系统配置执行报告

## 实现范围

新增平台级 `sys_config` 配置覆盖表、注册表与进程内缓存，平台管理员接口和管理端系统配置页；新增只读公开站点配置接口，管理端/达人端标题及品牌读取系统名称，推广表上传地址运行时读取；后端业务使用点改为每次读取当前值；管理端更新跳转回退地址时同步写入 Redis，跳转服务读取并缓存 30 秒，缺失/读取失败时回退环境变量。无覆盖记录时使用环境变量或代码默认值，恢复默认删除覆盖记录并立即刷新缓存。

邀请链接有效期按用户确认采用规范 06 的 72 小时上限（任务表格原写 720 小时）；操作日志保留期下限为 180 天。`sys_config` 为平台级表，不带 `tenant_id`，已加入租户插件忽略清单。新增迁移 `V202610211000` 创建配置表，`V202610211001` 将审计请求参数列改为 `TEXT`，用于完整保存系统配置旧值/新值摘要而不触碰已合并迁移。

## 配置项及使用处

| 键 | 默认值来源 | 主要使用处 |
|---|---|---|
| `site.name` | `SparkTrack` | 公开站点配置、两端标题/品牌、达人邀请与找回邮件 |
| `mail.from` | `TCRM_MAIL_FROM` | `MailConfiguration`、`ResendMailSender` |
| `url.kol-portal` | `TCRM_KOL_PORTAL_BASE_URL` | `KolPortalUrls` 邀请、注册、重置链接 |
| `url.link` | `TCRM_LINK_BASE_URL` | `LinkUrls`、`ProductLinkService`、达人商品链接 |
| `url.admin` | `TCRM_ADMIN_BASE_URL` | `WeidianAdminBaseUrl` OAuth 回调 |
| `url.upload` | `TCRM_UPLOAD_BASE_URL`，空值同源上传 | 管理端公开站点配置、`promo-sheet.ts` |
| `url.redirect-fallback` | `TCRM_REDIRECT_FALLBACK_URL` | 系统配置服务写 Redis；跳转服务读取 Redis / 环境变量 |
| `copy-token.default-quota` | `1` | `CopyTokenService` 创建令牌默认额度；管理端留空传服务端默认 |
| `copy-token.default-valid-minutes` | `1440` | `CopyTokenService` 创建令牌默认有效分钟；管理端留空传服务端默认 |
| `copy-token.max-quota` | `100000` | `CopyTokenService` 创建额度上限；管理端无静态最大值 |
| `copy-token.max-valid-minutes` | `10080` | `CopyTokenService` 创建有效期上限；管理端无静态最大值 |
| `shop.max-per-company` | `3` | `ShopService` 公司店铺数量校验 |
| `payout-account.max-per-kol` | `5` | `PayoutAccountService` 收款账户数量校验；前端由服务端动态规则执行 |
| `kol.invite-ttl-hours` | `72` | `KolInvites` 邀请 token 到期、`KolMailTemplates` 邮件提示 |
| `oper-log.retention-days` | `180` | `OperLogRetentionJob` 清理阈值 |
| `login.fail.pair-limit` | `5` | `LoginFailures` 用户名+IP 失败阈值 |
| `login.fail.ip-limit` | `20` | `LoginFailures` IP 失败阈值 |
| `login.fail.account-limit` | `50` | `LoginFailures` 用户名失败阈值 |
| `login.fail.window-minutes` | `15` | `LoginFailures` 计数窗口 |
| `captcha.issue-per-minute` | `crm.auth.captcha.issue-per-minute`（默认 `120`） | `CaptchaService` 签发限流 |
| `kol.register.ip-per-hour` | `20` | `KolRegistrationRateLimiter` 注册 IP 限流 |
| `kol.register-preview.ip-per-hour` | `20` | `KolRegistrationRateLimiter` 预览 IP 限流 |
| `kol.forgot.email-limit` | `3` | `KolAuthService` 邮箱找回限流 |
| `kol.forgot.email-window-minutes` | `10` | `KolAuthService` 邮箱找回窗口 |
| `kol.forgot.ip-limit` | `20` | `KolAuthService` IP 找回限流 |
| `kol.forgot.ip-window-minutes` | `60` | `KolAuthService` IP 找回窗口 |
| `product-links.ip-per-minute` | `crm.product-links.ip-rate-per-minute`（默认 `120`） | `ProductLinkRateLimiter` 来源 IP 限流 |
| `product-links.convert-token-per-minute` | `crm.product-links.convert-token-rate-per-minute`（默认 `10`） | `ProductLinkRateLimiter` 转换令牌限流 |
| `product-links.resolve-token-per-minute` | `crm.product-links.resolve-token-rate-per-minute`（默认 `120`） | `ProductLinkRateLimiter` 解析令牌限流 |
| `weidian.qps` | `crm.weidian.qps`（默认 `5`） | `WeidianRateLimiter` 动态调整 Redisson 限流速率 |

地址配置校验无路径、无末尾斜杠，要求 HTTPS；允许 `http://localhost[:端口]` 和 `http://127.0.0.1[:端口]` 本地预览地址。公开接口只返回各自约定字段。配置修改与恢复默认都会记录「系统配置 {键}：{旧值} → {新值}」审计摘要；摘要存于操作日志请求参数字段，操作名保留短摘要。
