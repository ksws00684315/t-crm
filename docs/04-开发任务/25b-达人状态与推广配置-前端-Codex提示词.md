## 3. 要做的事

### 3.1 达人编号

- 编号校验改为 `^KOL-[A-Z]{3}[0-9]{3,8}$`（管理端、达人端所有用到的地方），示例与占位文字改为 `KOL-ASD001`。

### 3.2 达人列表（管理端）

1. 新增「状态」列，显示 `displayStatus`：待审核、待推广、推广中、合作结束、待更新，五种颜色区分；可按状态筛选。
2. **点击状态跳转**：
   - 待审核 → 打开审核（编辑资料）界面；
   - 待推广 → 打开推广配置界面；
   - 推广中、合作结束 → 打开达人详情的推广数据（现有详情抽屉中的订单、链接等标签）；
   - 待更新 → 超管打开转移商务对话框（任务 16b）；商务只显示说明。
3. 行操作「修改状态」：选择目标状态，确认后调用 `PUT …/promotion-status`；422 `KOL_PROMOTION_CONFIG_INCOMPLETE` 时提示缺哪些配置，并提供「去填写」按钮打开推广配置。
4. 工具栏「认领达人」（只对可用商务显示）：输入达人编号或邮箱 → `GET /kol/claimable` → 显示找到的达人（编号、名称、脱敏邮箱、状态）→ 确认认领；找不到时提示「没有找到可认领的达人，请核对编号或邮箱」。

### 3.3 审核界面

- 复用现有编辑对话框：邮箱、达人编号只读，其他资料可改；底部「审核通过」按钮在保存后把状态改为待推广（两步：保存资料 → 改状态），任一步失败给出对应提示。

### 3.4 推广配置界面

- 抽屉或独立对话框，字段：
  - 佣金比例（百分比输入，后端存小数，沿用现有 `defaultRate` 的换算）；
  - 代购平台（多选，选项来自本公司代购平台模板）；
  - 落地页地址（https）；
  - 邀请码；
  - 推广表格地址（选填）；
  - 本次修改备注（选填）。
- 「保存」与「保存并开始推广」（保存后改为推广中）。
- 下方「修改记录」：分页列出每次配置与状态修改（时间、操作人、类型、改动字段的前后值、备注）。

### 3.5 清理配置（管理端）

- 位置：达人管理页右上角「清理配置」按钮（数据范围为「全部」且有 `kol:edit` 才显示）。
- 内容：开关、未出单天数（7～365）、说明文字（逻辑删除、商品对应关系一并结束、订单与佣金历史保留）；「预览」列出按当前配置下次会被清理的达人。

### 3.6 达人端

- 注册页：WhatsApp 改为必填。
- 收款账户：PayPal 增加币种（下拉，至少 USD、EUR、GBP、CNY，默认 USD）；卡片显示币种。管理端审核详情显示币种。

### 3.7 语言包

- 所有新文案中英文都有；英文用 Creator 术语（任务 24 的约定，已有测试会检查）。
