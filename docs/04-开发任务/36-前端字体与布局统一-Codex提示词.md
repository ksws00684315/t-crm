# 36 前端字体与布局统一

## 目标

依据 `docs/03-设计/网页字体字号规范.xlsx`、[字体字号规范讨论](https://chatgpt.com/share/6ad730bc-bc80-83e9-9990-b971cb0a9ae5) 和 `docs/05-工程规范/10-前端视觉与布局规范.md`，统一 `admin-ui` 和 `kol-portal` 全部现有页面的字体、字号、间距、布局及响应式规则。

## 实施约束

- 从已提交 `main` 建分支 `task/36-frontend-visual-standard` 独立开发；不覆盖负责人的其他未提交改动。
- 遵守 AGENTS.md 与 `docs/05-工程规范/`。不新增依赖、功能或服务依赖；保持两端独立构建。
- 两端所有字体和间距变量保持一致，由管理端契约测试校验。保留语言包行为、颜色与功能权限。
- 全站统一应用 20／28、16／24、14／22、12／20px 字体层级和 4、8、12、16、24、32px 间距阶梯；桌面控件 32px，手机端目标至少 44px。
- 移除 `DataColumn.mono`、等宽业务文案样式，ID、邮箱、日期与正文使用同一无衬线字体。金额继续右对齐并使用等宽数字特性。
- 达人列表保留 13 列、六个操作及其顺序、权限和禁用规则；恢复可读列宽，固定 ID 与操作列，使用表格容器内横向滚动。
- 按全站页面、组件和复用浮层清单逐项核查局部字号与间距。列表使用容器布局适配高度，不使用与固定页头、页签高度绑定的视口减法。
- 任务 34 系统配置页如未合入本分支，应在其完成后整合其页面与动态站点名称，复验交集后才宣布全部页面验收完成。

## 验收

- 两端执行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm notices:check` 和 `pnpm audit --audit-level high`。
- 浏览器 100% 缩放检查 1440×900、1280×800、390×844、375×812，中英文、已登录身份角色菜单、关键列表、空/长/错误状态、弹窗和抽屉。
- 验证同类文字字体、字号、行高、字重一致；三种表格密度只改变单元格纵向间距；手机交互目标不小于 44px；无页面横向溢出、裁切或重叠。
- 达人列表复核全列、列设置、固定列、六项行操作及既有角色可见/禁用断言。补充截图至本任务报告。
- 提交执行报告，说明范围、主要改动、命令结果、截图位置、遗留和 PR 链接；不要修改开发任务索引，该索引由负责人维护。
