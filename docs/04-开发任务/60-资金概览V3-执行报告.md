## 新口径与原契约差异

| 页面指标 | 数据来源 | 预览数据示例 |
|---|---|---|
| 总收入 | `income.estimated + income.prepayPaid`，BigInt 分钱相加 | 2400 + 100 = 2500 CNY |
| 顶部累计提现金额 | `income.cumulativePaid` | 佣金200 + 收到预付100 = 300 CNY |
| 顶部当前可提现金额 | `income.available` | 2000 CNY |
| 顶部冻结中金额 | `income.frozen` | 200 CNY |
| 佣金概览已提现 | `income.commissionPaid` | 200 CNY，佣金栏不重复计入预付 |

后端 `KolCommissionService.overview()` 的 `cumulativePaid` 明确等于佣金已付加实际收到预付；`prepayPaid` 来源为预付实际付款行，申请/未收到款项不计入。提现底座继续复用主线，无新增台账或双写。

本次总收入定义取代 ADR-032 附录 B 的旧 `totalIncomeCny ← income.paid` 展示映射，系负责人本次明确授权；原已接受 ADR 未改写。佣金概览标题下展示“预估总佣金 = 已提现 + 当前可提现 + 冻结中 + 提现中”。抵扣可能使原始各项出现差额，页面不根据公式反算或覆盖后端金额，仍以负数小字保留佣金抵扣；独立“资金说明”区已删除。
