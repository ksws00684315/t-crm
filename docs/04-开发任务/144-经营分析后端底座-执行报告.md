## 接口交接

| 用途 | 方法和路径 | 返回 |
| --- | --- | --- |
| 总览 | `GET /admin-api/stats/overview` | `data.meta`、`summary`、`previous`、`change`、`unavailable` |
| 示例店铺排行 | `GET /admin-api/stats/shop-performance` | 同级 `meta`、`summary`、`previous`、`change`、`ranking`、`unavailable` 和生效排序。店铺数、有成交店铺数及经营指标在 `summary` 中。 |
| 导出 | `GET /admin-api/stats/shop-performance/exports` | 当前页 XLSX。需要店铺看板和导出权限。 |

日期参数为 `startDate` 与 `endDate`，筛选参数为 `shopId`、`kolId`、`inviterId`、`channel`。排行追加 `page`、`size`、`sortBy` 和 `sortDirection`。示例 `?startDate=2026-11-03&endDate=2026-11-09&page=1&size=20&sortBy=skuCount&sortDirection=asc`。比例为小数比率，金额与长整型沿用项目的字符串序列化。环比与退款率分母为零时返回 null。

## 性能与运行记录

- Linux Docker 全量运行中的规模样例测得 MyBatis 总览单区间查询 159 ms、达人分组 457 ms。`EXPLAIN (ANALYZE, BUFFERS)` 分别为 181 ms 和 612 ms。测试租户占样本绝大部分，规划器对 90 天全量数据选择顺序扫描及哈希连接，达人分组的外部排序落盘约 4 MB 和 8 MB。窄范围仍可用既有的租户支付时间索引及退款订单关联索引。样例以订单和商品行为主，退款边界另由手算数据覆盖。耗时包含本机数据库查询与映射，未包含前端或线上网络。
- 测试使用隔离的 PostgreSQL 容器，按实际 Flyway 脚本迁移。未对共享中间件执行迁移或写入测试数据。
