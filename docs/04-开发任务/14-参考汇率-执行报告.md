# 任务 14：参考汇率执行报告

> 分支 `task/14-fx-reference-rate`（基于 main `c9f9eb0`）。本任务没有提示词文件，需求来自架构师的任务说明；设计依据为设计说明书 §0.2 D11、§3.4 第 1、4 项、§5.2 `crm_fx_rate`、§7.5、§9。

## 执行结论

后台每小时第 30 分（UTC）从欧洲央行拉取每日参考汇率，换算为"1 人民币兑多少美元"存入平台级表 `crm_fx_rate`，同一日期只存一次；`integration.api.FxRates` 供后续任务（达人端钱包等）读取最新汇率并折算美元参考金额。只做后端，没有新增 HTTP 接口、依赖和环境变量。本地 `mvn spotless:apply`、`mvn -B verify`、`mvn -B verify -Pdocker-it`（JDK 21）全部通过。

## 数据源与解析

`integration.service.EcbRateClient`：

- JDK `java.net.http.HttpClient`，连接与请求超时均为 10 秒；地址为 Spring 属性 `crm.fx.ecb-url`，默认 `https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml`（写在 `application.yml`，不是环境变量）。非 200、网络异常、超时都转换为本模块的 `EcbFeedException`（英文短消息，可安全写日志）。
- JDK DOM 解析器按 OWASP XXE 防护加固：禁止 DOCTYPE（`disallow-doctype-decl`）、关闭外部一般实体与参数实体、不加载外部 DTD、`ACCESS_EXTERNAL_DTD/SCHEMA` 置空、安全处理开启、不展开实体引用；替换默认错误处理器，避免解析错误打印到 stderr。响应超过 64 KB 直接拒绝（实际文件约 2 KB）。
- 取第一个带 `time` 属性的 `Cube` 为日期，在其下读取 `USD` 和 `CNY`（均为每 1 欧元）。人民币兑美元 = USD ÷ CNY，`BigDecimal` 保留 8 位小数，`HALF_UP`。
- 缺日期、日期格式错误、缺 USD 或 CNY、汇率非数字或不大于 0、非法 XML（含 DOCTYPE）一律拒绝：记 `WARN`，不写入。

## 定时任务

- `integration.service.FxRateFetchJob`：`@Scheduled(cron = "0 30 * * * *", zone = "UTC")`，Redisson 锁 `fx:fetch`，不等待（另一实例持锁时本次跳过），在系统范围执行并写明原因（设计 §3.4 第 4 项：平台级数据，不读写任何公司的数据）。
- `integration.service.FxRateService#update`：拉取 → `INSERT ... ON CONFLICT (rate_date) DO NOTHING`（该日期已入库则什么都不做，新入库记 `INFO`）→ 检查最新日期，早于"当天（UTC）− 7 天"或表为空时记 `WARN`。拉取、解析、数据库失败都只记英文 `WARN`，不向外抛出；下一小时自然重试。
- 设计说明书 §7.5"拉取"条与 §9 表格的"每日 16:30 + 失败每小时重试"已改为"每小时第 30 分，未入库才写入，失败下一小时自然重试"（按任务说明）。

## 供后续任务使用的接口

```java
// com.tcrm.admin.integration.api
public interface FxRates {
  Optional<FxRateDTO> latest();   // 最新一条；没有任何汇率时为空（达人端只显示人民币）
}
public record FxRateDTO(LocalDate rateDate, BigDecimal rate) {
  public BigDecimal toUsd(BigDecimal cny);   // cny × rate，四舍五入（HALF_UP）到 0.01 美元
}
```

- 实现类 `FxRateService`。`FxRateMapper` 整个接口标注 `@InterceptorIgnore(tenantLine = "true")`：表没有 `tenant_id`，在公司范围（如达人端请求）读取时不能追加公司条件，否则 SQL 报错；该表不含任何公司数据，因此不属于"绕开公司过滤读取公司数据"。集成测试覆盖了在公司范围内读取。
- 没有新增 HTTP 接口（达人端钱包接口在后续任务中实现）。
