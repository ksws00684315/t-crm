# 126 停用 SparkTrack 中转模板：执行报告

- 分支：`task/126-disable-relay-template`
- 日期：2026-11-07
- 类型：临时功能开关（后端，无迁移）

## 1. 背景

负责人 2026-11-07：客户暂时不需要中转链接，要求把表格脚本模板下拉里的
「SparkTrack 中转」停用。

## 2. 改动

| 文件 | 改动 |
|---|---|
| `backend/.../product/service/ProductLinkService.java` | 注释 `templates()` 中内置中转模板的 `out.add(...)` 块，保留原码与恢复说明（负责人决定，临时停用） |
| `backend/.../product/service/ProductLinkServiceTest.java` | 用例改名 `shouldListTemplates_withoutRelayAndDedup`，断言只剩公司模板；与中转 URL 相同的公司模板仍被去重 |
| `backend/.../product/controller/ProductLinkControllerTest.java` | 用例改为透传公司模板，断言 `data[0]` 为 kakobuy |
| `backend/.../product/ProductLinkIT.java` | 用例改为 `shouldReturnTemplates_withoutTheRelayTemplate`，断言 `data` 为空（测试库无公司模板） |

`TCR_TEMPLATE_CODE` 常量保留（恢复时使用）；去重集合仍包含中转 URL，防止公司模板把中转地址
配成平台模板后重复出现在列表里。

## 3. 影响范围

| 对象 | 影响 |
|---|---|
| 表格脚本「选择平台」下拉 | 不再出现「SparkTrack 中转」，只显示 `crm_link_template` 中启用的平台模板 |
| 已写入表格的 `https://t.<域名>/i/...` 链接 | 不受影响，跳转服务与 `/i/` 路由未改动 |
| 达人端「我的商品」的 `transitUrl` | 不受影响（`KolPortalItemService` 仍按 `url.link` 生成） |
| 复制流程 | 不受影响：`convert` 与复制任务未使用该模板列表 |
