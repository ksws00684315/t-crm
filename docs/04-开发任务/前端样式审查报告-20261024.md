### P0

**R-01 管理端「商品任务」结果列失败计数不可读，失败提示溢出行外**

- 端：管理端
- 位置：`admin-ui/src/views/product/copy-job/index.vue:88`（`result` 列 `minWidth: 280`）、`:291-311`（结果单元格模板）、样式 `:404-416`；截图 `docs/04-开发任务/assets/task-38/copy-jobs-1440-zh-data.png`
- 表现：1440 宽截图中，「总数 / 成功 / 失败」三个标签只剩色块残影，文字不可辨认；`t38_completed` 行的「含失败项，请查看明细」红字浮在行与行之间，撑出额外高度。失败数是该页最关键的信息，读者无法判断任务是否有失败项。
- 改进建议：结果列改为纵向两行或「成功 X / 失败 Y」一行文本加图标，失败数用文字色而非整块标签；提示文字放到结果列内部并限制在单元格高度内；列宽用 `minWidth` 保证三段文字完整显示。
- 需浏览器复核：截图可能受缩放影响，需在 1440×900 实测。
- 遗留关联：无。

**R-03 商品任务页只在挂载时读取 `jobCode`，已打开的页签不会重新筛选（需浏览器复核）**

- 端：管理端
- 位置：`admin-ui/src/views/order/chain/index.vue:66-68`（`openCopyJob` 推送 `/product/tasks?jobCode=`）；`admin-ui/src/views/product/copy-job/index.vue:213-219`（只在 `onMounted` 读取）；`admin-ui/src/utils/tabs.ts`（同一路径只保留一个页签，查询串不参与身份判断）。

## 4. 调用链路展示评估

链路：商品任务 → 达人商品（链接编码）→ 订单查询 / 订单详情 → 订单链路 → 退款查询 / 退款详情 → 人工匹配池「查看依据」→ 同步监控；达人列表 → 达人商品 / 推广配置；店铺管理 → 令牌 → 商品任务。

1. **商品任务 → 达人商品（链接编码）**：现状无跳转。任务明细只显示 `linkCode` 文本并可复制（`copy-job/index.vue:282`）。达人商品页（`product/kol-item/index.vue`）不读取 `route.query`，无法按链接编码定位。建议：链接编码改为可点击，跳转到达人商品并带 `linkCode` 参数，目标页读取参数（与 R-02、R-03 同一模式）。

2. **达人商品 → 订单查询**：现状无跳转。订单查询（`order/index.vue`）的筛选项没有链接编码或达人条件，无法从达人商品追到订单。建议：达人商品的「查看」抽屉增加「相关订单」入口，携带达人编号或链接编码。

3. **订单查询 → 订单链路**：`window.open` 新标签页（R-17）。链路页内容完整，但与页签系统脱节，返回路径不清晰。

4. **订单链路 → 退款**：链路页的退款表（`chain/index.vue:178-190`）行不可点击，无法进入退款详情。L-003 已记录该表的横向滚动和截断。建议：退款单号改为链接，跳转退款查询并携带 `refundNo`。注意退款查询页（`refund/index.vue`）目前只有本地筛选状态，没有读取 `route.query`，需要补上。

5. **退款查询 → 退款详情**：退款行的「原订单号」有按钮（`refund/index.vue:308-312`，`data-test="refund-order-link"`），但源码中未找到对应的跳转代码，行为待确认。若只是打开抽屉，建议文案改为「查看订单」以免误导；若是跳转，应在报告中补充目标。

6. **人工匹配池「查看依据」**：`MatchEvidenceDrawer.vue` 的达人/链接列表列宽较窄（`valid` 固定 300），在 1440 宽下未核对，需截图验证。依据抽屉与订单链路信息有重叠（达人、链接编码），建议共用 `DetailDescriptions` 与 `EntityLabel`（R-15、R-19）。

7. **同步监控 → 系统任务**：跳转未定位（R-02）。

8. **达人列表 → 达人商品 / 推广配置**：达人列表的行操作（资料编辑、审核、佣金信息、预付金额、清理配置、冻结）已完整直接显示（ADR-029），但没有到达人商品的入口。达人商品页的「达人」筛选支持名称、编号、邮箱，建议达人列表增加「查看商品」入口并带达人编号。

9. **店铺管理 → 令牌 → 商品任务**：店铺行操作（拉订单、拉退款、设为源店铺等）与令牌页（`product/copy-token/index.vue`）之间没有跳转；令牌页与商品任务页之间也没有参数衔接。建议：令牌页的店铺列可跳转到店铺管理并带店铺编码；商品任务页的目标店铺列可跳转到店铺管理。

**同一实体在不同页面的展示**

- 店铺：订单、退款、达人商品用「名称（编码）」，店铺管理用分列显示编码与名称，格式不统一；编码均未做到不断行（R-05）。
- 达人：订单与退款用「名称（编码）」（按语言切换括号），达人商品英文界面硬编码全角括号（R-09）。
- 订单号、退款单号、链接编码：有的带复制图标，有的没有（退款列表的退款单号在窄列中图标被挤出，商品任务的长任务编号无复制图标）。建议统一使用 `CopyText` 或 `EntityLabel`。
