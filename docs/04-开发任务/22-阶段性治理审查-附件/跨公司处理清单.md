### 重点项摘要

- **AccountStoreService / PlatformService**：`sys_user` 始终忽略；读写均带显式 userId / tenantId；平台查找用户名为精确匹配（`PlatformService.java:164-176`），无枚举接口。
- **UserService.companyCounts**（`:246-256`）：系统作用域只返回计数；ids 来自本租户成员分页。
- **ShopService:63**：系统作用域查微店店铺 ID 全局唯一；不返回他公司店铺内容。
- **ImportTaskService**：先系统读任务 `tenant_id`，再 `runCompany` 执行。
- **ClickConsumer**：系统作用域批量写入，但 `setTenantId(ref.tenantId())`（`:193`）。
- **OrderSnapshotCorrection**：系统枚举公司 → 各公司 `runCompany` 更新。
- **KolSelfRegisterService**：公开解析注册码后进入码所属公司；系统作用域不写入业务行（除码查询）。
- **系统作用域写入**：审计 / 引导 / 令牌 / 达人账号状态 / 任务清理等均对 DO 显式设置或按主键更新；未见「系统作用域批量 insert 业务表却未设 tenant_id」的路径（静态阅读，**可信度：文档或源码确认**；隔离 IT 本机未跑 Docker）。
