# 任务 144 执行报告：其他达人专属商品可作复制源

## 1. 背景与现象

- 2026-11-10 02:30 UTC，正式环境复制任务 `c8VyJKKgUynknUfo10iEiQ`（达人 Gabriel / KOL-KEB004，目标店铺 XD）共 2207 条明细，2206 条失败，错误全部为「该商品是其他达人的专属商品」。
- 只读排查（`crm_copy_job_item` 与 `crm_kol_item` 关联）：2206 个来源 ID 全部是达人 tiaozi（KOL-YPG003）在 XD 店内的有效专属商品映射（均挂有原商品，原商品位于已停用的楠枫1店）。
- 客户口径：现在只用一个店铺（XD），店内商品已尽数是达人专属商品，新达人复制只能以这些商品为源；任务 17b「专属商品不作原商品复制」的判断（`CopyJobWorker` 命中其他达人映射即判失败）使复制无法进行。负责人经飞书确认按本任务方案修改。

## 2. 方案（ADR-019「2026-11-10 修订」）

命中其他达人的有效专属商品映射时：

- 映射挂有原商品（`product_id` 非空且原商品未删除）：以这件专属商品本身为物理复制源，为新达人复制出全新 ID，新映射登记到原商品（`source=COPY`），额度照扣；目标达人已有同一原商品的有效映射时沿用原规则返回已有 ID、不扣额度。
- 映射未挂原商品或原商品已删除：仍判失败，提示改为「该商品是其他达人的专属商品，且缺少原商品对应关系，无法复制」。
- 「专属商品不登记为原商品」互斥不变，不把专属商品 ID 写入 `crm_product`，原达人的映射与订单归因完全不变。
