## 4. 主要改动

### 4.1 后端（`kol` 模块）

| 文件 | 改动 |
|---|---|
| `kol/controller/KolController.java` | 新增 `POST /admin-api/kol/kols/{id}/password-reset`：`@SaCheckRole("SUPER_ADMIN")` + `@AuditLog(module="KOL", action="Reset password")`，返回 `R<ResetKolPasswordVO>` |
| `kol/controller/ResetKolPasswordVO.java` | 新增：一次性明文应答 `record ResetKolPasswordVO(String password)` |
| `kol/service/RandomPasswords.java` | 新增：16 位随机密码（`SecureRandom` 逐位取值无取模偏差；字母数字去易混淆字符 `0 1 O I L l i o`，满足密码规范 10～72 位可打印 ASCII） |
| `kol/service/KolService.java` | 新增 `adminResetPassword(Long id)`：`requireVisible`（404 / OWN 越权 403）→ 未激活 422 → 事务内 `scoped(id,user)` 更新 `password_hash`（BCrypt）+ `credential_version+1` + `update_by/update_time`，`requireUpdated`，`KolAuthTokens.invalidateUnused(id, PURPOSE_RESET)` 作废未用自助重置链接 → 事务外 `StpKolUtil.logout(id)` 注销达人全部会话 → 返回明文 |
| `shared/ErrorCode.java` | 新增 `KOL_NOT_ACTIVATED(422, "KOL account is not activated")` |

安全要点：明文只在本次响应返回一次；操作日志只记路径入参（`AuditAspect` 不序列化响应体），`AuditSanitizer` 对含 `password` 的键脱敏兜底；应用日志不打印明文。多公司同邮箱达人各公司独立密码（ADR-014），本接口只影响当前公司行。ADR-038 版本拦截：`KolController` 未标注 `@EditionScope`，仅分销完整版可达，符合功能定位。
