## 四页筛选区两行布局

按确认的两行设计稿更新四页公共筛选组件。第一行为时间快捷项和日期选择。第二行为店铺、渠道下拉框，达人关键词输入及查询、重置。窄屏允许控件换行。

| 验收项 | 验证 |
| --- | --- |
| 四页布局与操作 | Edge 用接口样例验证 1440、1280、390 px 共 12 组页面组合。检查两个下拉框、达人输入框、日期区与条件区分行、查询及重置。桌面验证查询按钮与达人输入同行，验证自定义日期选择器未超出筛选卡。 |
| 达人搜索 | 服务端支持精确匹配系统 ID 和达人编号、按姓名包含匹配。空白取消筛选，未匹配返回空结果。关键词写入已生效条件，并沿用到详情和导出。 |
| 数据范围 | 在 PostgreSQL 验证达人匹配列表分别约束商品排行和订单明细，空匹配列表返回空结果。既有公司和归属条件同时生效。 |

后续微调将店铺、渠道、达人统一为等宽，时间与条件两行的垂直间距由 12 px 调为 16 px。生产构建通过，在四页的 1440、1280、390 px 共 12 组浏览器场景实测宽度与间距。

筛选区的时间段、条件、店铺、渠道和达人标签统一采用正文色。时间快捷按钮使用常规字重，选中态继续用颜色区分。

## 达人排行四张指标卡

| 卡片 | 口径与显示 |
| --- | --- |
| 有销售达人／有效达人 | 支付成交达人按所选期间去重。有效达人按期间内曾启用去重。迁移前状态无法追溯，选定范围的历史不完整时显示横线，悬停解释。小字显示截至查询时已关联商务的达人数，选定店铺时使用在该店有过历史成交的达人。 |
| 订单数／销量 | 使用相同业务条件内的支付订单及购买件数，小字为成交 SPU（同店原 SPU 去重）和平均订单价（销售额 ÷ 去重支付订单数）。 |
| 净销售额 | 保留支付日起 30 个北京时间自然日内完结的同批退款窗口。小字对照支付销售额和同批成功退款。 |
| 达人总佣金 | 按同一支付期间、权限与业务筛选汇总已核实订单的 CNY 佣金快照。扣回取同批订单钱包已入账扣减中能核实为成功退款导致的金额，按正数展示。归属转移冲销不计入，原因无法核实则金额拆分显示横线。无佣金权限时不查询或返回金额。 |

确认后的「关系达人」与「佣金扣回」仍待其他位置口径确认后统一补入名词表。
