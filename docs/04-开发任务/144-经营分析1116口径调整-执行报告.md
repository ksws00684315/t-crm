## 同店商品链接合并

畅销榜按店铺和已识别的同款商品分组，汇总原链接和复制链接的销量、销售额及可归到商品的退款，并按支付订单去重。SPU ID 取本店原链接 ID。本店没有原链接时，取本店最早确认的关联链接，历史关联记录缺失时可以使用最早有原商品归属的支付记录。尚未识别关联的链接按各自的微店商品 ID 统计。

店铺抽屉的订单商品和成功退款保留原有的明细粒度，使用与排行一致的 SPU ID。商品筛选按同店商品分组应用，店铺成交 SPU 数对同店已关联链接去重。

验收通过 37 项后端测试（含 PostgreSQL 和架构检查）、14 项前端测试及前端生产构建。Edge 验证桌面和移动宽度的商品及退款明细 SPU 显示和悬停口径。PostgreSQL 回归覆盖三条同店链接合计、跨店各自的 SPU ID、同名未关联链接单列及商品筛选。
