# 管理端工作台执行报告

开发工作树位于「代码核对/实现-管理端工作台」，分支为 `task/admin-workbench-on-analytics`，以已包含经营分析页面和统计查询的任务 144 分支 `a2f280f3` 为基线。

## 逐项复核

| 需求 | 实现与核对 |
| --- | --- |
| 管理端首页与响应式 | 将 `/home` 欢迎页升级为工作台。沿用现有后台外壳和语言包。普通桌面每行两张指标卡，内容宽度不足时单列。下方安排摘要条、排行、达人与店铺概况、三类待办。 |
| 今日交易与排行 | 按北京时间支付期取数，使用已确认达人归属的行实付，订单在范围内去重。两张排行按销售额降序取前五，进入经营分析时携带同一日期、排序和分销范围。 |
| 当前资源 | 链接与复制口令使用源业务有效状态。容量汇总可见启用店铺的商品位快照，剩余位按店分别取非负后求和。快照缺失时显示不可用。 |
| 队列与跳转 | 达人按待审核查，邀请人取自注册首次归属记录。复制任务含失败和部分失败，按完成时间取最近记录。提现按账号可处理的审核及付款环节取数。四个待办入口沿用首页的过滤条件。 |
| 金额与权限 | 接口从登录态确定公司及权限。今日预估佣金使用已核实的商品行佣金快照，任何应计行缺失可靠快照时显示暂不可用。提现仅返回列表所需字段，付款账号可访问对应任务。 |
| 刷新与异常 | 首载骨架、局部不可用及真实零值分别显示。失败刷新保留当前账号的最近成功结果，账号变化后清空旧结果，较早请求的响应作废。 |
| 验收证据 | 管理端类型检查和生产构建通过。路由、视觉令牌、资金、商品与达人页面的相关回归共 125 项通过。Edge 使用接口样例核验 1440、1280、600 像素视口、两张排行和四个待办入口的请求参数，并验证刷新失败保留旧数据、真实零值和局部不可用。 |

前端全量回归出现超时。店铺权限按钮、达人库首页用例单独复跑通过。达人库表单的删除权限用例在工作台分支和未修改的任务 144 基线均触发 5 秒超时。

## 接口联调

`GET /admin-api/workbench/overview` 使用管理端统一响应。返回 `businessDate`、`asOf`、按权限可见的指标与队列及 `unavailable` 字段。队列分别返回 `total` 和最多五条 `rows`。如无工作台相关业务权限，则显示基础首页。

后端 113 项定向测试通过，含接口权限架构检查与独立 PostgreSQL 对账。数据库样例复核了支付日边界、租户与商务隔离、商品行实付、订单去重，以及佣金快照缺失、未结算、已结算三种结果。正式库的历史归属、容量同步覆盖范围和已核实佣金快照覆盖情况由联调人员核对。待处理提现的组合过滤用于队列查看和处理，单状态仍可沿用现有导出入口。
