## 主要改动

1. **ADR-032（新增）**，14 条决定：
   - 余额唯一来源：`crm_commission_wallet` / `crm_commission_ledger`（任务 47A），新表不存余额；台账 `entry_type` 扩展为 `COMMISSION_CREDIT`（正，经 `postCommissionCredit` 自动按 #105 FIFO 冲抵预付）、`COMMISSION_ADJUSTMENT`（负，释放后差额）、`PREPAY_DEDUCT`（不变）、`COMMISSION_WITHDRAWAL`（付款核销），`source_key` 约定成文；显式否决 #116 绕过预付冲抵的带符号过账做法。
   - 商品行级计佣来源快照（`crm_commission_item_state` + `crm_commission_item_revision`，语义 `WEIDIAN_COMMISSIONABLE_CNY`）；核实三条件（语义、归属 1/2、支付时比例），未核实不计提、不释放、不可占用。
   - 佣金比例沿用推广配置版本（`crm_kol_promotion_record` 的 `version_no` / `effective_time` / `after_json.defaultRate`），**不建** #116 的达人比例版本表；上线基线与「补设不追溯」口径成文。
   - 结算配置版本表 `crm_commission_rule_version`（币种、最低提现额默认 200、渠道冻结天数 0～365，按支付时版本快照；版本化理由：释放时间取决于支付时规则）。
   - 释放依据五值（`CONFIRMED` / `FALLBACK` / `UNSETTLED` / `AFTER_SALES` / `UNVERIFIED`）与退款阻断联动（`paused` / `RESUMED`）。
   - 提现占用：钱包层（余额 − 活跃占用）与商品行层（已释放 − 全部占用含已付）两级校验；按 `release_at, order_item_id` 先进先出分配；申请时固化行级与**订单级**剩余快照（新增 `crm_commission_withdrawal_order`，满足 #112「禁止以求和代替订单级历史快照」的要求）。
   - 状态机 `PENDING_REVIEW` / `PENDING_PAYMENT` / `PAID` / `REJECTED` / `WITHDRAWN` + 驳回重提 `previousId`，不设提现二级审核。
   - 付款登记幂等（UUID + 指纹，一单一次，金额必须等于申请额，非 CNY 必填换算说明，凭证必填）；已付记录永不改写，修正差额走台账（10.02）；待办按达人当前商务实时计算、已完成审批保留操作人快照（07.05）。
   - 权限：新增 `withdrawal:pay`（FUNDS 组，财务模板默认携带）；编号 `W`+北京时间日期+6 位序号；通知类型 `WITHDRAWAL_SUBMITTED/APPROVED/REJECTED/PAID`；8 个新错误码。
   - 附录 A / B：#112、#116 前端字段逐条对照（含无对应字段的处理方式）。
2. **设计说明书**：§4.8 改写为正式流程（计佣冻结、释放与余额、申请、审核付款、差额、冻结提现六个小节）；§5.1 ER 图更新；§5.2 新增 8 张表定义（快照、修订、规则版本、提现申请、订单级占用、行级占用、付款事实、历史），`crm_commission_entry`、`crm_withdrawal` 旧草案显式废止，`crm_commission_ledger` 类型扩展说明；§6.2 管理端佣金/财务任务/提现接口整组重写；§6.3 达人端概览、流水、提现条件、收款选项、提现申请/详情/撤回接口新增，订单接口扩展结算状态；§8.3/§8.4 计佣与提现规则按契约重写（§0.2 D6 同步废止「明细实付」口径）；§9「佣金转可提现」改为「佣金释放」（每 5 分钟，含阻断重算），钱包核对口径更新；§13 增加「61 佣金与提现契约」摘要节。

## 偏离与原因

1. **11.03 结算配置修改限定仅超管**（需求原文「支持授权人员修改并保存」）：沿用 #116 与预付「资金配置超管专属」的口径（§3.1 超管专属清单），授权粒度未来可通过拆分权限码放开；ADR-032 §4 未单列理由，在此补记。
2. **07.05 预付待办不随转交移动**：预付申请人锁定是任务 47 已合并的行为（§4.13 第 7 条），本契约只承诺提现与收款账户待办随达人归属移动；07.05 原文将三类并列表述，实际按既有规则分流。
3. **13.01 导出按类型拆分**：提现导出（`withdrawals/export`）与预付导出（既有 `prepays/export`）各为同步流式 CSV，未提供合并的「财务任务」导出；列表页可分别导出，口径与权限（`data:export` AND）一致。
4. **`actual_amount NUMERIC(20,6)`** 偏离「金额 NUMERIC(14,2)」通用口径：非 CNY 实付（如 USDT 数量）保留来源币种精度，已在 §5.2 注明。
