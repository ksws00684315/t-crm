## 4. 安全发现

### 4.1 总体结论

- **未发现**可直接判定的跨公司数据泄露 P0（静态阅读 + 既有 `TenantIsolationIT` 存在于仓库；**本机未跑 Docker IT**，故隔离 IT 结论 defer 给 CI）。
- 平台管理员：`AccountDTO.effectivePermissions()` 对非 `STAFF`/`SUPER_ADMIN` 返回空；业务接口多用 `@SaCheckPermission` / 公司角色，平台账号应被拒。平台接口集中在 `/admin-api/platform/**`。
- 公开端点 11 个（登录/验证码/达人注册激活找回/微店 OAuth callback），与 `SecurityConfiguration` 排除路径一致；微店 callback 使用一次性 Redis `state`（格式校验 + getAndDelete）。
- `${}` 仅见于点击日志分区 DDL，`ClickPartitions` 白名单表名/日期；注释写明不可绑定参数。**非用户输入直达**。
- Google Sheets：`spreadsheetId` 正则约束；请求基于配置的 `baseUrl` + path expand，降低任意 SSRF 面。
- 跳转服务：`httpUri` 仅允许 http(s)、要求 host、拒绝 userinfo；目标来自 Redis 索引而非用户查询参数直跳（开放重定向面可控，符合 ADR-012 方向）。
- 上传：收款二维码按文件魔数识别 png/jpeg，上限 2MB。
- 导出 CSV：`sanitizeCell` 防公式注入；后端 Excel 写出亦有转义。
- 机密：默认 `crm.mail.log-links: false`；`TCRM_SECRET_KEY` / `TCRM_IP_HASH_SALT` 空则启动失败。镜像 `USER 10001`。Nginx 有 TLS、HSTS、CSP（web）、登录/验证码/跳转限流。
- 密码策略：长度 ≥10 且可打印 ASCII，**无**大小写/数字/符号复杂度要求 → P2。
- 权限码变更：`PermissionChangeApplier` 不 kick 令牌；权限每请求从库加载，缩权/扩权下次请求生效（可接受；若需强制重登可另议）。
