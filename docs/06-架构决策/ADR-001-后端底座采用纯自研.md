# ADR-001 后端底座采用纯自研

- 状态：已接受（2026-10-04）
- 决策人：项目负责人

## 背景

后台需要登录、角色权限、数据隔离、操作日志等基础能力。曾计划使用 RuoYi-Vue-Plus 6.0 脚手架。

## 决定

不使用后台管理脚手架。后端基于 Spring Boot 4.1 + Sa-Token + MyBatis-Plus + Flyway + Redisson 自行实现基础设施；管理端前端基于 pure-admin-thin 精简模板。

## 备选方案及放弃原因

| 方案 | 放弃原因 |
|---|---|
| RuoYi-Vue-Plus 6.0 | 本项目角色固定为 4 个，不需要动态菜单与按部门的数据权限；脚手架带大量用不上的模块；6.0 刚发布，基于改动较大的 Spring Boot 4，兼容风险高；项目负责人优先要求代码完全可控 |
| RuoYi-Vue-Plus 5.x | 基于 Spring Boot 3.5，官方免费支持已于 2026-06-30 结束 |

## 影响

- 骨架阶段多投入约 3 天实现基础设施。
- 安全相关代码（认证、令牌、越权）由本项目自行负责，须按规范 06 与 05 的必测清单覆盖测试。
