# ADR-020：参考汇率表 `crm_fx_rate` 不带公司字段

- 状态：已接受（2026-10-16）
- 决策人：项目负责人（设计说明书 §3.4、§7.5 修订时确认）
- 相关：[ADR-014](ADR-014-多公司采用共享库与公司字段隔离.md)（业务表必须带 `tenant_id`，新增例外须写 ADR）

## 背景

达人端要在人民币金额旁显示美元参考金额（设计 D11、§7.5）。汇率取自欧洲央行每日参考汇率，各公司相同，与任何公司的业务数据无关。

## 决定

1. `crm_fx_rate` 是平台级参考数据，不带 `tenant_id`，列入设计说明书 §3.4 的例外清单。
2. `shared.CompanyTenantLineHandler` 始终忽略该表，与 `sys_tenant`、`crm_link_index_outbox` 一样；公司范围内的请求可以直接读取。
3. 写入只由系统范围的拉取任务进行（`FxRateFetchJob`，代码中写明系统范围的原因）；没有任何接口可以修改该表。

## 备选方案及放弃原因

| 方案 | 放弃原因 |
|---|---|
| 每家公司各存一份 | 数据完全相同，多拉多存没有意义 |
| 只在 Mapper 上用 `@InterceptorIgnore` | 例外分散在各模块，难以审查；与 outbox 的做法不一致 |
