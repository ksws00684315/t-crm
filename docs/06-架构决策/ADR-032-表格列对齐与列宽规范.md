# ADR-032：表格列对齐与列宽规范

- 状态：已接受
- 日期：2026-10-22
- 关联：规范 10、规范 13（新增）、规范 09；ADR-029；issue #107

## 背景

负责人 2026-10-22 在管理端使用中提出两个问题：**表格对齐没有统一**、**列宽没有随屏幕自适应，小屏有列占得过宽**。

排查后确认这不是个别页面的疏漏，而是规范缺口导致的结构性问题：

1. **对齐**：全站 28 个列表页共用 `admin-ui/src/components/DataTable.vue`，其中对齐逻辑只有一条 `column.amount ? 'right' : undefined`。`amount` 是金额语义（同时挂 `.tcrm-amount` 的等宽数字），无法表达"这是数值列"。结果 17 处右对齐清一色是金额/佣金/运费，"权限数（10 项）"这类数值列与右侧固定的操作列都是左对齐。规范 10 §1.1 只写了"金额列右对齐"，没有覆盖其余列的语义。
2. **列宽**：列宽是写死的 px 下限（`DataTable.vue` 把非操作列一律当 flex 列，`min-width = minWidth ?? width`），容器不足时只横向滚动。实测账号管理在 1440 与 1024 下表格总宽**完全相同**（1448），达人列表 1558；1024 下可见比例仅 51% / 48%。规范 10 §3 只写了"列较多时允许横向滚动"，没有定义"哪一档该保哪些列"，于是滚动成了默认结果。

按本目录 README 的约定，规范先于代码；补规范须走 PR 并在 `docs/06-架构决策/` 记录原因，故立本 ADR。

## 决定

1. **新增规范 13「表格列规范」**，补齐 10 章缺失的三件事：列语义、列宽分配、窄屏保列。

2. **对齐由列语义唯一决定。** 列分 8 类语义（文本左、数值右、金额右、日期时间左、状态居中、布尔居中、序号右、操作右），数值与金额同时使用 `tabular-nums`；表头与内容对齐一致；页面不得直接写 `align`。

3. **新增 `number` 语义，`amount` 收窄为金额专用。** `amount` 继续负责金额格式（千分位、小数位）与右对齐；计数、比例、天数等走 `number`，只右对齐加等宽数字，不做金额格式。

4. **列宽按档位 + 优先级分配，不按分辨率写死。** 档位边界 1600 / 1280 / 1024（与 10 章 1280 / 768 同源）。每列标 P0 / P1 / P2：P0 任何档位可见；P1 在紧凑档按预算保留；P2 在紧凑档及以下默认隐藏，且隐藏可通过列设置恢复，不得删列。

5. **横向滚动不再是默认结果。** 默认档位下必须通过隐藏低优先列避免横滚；1024 档的硬指标是"仅显示 P0 及预算内 P1 时滚动量为 0"，横向滚动只在用户手动打开额外列后出现。页面本身始终不得横向滚动。

6. **ADR-029 维持不变。** 行操作继续全部平铺、定宽、不参与拉伸、不折进「更多」；窄屏空间不足时由其它列让路，而不是折叠操作。

## 备选方案及放弃原因

- **把行操作收进「更多」以腾出宽度**：与 ADR-029 的负责人决定直接冲突（操作全部直接显示）。放弃，且不代为重议——如负责人日后要改，应另立 ADR 替代 029，而不是借本条悄悄放松。
- **维持"允许横向滚动"作为默认行为**：即当前现状，负责人已明确反馈小屏不可接受，放弃。
- **按单个分辨率给页面写死 `width`**：不可维护，且规范 10 §3 已明确"列宽是下限不是定值"，放弃。
- **窄屏统一缩小字号**：违背规范 10 §1 的字号表（表格内容固定 14/22px），且影响可读性，放弃。
- **在 `px(zh, en)` 里再塞一个屏幕参数**：会把语言差异与屏幕差异揉成一个函数，语义混乱；改为档位 + 优先级两套独立机制，放弃。

## 影响

- `DataTable` 需新增 `kind` / `priority` 字段，对齐与默认隐藏改由语义推导；实施见 issue #107。
- 28 张列表页需逐表标注列语义与优先级，并复核 P0 组合在 1024 档的宽度预算（规范 13 §2.3 已给出账号管理、达人列表两张表的核算示例）。
- 规范 10 的相关条款改为指向 13 章：§1.1「金额右对齐」扩展为全语义；§3「列较多时允许横向滚动」收紧为"仅在用户打开额外列后出现"。
- 验收新增 1920 / 1600 / 1024 三档，并要求 `DataTable` 用单测断言"容器宽 → 可见列与列宽"，减少对截图回归的依赖。
- 操作列宽度仍按 ADR-029 的实测值（中文 344、英文 476 等）保留，本 ADR 不改这些数值。
