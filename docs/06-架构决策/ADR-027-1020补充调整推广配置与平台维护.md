# ADR-027：10-20 补充调整推广配置与平台维护

状态：已确认（2026-10-20 客户补充表，项目负责人确认字段解释）

## 背景

客户在 `docs/00-需求/客户补充资料-1015/燎原系统调整1020.xlsx` 中要求：佣金信息不再显示平台专属地址和达人邀请码，备注改选填；平台维护把原“编码”显示为“平台名”，移除独立名称、排序与预览输入，并显示首次维护时间。原 ADR-025 将前两项和备注列为推广配置必填，与新需求冲突。

## 决策

- 推广配置必填项为已审核、佣金比例、至少一个代购平台和推广表格地址。隐藏字段仍保存在数据库；后续保存为空时沿用该达人的已有邀请码和已有平台地址。首次选择平台时，从平台维护的 `template_url` 写入平台地址。备注可空。
- 新增 Flyway 迁移按上述条件重新计算历史达人的存储关系状态；不修改任务 33 已合并的迁移脚本。
- `template_code` 作为界面上的“平台名”，沿用不可编辑及唯一性规则，保持导入脚本按编码识别平台的兼容性。既有 `template_name`、`sort_order` 留在数据库和 API 中；新平台的内部名称默认等于平台名，编辑时保留原值和排序。移除的是界面输入，而非历史数据。
- 平台首次维护时间使用已有 `create_time`，无需数据库迁移。平台列表查询按平台名在当前公司已加载的记录中过滤。
- 自动清理剩余天数沿用定时清理任务的最近归因订单支付时间／最近开始推广时间／回退时间基准，并按天向上取整；接口只返回当前公司且当前账号可见的达人。关闭时仍显示“清理配置”。
- 若模板含 `{INVITE_CODE}` 且达人没有已有邀请码，中转链接按现有规则回退微店商品页；没有占位符的模板仍可正常使用平台地址。
- 界面上不再出现“模板”一词：错误码文案、地址校验提示、停用／启用确认统一称“平台”，避免同一页两套叫法。API 与数据库字段名（`template_code`、`template_url`）保持不变。

## 影响

更新管理端表单与列表、推广配置校验、平台维护时间 API、清理剩余天数只读接口和设计说明书。旧字段、旧记录、导入编码及跳转回退规则继续兼容。
