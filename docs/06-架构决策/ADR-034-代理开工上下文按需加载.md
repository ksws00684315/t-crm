# ADR-034：代理开工上下文按需加载

- 状态：已接受（2026-10-28）
- 决策人：项目负责人
- 补充：ADR-002（统一工程规范与 AGENTS.md）、ADR-028（规范 11、12）
- 依据：[AI 编码代理上下文工程调研报告](../02-调研/AI代理上下文调研/reports/AI%20编码代理上下文工程.md)

## 背景

每个任务都由代理在新的工作树、新的会话中执行。`本机任务通用要求.md` 第 1 节要求「完整阅读 `docs/05-工程规范/`，重点 01～06、08 第 9 节、10、11、12」，任务提示词的「开工前先完整阅读」再叠加设计说明书多个章节、ADR 和前序报告。以任务 76 为例，仅规范正文就约 6.7 万字符。这些内容是代理用工具读进对话的，每个工作树的会话前缀不同，无法复用提示词缓存，每个任务都按全价重读；规范和任务越多，开工成本越高。

调研中有对照的证据：

- ETH/LogicStar（arXiv 2602.11988）：上下文文件对解决率没有显著提升，成本增加约 20%；代码库概览没有让代理更快找到相关文件；文件里写的每条要求代理都会执行。
- Chroma「Context Rot」：同样的信息，聚焦版明显优于完整版；与任务看似相关的干扰文本危害更大。
- IFScale（arXiv 2507.11538）：指令越多，遵循率越低，且偏向靠前的指令。

社区做法趋同为三层：少量稳定规则常驻（`AGENTS.md`），流程性知识按需加载（skill），能机械检查的规则交给工具报错。

## 决定

1. **规范按改动类型读**：`本机任务通用要求.md` 第 1 节改为「完整读 `AGENTS.md` 和提示词必读，规范按改动类型对照表读对应章节」，不再要求通读规范目录。
2. **提示词写法**（规范 12 第 3 节）：「必读」只列与本任务直接相关的章节，每项附一句要点；写明「参照实现」；流程性要求引用 skill，不在提示词中重复。
3. **流程性规范做成仓库 skill**，放在 `.agents/skills/`（Codex 从工作目录向上到仓库根发现；启动时只加载名称和描述，用到时才读全文）：
   - `flyway-migration`：新增迁移（规范 04 第 1～4 节）；
   - `browser-acceptance`：浏览器验收（规范 12 第 5 节、规范 08 第 9.2 节）；
   - `preview-verify`：用独立预览实际启动（规范 12 第 6 节）。
   skill 只写步骤并注明规范出处，条款以规范原文为准；修改对应规范时同步修改 skill。`.agents/` 与 `AGENTS.md` 一样不进入交付包（`.gitattributes`）。
4. **架构测试的失败信息写明原因和改法**：后台与跳转服务的 ArchUnit 规则全部加 `because(...)`，注明规范出处和应当怎么改。代理违规时从报错得到指引，不必为这些条款开工前通读规范 01、02、06。

## 备选方案及放弃原因

- **把规范 `@import` 进 `CLAUDE.md` 或 `AGENTS.md`**：导入不减少上下文占用，每个会话都背上全部规范；Codex 拼接 `AGENTS.md` 有 32 KiB 上限。
- **每个模块放子目录 `AGENTS.md`**：Codex 只加载从仓库根到启动目录路径上的文件，从工作树根启动时子目录文件不会自动加载，未实测前不采用。
- **代码库概览或自动生成的代码地图**：对照研究显示概览不缩短定位步数；命名与分层固定的代码库用 grep 已足够。等有基线数据证明定位成本高时再考虑。
- **向量索引、Serena 等检索工具**：前者需要代码出境或新增中间件，后者主程序为 GPL-3.0，规范 07 未区分开发工具，需另行决策。
- **把交付流程（执行报告、PR）也做成 skill**：每个任务都要用，按需加载没有收益，仍留在 `本机任务通用要求.md` 第 5 节。

## 影响

- 代理开工时默认读入的规范从约十份全文降为若干章节；风险是代理漏读某条未被工具覆盖的规范。缓解：`AGENTS.md` 保留全部关键规则摘要；提示词由架构负责人挑出本任务相关章节；PR 审查仍对照规范全文。
- 新增 `.agents/skills/` 需要随规范维护。Claude Code 读取 `.claude/skills/`（本仓库 `.claude/` 未纳入版本管理），Claude Code 代理按 `本机任务通用要求.md` 中给出的 SKILL.md 路径直接读取。
- 效果尚未量化。后续用 Codex 会话记录统计「首次修改文件前的 token 与工具调用次数」，对已合并任务做新旧提示词的回放对照；没有改善时回退本决定的第 1、2 条。
