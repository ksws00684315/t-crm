# ADR-003 接口响应采用统一信封与错误码

- 状态：已接受（2026-10-04）
- 决策人：项目负责人

## 背景

需要统一的接口成功与错误返回格式。业界较新的标准是 RFC 9457（Problem Details for HTTP APIs），Zalando API 指南要求使用该格式。

## 决定

使用统一信封 `{code, msg, data, errorCode, traceId}`：HTTP 状态码表达错误类别，`errorCode`（`{模块}_{原因}`）表达具体原因，`traceId` 用于排查。

## 备选方案及放弃原因

| 方案 | 放弃原因 |
|---|---|
| RFC 9457 Problem Details | 两个前端模板及国内后台生态普遍按统一信封处理响应；接口只供本系统前端使用，不对外开放 |
| 仅用业务码、HTTP 状态恒为 200 | 掩盖错误类别，不利于网关、监控和缓存正确处理 |

## 影响

- 字段语义与 RFC 9457 对齐（类别、原因、追踪），将来若要对外开放接口，可在网关层转换。
