# ADR-036：管理端独立分页主列表铺满剩余高度

日期：2026-10-29。状态：负责人已确认，待PR审查合并。

## 背景

订单列表已采用卡片铺满剩余高度、分页位于底部、明细内部滚动。其他列表仍按完整行或内容回收高度，负责人要求达人收入、达人提现、达人预付及同类问题一起调整，文字字号和行高不变。

## 决定

将规范13第3.16节的铺满规则用于管理端当前可访问的独立分页主列表；14个此前未启用的列表显式开启现有fill-available-height，订单保持。通知中心将消息滚动区与固定在卡片内的标题、分页分开。只改变空间分配与滚动容器，不改变查询、分页参数、业务操作、权限、接口或数据库，也不修改字体、行高、密度与组件默认行为。

配置小表、plain详情、抽屉弹窗小表、表单、看板及达人端现有移动卡片不套用。短视口保留可读最低明细高度和外层纵滚兜底，不能为贴底遮住最后一行。普通列表最低按首条数据行计算，订单分组保持信息带和首商品两行，避免把订单专用的首组保底错误地变成普通列表必须展示两条长行。完整验收要求见规范13第3.16节。

## 备选方案

继续自然收缩会保留负责人指出的底部空白；全局改DataTable默认值会误影响配置表和详情；写固定视口高度会在筛选展开、摘要换行及小屏时失效，均不采用。

## 影响

补充ADR-035中订单列表的高度规则，并替代规范10、13中对本节覆盖主列表的旧“短列表贴合内容”口径；ADR-035既有文字、对齐及其他视觉决定保留。实现与浏览器证据随本任务PR交付，不把文档确认当作页面已通过验收。
