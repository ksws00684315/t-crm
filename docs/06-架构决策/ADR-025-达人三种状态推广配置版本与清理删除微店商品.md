# ADR-025：达人三种状态、推广配置版本与清理删除微店商品

- 状态：已接受（2026-10-19）
- 决策人：项目负责人
- 相关：[ADR-023](ADR-023-达人编号格式与推广状态由商务维护.md)、设计 §4.2、§5.2、§6.2、§6.3；任务 29 / 30

## 背景

客户 1018 表第 7～15 行要求把达人生命周期拆成审核、登录、关系三种状态；推广配置改为每个代购平台各填专属地址并保留版本；清理时调用微店删除专属商品。ADR-023 中的单一 `promotion_status`、单一 `landing_url`、清理不调微店已不足以表达。

## 决定

1. **达人编号**：保留 `KOL-` + 3 位随机大写字母 + 序号（如 `KOL-ASD001`），**不改**。
2. **三种状态**：
   - 审核状态 `review_status`：`PENDING` / `APPROVED`；审核接口只可调用一次；
   - 关系状态 `relation_status`：`PENDING_PROMOTION` / `PROMOTING` / `INVALID`；显示用另含 `PENDING_UPDATE`（无可用商务且非 INVALID）；
   - 登录状态 `loginStatus`：不存储；由账号启用、激活与登录失败锁定推导。
   - 删除 `promotion_status`；迁移按 ADR-023 四值映射到审核 + 关系状态。
3. **推广配置**：商务为每个代购平台各填一个 https 地址（存 `crm_kol_platform.address`），删除 `crm_kol.landing_url`；每次保存递增 `config_version` 并写入 `version_no` / `effective_time`。
4. **清理**：自动与手动清理在结束对应关系、逻辑删除达人之外，为每条有效专属商品生成清理明细，并调用微店删除；「商品不存在」视为成功；失败记中文原因，不业务重试，提供手动重试。

## 后果

- 取代 ADR-023 中「推广状态四值」「单一落地页」「清理不调微店」三条。
- 前后端契约见任务 29 第 3 节；管理端 / 达人端由任务 30 同步。
- 商务邀请码改为 8 位（去易混淆字符），注册链接 `?code=`。

## 替代关系

本 ADR 部分取代 [ADR-023](ADR-023-达人编号格式与推广状态由商务维护.md) 第 2、3、5 条中与状态、落地页、清理相关的内容；编号格式（第 1 条）与商务达人范围（第 4 条）不变。
