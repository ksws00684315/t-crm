# ADR-026：管理端与达人端统一前端视觉规范

## 背景

管理端与达人端的字体、字号、控件文字和间距随页面增长而分散变化。项目已有《网页字体字号规范.xlsx》，但它注明适用桌面管理端，达人端也需要一套可执行且适合手机的统一标准。达人列表还须在保留 13 列和六个操作入口的同时支持标准字号。

## 决定

两端共用 Excel 定义的字体栈、20／28、16／24、14／22、12／20 四级字体规格与 4px 间距阶梯。手机端保持字号，调整内容区留白和交互目标尺寸。两端应用独立构建，通过 CSS 变量和管理端契约测试维持视觉 token 一致。

达人列表按可读性调整列宽，固定达人 ID 和右侧操作列。表格容器提供横向滚动，保留现有 13 列、六个行操作及其顺序和权限规则；不再保证 1440px 下无滚动显示所有列。

## 备选方案及放弃原因

- 将字体表只用于管理端：会保留达人端现有不一致。
- 将六个操作收进“更多”：改变任务 32 已明确的固定操作入口。
- 通过 11／12px 字体与极窄列宽保持所有列同屏：不符合既有字体表和表头可读要求。

## 影响

历史页面将按统一样式调整；达人列表可在内部横向滚动。新增页面须遵循 `docs/05-工程规范/10-前端视觉与布局规范.md`。不新增运行时依赖或服务间依赖。
