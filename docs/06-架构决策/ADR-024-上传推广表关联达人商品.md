# ADR-024：商务上传推广表，按微店链接关联达人商品

- 状态：已接受（2026-10-18）
- 决策人：项目负责人
- 相关：[ADR-019](ADR-019-兼容客户表格脚本的商品复制接口.md)、[ADR-021](ADR-021-原商品以Google商品源表为主要来源.md)、[1017 确认事项与变更清单](../00-需求/客户补充资料-1017/1017确认事项与变更清单.md) R10～R12、设计 §4.3、§4.4、§5.2

## 背景

2026-10-17 会议确定第一版的做法：商务在谷歌表格中用客户脚本（3.0.5）完成链接替换，替换后的表格上传到系统；系统按表中的微店商品 ID 把商品关联到达人，订单按「微店商品 ID → 达人」归属（R10、R11）。

推广表样例（`测试专用【达人名称A】.xlsx`）的特点：

- 单个文件 241 MB，几乎全是内嵌图片（646 张）；
- 一个工作表，表头在第 2 行（PHOTO / NAME / CW / PRICE / LINK / …）；
- 链接列显示文字为「LINK」，实际地址是单元格超链接，形如代购平台地址包着微店链接：`https://item.kakobuy.com/item/details?url=https%3A%2F%2Fshop{店铺号}.v.weidian.com%2Fitem.html%3FitemID%3D{商品ID}…`；
- 还有分类标题行、「RETURN」导航行、指向 Discord 等的非商品链接，以及重复出现的商品。

已有的对应关系导入（任务 05）要求原商品编码，而上传的表里只有复制后的商品 ID，无法直接使用。

## 决定

1. **上传与解析**（新接口，权限 `kol:edit`，数据范围为「本人」时只能上传给名下达人）：
   - 一次上传一位达人的推广表（`.xlsx`），上限 300 MB；
   - **流式处理**：上传内容写入临时文件，只读取工作表、共享字符串和超链接关系（`xl/worksheets/*.xml`、`xl/sharedStrings.xml`、`xl/worksheets/_rels/*`），跳过 `xl/media`；处理完删除临时文件，**文件不存入数据库**（不走现有导入任务框架，因为它把文件内容存进 `crm_task_file`）；
   - 读取全部工作表的超链接（单元格超链接、`HYPERLINK` 公式、文本中的 http 链接，规则同 ADR-021 第 5 条）。
2. **链接识别**：复用任务 07 的 `SheetLinkParser`：
   - 解开代购平台包装，取微店店铺号和商品 ID；
   - 非微店链接（Discord、淘宝、1688 等）、工作表内部跳转、取不到商品 ID 的链接计入「跳过」并分类报告；
   - 同一商品 ID 多次出现只算一次。
3. **关联规则**：
   - 店铺号必须是本公司已登记的店铺，否则报告「店铺未登记」；
   - 商品 ID 尚未关联任何达人：建立该达人的对应关系；
   - 已关联本达人：跳过（已存在）；
   - 已关联其他达人：报告冲突，**不覆盖**；
   - 本次表中没有、但该达人已有的对应关系：只报告，不自动结束。
4. **对应关系的原商品可以为空**：`crm_kol_item.product_id` 改为可空。上传建立的关系只有复制商品 ID；能按「店铺 + 商品 ID」找到原商品时才填，否则留空。订单归因只需要「复制商品 ID → 达人」，不受影响。
5. **先预览，后确认**：
   - 上传后返回解析结果：将新增、已存在、冲突、跳过（分类与样例行号），不写库；
   - 商务确认后才写入；
   - 确认后写操作日志：达人、文件名、各类数量。
6. **不改达人状态**：上传不改变推广状态（ADR-023），由商务手动改为「推广中」。
7. **达人端「我的商品」**：列出本人有效的对应关系（商品名称、图片、复制商品 ID、链接），替代原推广表中的商品 sheet（R12）。

## 后果

- 第一版不依赖谷歌接口和对外复制接口（17b）即可完成「商品 → 达人」关联；17b 上线后，脚本调用复制接口时由令牌直接关联，上传作为补充手段保留。
- 新增上传预览与确认接口、临时文件处理；Nginx 与 Spring 的上传大小需要放宽到 300 MB（仅该接口），并在部署文档中说明。
- 上传使用不经 Cloudflare 代理的独立子域名 `upload.<域名>`（负责人 2026-10-18 决定，任务 26 审查）：免费计划的代理会拒绝约 100 MB 以上的请求体，300 MB 的推广表必须绕过代理直连源站；该子域名只放行上传接口（含 CORS 预检）。任务 34 起，上传地址通过系统配置 `url.upload` 运行时读取；环境变量只提供默认值，空值表示管理端同源上传。跨域访问仍要求 `TCRM_CORS_ALLOWED_ORIGINS` 包含管理端源。
- `crm_kol_item.product_id` 改为可空，依赖它的查询（对应关系列表、导出、原商品统计）要处理空值。
