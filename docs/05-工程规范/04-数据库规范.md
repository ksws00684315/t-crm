# 04 数据库规范

> 依据《阿里巴巴 Java 开发手册》MySQL 数据库章节，结合本项目（雪花 ID、UTC 时间、Flyway 迁移）调整。

## 1. 建表

【强制】表名、字段名使用小写字母、数字、下划线，不以数字开头；单数名词；不使用 MySQL 保留字。
【强制】表名前缀表示归属：`sys_` 系统、`crm_` 业务、`agg_` 汇总。
【强制】引擎 InnoDB，字符集 `utf8mb4`，排序规则 `utf8mb4_0900_ai_ci`。
【强制】每张表、每个字段都写 `COMMENT`；枚举类字段在注释中列出全部取值及含义。
【强制】必备字段（日志、点击、汇总等只追加的表可省略修改类字段与逻辑删除）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `BIGINT UNSIGNED NOT NULL` | 主键，雪花算法生成（不使用自增，避免 ID 可猜测） |
| `create_by` | `BIGINT UNSIGNED NULL` | 创建人，系统操作为空 |
| `create_time` | `DATETIME(3) NOT NULL` | 创建时间（UTC） |
| `update_by` | `BIGINT UNSIGNED NULL` | 修改人 |
| `update_time` | `DATETIME(3) NOT NULL` | 修改时间（UTC） |
| `is_deleted` | `TINYINT UNSIGNED NOT NULL DEFAULT 0` | 逻辑删除：0 否，1 是 |

【强制】禁止外键约束和级联操作；关联完整性由应用层保证。
【强制】禁止存储过程、触发器、视图中写业务逻辑。
【推荐】使用 `CHECK` 约束限定枚举与状态取值。

## 2. 字段类型

| 数据 | 类型 |
|---|---|
| 金额 | `DECIMAL(14,2)`，禁止 `FLOAT`、`DOUBLE` |
| 比例 | `DECIMAL(6,4)` |
| 时间 | `DATETIME(3)`，存储 UTC；禁止 `TIMESTAMP`（2038 问题） |
| 日期（统计日） | `DATE`，在注释中写明时区 |
| 布尔 | `TINYINT UNSIGNED`，字段名 `is_xxx` |
| 枚举 | `VARCHAR`，存枚举名称 |
| 外部平台 ID | `VARCHAR`（如微店商品 ID），不用数值类型 |
| 结构化扩展信息 | `JSON`，仅用于不参与查询条件的数据 |

【强制】字符串长度按业务上限定义，不随意使用 `VARCHAR(255)` 或 `TEXT`。
【强制】可为空的字段须在设计时说明为空的含义；能给默认值的不允许为空。

## 3. 索引

【强制】唯一索引 `uk_{表名}_{字段}`，普通索引 `idx_{表名}_{字段}`。
【强制】业务上唯一的字段组合必须建唯一索引（不能只靠应用层判断）。
【强制】每个查询条件都要能命中索引；新增查询时在 PR 中附 `EXPLAIN` 结果或说明使用的索引。
【强制】单表索引不超过 6 个；联合索引遵循最左前缀，区分度高的字段放前面。
【推荐】大表（点击日志、订单明细、佣金明细）的列表查询使用"游标分页"（按 `id` 或时间），避免深分页。

## 4. 迁移脚本（Flyway）

【强制】所有结构与基础数据变更只通过 Flyway 迁移脚本完成，禁止手工改库。
【强制】脚本位于 `backend/src/main/resources/db/migration`，命名：`V{yyyyMMddHHmm}__{snake_case_描述}.sql`，例如 `V202610041200__init_system.sql`。使用时间戳是为了避免多个分支同时新增脚本时版本号冲突。
【强制】**已合并到 `main` 的脚本不得修改**；需要调整时新增脚本。
【强制】一个脚本只做一件事（一个功能点的建表或改表）；结构变更与数据修正分开写。
【强制】大表加字段、加索引须评估锁表时间，在 PR 中说明。
【强制】脚本中不得包含密码、令牌等敏感数据，不得包含测试数据。

## 5. SQL 编写

【强制】使用 MyBatis-Plus 的 Lambda 条件构造器（`LambdaQueryWrapper`）或 XML 中的 `#{}` 参数绑定；禁止字符串拼接 SQL，禁止 `${}`（排序字段等确需动态的，必须经过白名单校验）。
【强制】禁止 `SELECT *`，查询只取需要的字段（Mapper 默认方法除外）。
【强制】分页查询必须带排序字段，且排序结果确定（最后加 `id` 兜底）。
【强制】批量写入使用批处理，单批不超过 1,000 行。
【强制】`UPDATE`、`DELETE` 必须带条件，禁止全表更新。
【推荐】统计类复杂查询写在 XML 中，并配集成测试。
