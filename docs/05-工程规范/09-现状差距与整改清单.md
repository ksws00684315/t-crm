# 09 现状差距与整改清单

> 对照时间：2026-10-04，对照对象：`main` 分支 `58086c7` 之后的 `backend/`、`redirect/`。
> 整改由开发任务《02-工程化基线与规范整改》完成。整改完成后本文件保留作为记录。

## 1. 架构与结构（01）

| # | 现状 | 规范要求 | 整改 |
|---|---|---|---|
| A1 | 业务模块位于 `com.tcrm.admin.crm.*` 下 | 每个模块是根包的直接子包 | 移动为 `com.tcrm.admin.{kol,product,link,sheet,order,commission,stats,integration,task}` |
| A2 | 共享包名为 `common` | 共享内核包名 `shared` | 重命名 |
| A3 | `system`、`security` 内 controller、service、mapper、实体平铺在同一个包 | 模块内固定子包 `controller/service/mapper/model` | 按分层拆分子包 |
| A4 | `UserService` 依赖 `UserController.CreateRequest` 等请求对象（service 依赖 controller） | service 不得依赖 controller 包 | 请求对象移到 controller 包的独立文件；service 入参改为 `*Command` |
| A5 | 实体命名 `SysUser`、`OperLog`；返回对象 `UserInfo` | `*DO`、`*VO` 后缀 | 重命名为 `SysUserDO`、`SysOperLogDO`、`UserVO` |
| A6 | 跳转服务所有类平铺在根包 | `controller/service/config` 子包 | 拆分 |
| A7 | 无架构约束测试 | ArchUnit 强制检查分层与模块依赖 | 新增 `ArchitectureTest` |

## 2. 编码（02）

| # | 现状 | 规范要求 | 整改 |
|---|---|---|---|
| C1 | 17 个文件使用通配符导入 | 禁止通配符导入 | 展开；Checkstyle 拦截 |
| C2 | 实体与部分类使用 `public` 实例字段（约 27 处） | 字段 `private` + getter/setter | 改写 |
| C3 | 使用字符串列名的 `QueryWrapper`（4 处） | `LambdaQueryWrapper` | 改写 |
| C4 | `pom.xml` 压缩成单行书写 | 标准多行格式、按组排列 | 重排 |
| C5 | 无格式化与静态检查插件 | Spotless + Checkstyle，CI 校验 | 新增 |
| C6 | 无 `traceId` | 每个请求生成 `traceId`，写入 MDC 与响应头 | 新增过滤器 |

## 3. 接口（03）

| # | 现状 | 规范要求 | 整改 |
|---|---|---|---|
| I1 | 路径为单数：`/system/user`、`/system/oper-log` | 复数 kebab-case | 改为 `/system/users`、`/system/oper-logs`（前端尚未对接，无兼容负担） |
| I2 | 响应信封只有 `code`、`msg`、`data` | 增加 `errorCode`、`traceId` | 扩展 `R` |
| I3 | 错误以零散字符串返回，无错误码表 | `shared.ErrorCode` 统一登记 | 新增枚举，改造全局异常处理与业务异常 |
| I4 | 分页响应 `{rows, total}` | `{items, total, page, size}` | 改造 `PageResult` |
| I5 | 参数校验失败只返回第一个字段 | 返回字段级错误列表 | 改造 |
| I6 | 无 OpenAPI 文档 | springdoc，仅开发与测试环境开放 | 新增（须有支持 Spring Boot 4.1 的稳定版，否则记录并跳过） |

## 4. 数据库（04）

| # | 现状 | 规范要求 | 整改 |
|---|---|---|---|
| D1 | 脚本名 `V1__init_system.sql` | `V{yyyyMMddHHmm}__描述.sql` | 项目未上线、无生产数据，直接改名为 `V202610041200__init_system.sql`（此次为一次性例外，之后已合并脚本不得修改） |
| D2 | 数据库为 MySQL 8.4（驱动为 GPL 许可证） | PostgreSQL 17（ADR-005） | 迁移：驱动、Flyway 模块、迁移脚本、Testcontainers、配置；类型按规范 04 改为 `TIMESTAMPTZ(3)` 等 |
| D3 | 逻辑删除字段 `del_flag`（TINYINT） | `is_deleted BOOLEAN`，Java 字段 `deleted` | 修改 |
| D4 | 表与字段无 `COMMENT` | 全部写注释 | 补充 |
| D5 | `sys_oper_log` 无必备字段说明 | 只追加表可省略修改类字段，须在注释中说明 | 补充注释 |
