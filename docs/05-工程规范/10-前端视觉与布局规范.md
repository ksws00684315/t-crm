# 前端视觉与布局规范

适用范围：`admin-ui` 管理端和 `kol-portal` 达人端的所有页面、公共组件、Element Plus 控件及弹层。本规范以《网页字体字号规范.xlsx》为项目标准，双方样式变量必须保持一致。业务设计有特殊要求时，新增例外须在任务说明中写明原因。

## 1. 字体与文字层级

全站字体栈：

```css
font-family:
  -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Microsoft YaHei", Arial, sans-serif;
```

| 角色                 | 字号／行高 | 字重 | 用途                                                       |
| -------------------- | ---------- | ---- | ---------------------------------------------------------- |
| 品牌名、页面主标题   | 20／28px   | 600  | 每页最多一个主标题；选中状态不改变字号                     |
| 区块、弹窗、抽屉标题 | 16／24px   | 600  | 内容分组与浮层标题                                         |
| 正文及常规控件       | 14／22px   | 400  | 菜单、面包屑、页签、表单标签及值、占位文字、表格内容、分页 |
| 按钮、表头、选中项   | 14／22px   | 600  | 只通过字重、颜色及边框表示强调                             |
| 辅助说明、校验提示   | 12／20px   | 400  | 说明或反馈；不能用于核心业务数据                           |

中文按系统回退到苹方、微软雅黑等无衬线字体。原生控件、Element Plus 组件和挂载在 `body` 下的弹层都继承字体。ID、邮箱、日期和账号与正文同字体同字号；金额可使用 `font-variant-numeric: tabular-nums`，金额列右对齐。不得使用等宽字体表现业务数据。

## 2. 布局、间距与控件

- 间距变量仅使用 4、8、12、16、24、32px；圆角沿用既有颜色与组件主题，不在页面另建尺寸体系。
- 内容区外边距：视口宽度大于等于 1280px 为 24px，768～1279px 为 16px，小于 768px 为 12px。
- 卡片默认内边距 16px，相邻内容区间距 16px，主要区块之间 24px。筛选项横向间距 16px、纵向间距 12px；按钮之间 8px。
- 桌面普通输入和按钮高度 32px。小于 768px 时交互目标至少 44px，字号保持不变。
- 页面使用 `min-width: 0`、可收缩的 flex/grid 轨道及内容区内滚动适应窄视口；避免视口级横向溢出。长邮箱、账号、链接按需省略，并提供完整内容的可访问提示。

## 3. 表格与表单

- 所有状态下，表格文字均保持 14／22px；默认、紧凑、宽松密度只改变单元格纵向内边距，分别为 12、8、16px。列宽优先保证可读表头，不通过缩小字号或任意拆断文字适配宽度。
- 管理端列表继续使用 `ListSearch`、`DataTable` 和 `CopyText`。不在页面手写另一套列表分页；筛选标签置于输入框上方，查询和重置与输入框底部对齐，主要新增操作靠右，空间不足时自然换行。
- 常规列表使用浅色隔行背景与水平分隔线，不使用密集竖向边框。行高由文字行高和密度内边距决定，默认密度约 48～50px；操作文字同排优先，不为压缩行高缩小字号。
- 列表卡片高度贴合内容：行数少时卡片随内容收缩，"共 N 条"与分页紧跟最后一行，不在视口底部留下大块空白；行数多时表格在卡片内部滚动，"共 N 条"与分页始终可见。实现方式是用容器可用高度作为表格 `max-height` 上界，不用固定视口减法。
- 列较多时允许表格容器横向滚动，固定需要持续定位的首列和操作列；页面本身不得因此横向滚动。横向溢出时固定列必须有左侧投影、横向滚动条保持可见（不依赖悬停），否则被裁的列会被误读为渲染错误。业务定义的列序、操作入口、权限和禁用状态保持不变。
- 状态标签使用辅助规格 12／18px，随行高收紧；正文仍为 14px，不用标签字号挤压行高。
- 列宽按渲染后的 14px 文字实测确定：表头优先完整不换行，长邮箱、电话、社媒 ID 等长值省略并悬停显示全文。中文与英文标签长度差异大时，允许按语言给出不同列宽，但同一语言内同类页面保持一致。
- 表单标签使用统一正文规格并保持同一对齐方式；错误、帮助文字使用辅助规格。提交和校验状态不得造成控件文字跳动或裁切。

## 4. 响应式与验收

- 达人端桌面表格在小于等于 767px 时使用已有卡片布局；长值允许换行。管理端列表在表格容器内横滚，搜索项与分页允许换行，工具区不覆盖内容。
- 浏览器缩放 100%，至少验收 1440×900、1280×800、390×844 和 375×812。两种语言均检查导航、页面标题、筛选表单、表格、分页、弹窗、抽屉、空状态和错误提示。
- 列表页另验三条：行数少于半屏时卡片不撑满视口；行数超过一屏时分页仍在视口内；横向溢出时能看到滚动条和固定列投影。
- 逐页抽查登录、首页、主要列表、详情和所有复用浮层；验证有数据、空数据、长内容和校验提示状态。核对计算后的字体、字号、行高、字重、密度与响应式控件高度，无文字裁切、重叠、异常断行或页面横向滚动。
- 两端使用 CSS 变量表达本规范的类型和间距值；`admin-ui` 的视觉契约测试负责比较两端 token，改动任一端时必须同步更新另一端。
