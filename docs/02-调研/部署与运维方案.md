# 海外达人分销 CRM —— 部署与运维方案（美国服务器）

> 编制日期：2026-09-30
> 价格为 2026 年公开信息的调研结果，下单前以各厂商官网实时价格为准。

---

## 一、结论

| 事项 | 建议 |
|---|---|
| 机房位置 | **美国西部**（洛杉矶 / 硅谷 / 俄勒冈），而不是美东 |
| 服务器规格 | 起步 2 核 4G 能跑；**推荐 4 核 8G**，一台机器装下全部服务 |
| 云厂商 | 首选**腾讯云轻量（硅谷）**；UCloud 洛杉矶可用，但轻量套餐最高只到 2 核 4G。详见 §三 |
| 域名 | 在 **Cloudflare** 注册 `.com`，约 US$10.5/年，DNS、SSL、CDN、防护都在同一个平台 |
| 备案 | **不需要 ICP 备案**。服务器在中国大陆以外，不需要工信部备案 |
| 客户每月运行成本 | **约 ¥300～550/月**（服务器 + Google Workspace；域名按年付） |
| 账号归属 | 云服务器、域名、Google Workspace **都用客户名义注册**，客户再授权你管理 |

**为什么选美西而不是美东：**

- 北美用户点跳转链接，美东美西差几十毫秒，基本感觉不到。
- 但有两类访问是从中国发起或连到中国的：国内运营/财务登录后台，服务器调用微店接口。美西到国内的延迟（约 130～180ms）比美东（约 200～250ms）低不少。

## 二、部署架构

```
                       Cloudflare（DNS + SSL + CDN + 防护）
                                   │
   t.xxx.com  ─── 跳转链接（北美用户点击）─┐
   kol.xxx.com ── 达人端（英文）         ├──► 美西云服务器 4C8G（Docker Compose）
   admin.xxx.com ─ 管理后台（国内运营）───┘        ├─ Nginx
                                                  ├─ Spring Boot 应用（含跳转服务）
                                                  ├─ MySQL 8
                                                  └─ Redis
   服务器 ──► Google Sheets/Drive API（美国直连）
   服务器 ──► 微店开放平台 API（跨境访问，第 1 周验证）
   服务器 ──► 邮件服务（注册验证邮件）
   每日备份 ──► 对象存储（异地）
```

- **一台机器够用**：100 位达人、200 万条链接、日均几千单，单机 4 核 8G 有充足余量。点击量暴涨时再拆分跳转服务。
- **MySQL 和 Redis 不暴露公网端口**，只在 Docker 内部网络访问。
- **admin 子域名建议关闭 Cloudflare 代理（只做 DNS 解析，即"灰云"）**。国内访问 Cloudflare 节点有时不稳定，后台直连服务器更可靠；跳转和达人端走 Cloudflare 代理（"橙云"）。

### 选型建议

1. **想要省心 + 便宜：腾讯云轻量硅谷 4 核 8G**（US$36/月）。一个价格包含带宽和 5TB 流量，中文控制台，支持支付宝和微信付款。
2. **继续用 UCloud**：
   - 洛杉矶轻量 **2 核 4G、3TB 流量套餐（¥106/月）** 可以支撑一期，需要控制 JVM 和 MySQL 的内存占用。
   - 后期要扩容就得换成云主机 UHost，涉及迁移。
   - 下单前请在控制台确认：洛杉矶 4 核 8G UHost 的价格，以及轻量主机能不能直接升配。
3. **客户偏好美国本土厂商**：AWS Lightsail 或 Vultr。

> 无论选哪家，下单前都要确认"续费价格和首购价格是否一致"。国内厂商的海外活动价常常只限首年。

## 四、域名注册

### 4.1 注册商对比

| 注册商 | `.com` 价格 | 说明 |
|---|---|---|
| **Cloudflare Registrar**（推荐） | 约 US$10.46/年，续费同价 | 按成本价卖，不加价；DNS、SSL、CDN 一站式；需信用卡或 PayPal |
| Namecheap / Porkbun | 首年常有优惠，续费价一般高于 Cloudflare | 支持 PayPal，界面友好 |
| 阿里云 / 腾讯云（国内站） | 首年便宜 | 按规定要做**域名实名认证**（提交证件）。这不是 ICP 备案，但多一道手续 |

### 4.2 域名选择注意

- **用 `.com`**，不要用 `.xyz`、`.top`、`.site` 这类便宜后缀。这些后缀常被 TikTok、Google 安全浏览、邮件服务商标记为高风险，会导致跳转链接被拦截、验证邮件进垃圾箱。
- **跳转链接的域名要短**。可以另买一个短域名专门做跳转，比如 `xxx.link` 或短 `.com`；主域名做达人端和后台。另买的话每年多约 US$10～20。
- **域名必须登记在客户名下**。域名是所有推广链接的根，将来发生纠纷时，域名在谁手里，200 万条链接就归谁控制。

### 4.3 关于"备案"

| 情况 | 是否需要备案 |
|---|---|
| 服务器在美国（本方案） | **不需要 ICP 备案，也不需要公安备案** |
| 服务器在中国大陆 | 需要 ICP 备案，且需要中国大陆主体 |
| 在国内注册商买域名 | 不需要备案，但需要域名实名认证 |

## 五、其他需要开通的服务

| 服务 | 用途 | 推荐 | 费用 |
|---|---|---|---|
| **Google Workspace** | 持有 100 个达人表格，给系统提供 API 权限 | Business Starter，1 个账号即可 | US$7/用户/月（年付）或 US$8.4（月付） |
| **Google Cloud 项目** | 创建服务账号，开通 Sheets / Drive API | 用 Workspace 同一个组织开通 | 免费（在 API 配额内） |
| **事务邮件** | 达人注册验证、找回密码 | Resend 免费版（3000 封/月，每天 100 封）；量大时用 Amazon SES | 100 位达人的规模免费够用 |
| **对象存储（备份）** | 数据库每日异地备份 | Cloudflare R2 或云厂商自带对象存储 | 免费额度内基本够用 |
| **可用性监控** | 网站宕机告警 | UptimeRobot 免费版，或自建 Uptime Kuma | 免费 |

> Google Workspace 要验证域名归属，所以**先买域名，再开 Workspace**。开通前请确认所选套餐是否包含"共享云端硬盘"（用于存放 100 个表格，避免服务账号没有存储空间的问题）。

## 七、上线操作清单（按顺序执行）

### 第 1 步：账号准备（客户操作，你协助）

- [ ] 客户用公司邮箱注册 Cloudflare 账号 → 购买域名 → 邀请你成为管理员
- [ ] 客户注册云服务器账号并实名/付款 → 通过子账号或 RAM 用户给你授权
- [ ] 客户用新域名开通 Google Workspace → 创建 Google Cloud 项目 → 给你开项目权限
- [ ] 所有账号的主密码和二次验证在客户手里；你只使用子账号

### 第 2 步：服务器初始化

- [ ] 购买美西 4 核 8G，系统选 **Ubuntu 24.04 LTS**
- [ ] 安全组只开放 80、443，以及 22（限定你的 IP）
- [ ] 新建普通用户，改为 SSH 密钥登录，禁用 root 和密码登录
- [ ] 开启 ufw 防火墙和 fail2ban（防 SSH 暴力破解）
- [ ] 设置时区、2～4G swap、自动安装安全更新
- [ ] 安装 Docker 和 Docker Compose

### 第 3 步：域名与 SSL

- [ ] 在 Cloudflare 添加 DNS 记录：
  - `t` → 服务器 IP（开启代理，即"橙云"）
  - `kol` → 服务器 IP（橙云）
  - `admin` → 服务器 IP（只解析，即"灰云"）
- [ ] 橙云子域名：SSL 模式设为 **Full (strict)**，Nginx 安装 Cloudflare 源站证书（有效期 15 年，免续期）
- [ ] 灰云子域名（admin）：用 acme.sh 申请 Let's Encrypt 证书，自动续期
- [ ] Cloudflare 开启"Always Use HTTPS"，并给登录接口配置频率限制规则

### 第 4 步：第三方服务配置

- [ ] Google：开通 Sheets API 和 Drive API → 创建服务账号 → 建共享云端硬盘，把服务账号加为成员 → 服务账号密钥放到服务器的环境变量或密钥文件中（不提交到代码仓库）
- [ ] 邮件：Resend 添加域名 → 在 Cloudflare 添加 SPF、DKIM、DMARC 三条 DNS 记录 → 发测试邮件，确认没进垃圾箱
- [ ] 微店：在服务器上实测调用微店 API 的连通性和延迟（第 1 周技术验证时一起做）

### 第 5 步：部署应用

- [ ] 用 Docker Compose 编排 Nginx、应用、MySQL、Redis；数据目录挂载到宿主机
- [ ] 数据库密码等敏感配置放在 `.env` 文件，不进 Git
- [ ] 部署方式：本地或 GitHub Actions 构建镜像 → 推送 → 服务器执行 `docker compose pull && docker compose up -d`
- [ ] 部署前自动备份一次数据库，以便回滚

### 第 6 步：备份与监控

- [ ] 每天凌晨执行 `mysqldump`，压缩后上传到对象存储。保留最近 7 天的每日备份，外加 4 份每周备份
- [ ] 每周做一次云厂商整机快照
- [ ] **上线前做一次恢复演练**：把备份恢复到一个新库，确认数据完整
- [ ] UptimeRobot 每 5 分钟检测 `t.`、`kol.`、`admin.` 三个地址，异常时发邮件或推送飞书群机器人
- [ ] 应用内对这些异常发告警：订单同步失败、Google 写表失败、磁盘使用率超过 80%
- [ ] Docker 日志开启轮转，防止写满磁盘

### 第 7 步：上线切换

- [ ] 生产环境导入 2 万条商品 → 分批初始化 100 位达人的链接和表格（注意 Google 接口的频率限制，预计需要数小时）
- [ ] 抽查 10 位达人的表格和跳转链接
- [ ] 用测试订单走一遍"点击 → 下单 → 归因 → 佣金"全流程
- [ ] 通知达人新表格地址

## 八、日常运维内容（对应 ¥1,500/月运维服务）

| 频率 | 工作内容 |
|---|---|
| 实时 | 监控告警响应：宕机、同步失败、写表失败 |
| 每周 | 检查备份是否成功，查看磁盘、内存、慢查询；系统安全更新 |
| 每月 | 抽查备份能否恢复；检查 Google 接口配额和微店授权是否将要过期；提交简要运维报告 |
| 按需 | 批量任务（建表、链接生成、订单同步）失败时的排查与重跑；运营人员操作答疑；每月 1 天以内的小调整 |

**建议在运维合同中写明**：故障响应时间（例如工作时间 2 小时内响应）、不在服务范围内的事项（第三方平台故障、客户误操作导致的数据恢复另行计费），避免"包月变无限责任"。

## 九、合规提示

- 跳转服务会记录用户的 IP 地址和设备信息，达人端会收集达人的个人资料。达人端和跳转落地页需要附上**隐私政策**，写明收集哪些数据、用途和保存期限。北美用户主要涉及加州 CCPA，欧洲达人涉及 GDPR。
- 隐私政策文本由客户提供或确认，不在开发范围内。
