# 美国部署：域名注册、备案与 HTTPS 调研

调研日期：2026-09-30（北京时间）。适用项目：海外达人分销 CRM；美国源站，主要服务北美电商业务。以下为官方资料核查和工程建议，尚未购买任何资源。价格为普通、非溢价 `.com` 的美元价格，不包含支付渠道汇兑差价或适用税费；最终以客户账号结账结果为准。

## 一、建议方案

建议优先使用客户现有品牌域名的子域名，例如 `crm.example.com`，无需另购域名。若客户尚无域名，建议 **Porkbun 注册普通 `.com` + 美国云服务器**，初期可用 Porkbun DNS，Cloudflare DNS/代理作为可选项，兼顾低续费成本和后续更换 DNS 的自由。也可直接 Cloudflare Registrar 注册，减少供应商数量，但需要接受必须使用 Cloudflare 名称服务器的限制。[Porkbun 官方价格](https://porkbun.com/products/domains)、[Cloudflare Registrar FAQ](https://developers.cloudflare.com/registrar/faq/)

域名注册商、DNS 服务商、服务器供应商可以分别选择。注册在海外并不决定是否要中国备案；需要依据服务器/CDN 节点位置、运营主体和服务场景分别判断。默认本期使用美国源站，不启用中国内地 CDN；先核实客户的中国运营主体与用户分布，再确定公安联网备案是否适用。

## 三、ICP备案和公安联网备案必须分别判断

### 1. 美国源站，不使用中国内地 CDN

工信部《非经营性互联网信息服务备案管理办法》第二条规定其适用于在中国境内提供非经营性互联网信息服务；云厂商操作规则明确海外服务器无须办理 ICP 备案。本项目采用美国源站、且无中国内地 CDN 时，**按云服务商当前接入规则，通常不需要 ICP 备案**。[工信部办法原文](https://www.miit.gov.cn/zcfg/xxtxl/art/2024/art_7e48434c08c24131b4b7eecfca5b2b6c.html)、[阿里云 ICP 流程说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)

但不能由此直接得出“所有中国备案均不需要”。公安联网备案另有适用主体：《计算机信息网络国际联网安全保护管理办法》第二条限定中国境内的计算机信息网络国际联网安全保护管理，第十二条要求互联单位、接入单位、使用计算机信息网络国际联网的法人和其他组织，自网络正式联通起三十日内向所在地受理机关备案。原文并没有简单写成“全世界任何能从中国访问的网站都必须备案”。[司法部法规库原文，第 2、12 条](https://xzfg.moj.gov.cn/law/download?LawID=1198&type=pdf)

阿里云官方实施指导另明确：海外或香港节点无须 ICP，但中国内地可访问的网站/App 仍须在开通后三十天内办理公安联网备案。该指导适用于其备案业务说明；**不能仅凭这条帮助文档把所有美国主体的网站一概纳入中国公安备案**。[阿里云说明：ICP备案后处理](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)

本项目落地边界：

- 若实际运营主体为中国大陆公司、管理和运营人员主要在中国，先以客户主体信息向所在地公安网安受理机关确认海外 CRM/公开推广入口的备案范围，必要时办理；不在报价中承诺“海外部署一律免公安备案”。
- 若运营主体为美国公司、业务面向北美，不能只因中国偶尔可以访问，就直接要求其办理中国公安备案。主体、使用方式尚未明确，当前应标为待核实，不预先增加办理费用。
- 是否仅限内部登录、是否存在公开推广页面、是否向中国客户提供服务，需要向受理机关完整说明；不能自行把“内部 CRM”视为当然豁免。

上述是基于原文与厂商操作指导的项目判断。政府办理入口为[全国互联网安全管理服务平台](https://www.beian.gov.cn/)。办理地点与材料应按实际主办主体所在地的受理要求确定。

### 2. 后续切换大陆源站或启用大陆 CDN

| 部署变化 | ICP 处理 | 排期影响 |
| --- | --- | --- |
| 迁移到中国内地服务器 | 向实际接入商办理 ICP；已有备案可能需新增接入 | 资料准备、接入商初审、短信核验、主管部门审核，不能只按代码迁移工期承诺 |
| 美国源站 + 仅海外 CDN | 阿里云对应海外加速区域无须 ICP | 公安备案仍依据运营主体等独立核查 |
| 美国源站 + 中国内地 CDN / 含内地的全球加速 | 无论源站在哪，域名需要 ICP | 先核实备案资格和域名要求，再启用大陆节点 |

来源：[阿里云 CDN 加速区域的备案要求](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/use-alibaba-cloud-cdn)、[全球加速与源站无关的备案要求](https://help.aliyun.com/zh/sae/configure-cdn-acceleration-for-application-domain-names)、[ICP 实际接入商流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)。其他 CDN/云供应商应以其官方准入流程核对。

若将来需要大陆 ICP，域名必须满足接入商备案条件，包括后缀、实名认证、注册商资质等；海外注册商中的域名未必直接合格，可能需要转入获批注册商。不要现在为了未知的大陆迁移需求增加复杂度，但应在合同中注明以后大陆化部署另评估。[阿里云域名及主体备案条件](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/for-the-record-process-faq)

## 四、HTTPS 和 DNS 的上线操作

建议使用 Caddy 或 Nginx + ACME 客户端为 `crm.example.com` 签发和自动续期 Let's Encrypt 证书。普通 CRM 不必采购商业 SSL 证书。Let's Encrypt 提供免费 TLS 证书，并通过 ACME 客户端自动化签发。[Let's Encrypt 官方介绍](https://letsencrypt.org/)、[官方入门](https://letsencrypt.org/getting-started/)

若使用 Cloudflare 代理，采用 **Full (strict)**，源站也部署有效证书，确保浏览器到边缘、边缘到源站均加密并校验证书。Cloudflare NS 不等于一定要开 CDN 代理；源站证书与 DNS 也可以独立运行。[Cloudflare Full (strict) 要求](https://developers.cloudflare.com/ssl/origin-configuration/ssl-modes/full-strict/)

具体步骤（此处仅给方案，尚未执行采购或账户配置）：

1. 确定域名由客户真实主体持有；使用客户控制的长期邮箱注册账号，准备可支付美元的方式。
2. 搜索普通 `.com` 可用性，核对注册、续费、ICANN、税费；避免误选 premium。注册后完成联系人邮箱验证，开启自动续费和域名转移锁。
3. 如使用 Cloudflare DNS，先在 Cloudflare 建立区域并导入/核对全部 DNS 记录，再到注册商替换 NS。迁移已有域名时同时核对 MX、TXT、SPF、DKIM、DMARC，避免企业邮件中断。Namecheap 官方提醒更换 NS 不会自动迁移解析记录。[Namecheap NS 说明](https://www.namecheap.com/support/knowledgebase/article.aspx/767/10/how-to-change-dns-for-a-domain/)
4. 创建 CRM 子域的 A/AAAA 或 CNAME，指向美国服务；对本项目最少只需一个 CRM 域名。后台与 API 可以同域反向代理，减少跨域配置。
5. 安装源站 TLS，开启 HTTP 到 HTTPS 跳转；检查第三方 OAuth 回调、Webhook、邮件链接都使用正式 HTTPS 地址。若开 CDN，登录/CRM/API 响应应保持不缓存，公开静态资源可单独评估缓存。
6. 在北美和实际中国运营网络测试域名解析、登录、回调、专属推广链接；第一次上线给 NS/DNS 传播留出窗口。Porkbun 文档提示 NS 全网传播最长可能约 48 小时。[Porkbun NS 传播说明](https://kb.porkbun.com/article/35-how-long-to-change-nameservers)
7. 配置证书自动续期、续期失败与到期监控。Let's Encrypt 自 2025-06-04 停止证书到期通知邮件，不能仅依赖证书机构邮件。[Let's Encrypt 官方公告](https://letsencrypt.org/2025/01/22/ending-expiration-emails/)
8. 保存域名/解析/TLS 清单、采购订单与续费日期，交付客户；依前述主体核查结果办理适用备案。

## 五、账户所有权、MFA 与长期运维交接

**工程建议：客户持有域名、云资源主账号、付款方式和最终恢复权；开发方取得可撤回的管理授权。** 注册联系信息应填客户真实资料，隐私服务只是隐藏公开信息，不能使用虚假主体。Cloudflare 官方要求联系人邮箱验证、保持注册资料真实，未验证可能使域名停止解析。[Cloudflare 注册 FAQ](https://developers.cloudflare.com/registrar/faq/)

- Cloudflare：客户作为 Super Administrator，邀请开发人员独立身份加入并按所需资源授权；所有相关账号启用 MFA，备份恢复码保存在客户密码库。[Cloudflare 成员权限](https://developers.cloudflare.com/fundamentals/manage-members/)、[MFA 与恢复码](https://developers.cloudflare.com/fundamentals/user-profiles/2fa/)
- Porkbun：可邀请开发方为 Authorized User，双方须验证邮箱、电话并启用 MFA；该角色权限较广，但不能解锁域名或发起账号转移。使用客户专用账号，避免一次授权暴露客户其他域名。[Porkbun 授权用户](https://kb.porkbun.com/article/220-how-to-grant-access-to-another-porkbun-user-as-an-authorized-account)、[MFA 与恢复码](https://kb.porkbun.com/article/19-how-to-enable-two-factor-authentication)
- Namecheap：可通过 Share Access 分配域名部分管理权，例如仅 DNS；无需共享客户主账号密码。[Namecheap 域名授权](https://www.namecheap.com/support/knowledgebase/article.aspx/192/46/how-do-i-share-access-to-my-domain-with-other-users/)、[MFA](https://www.namecheap.com/support/knowledgebase/article.aspx/9253/5/how-can-i-enabledisable-twofactor-authentication/)

运维合同应包含 DNS/证书检查、域名续费提醒、授权变更记录；域名注册费客户直接支付或凭票实报实销。若合作终止，移除开发方成员、旋转部署/API 密钥，客户确认续费付款方式及恢复渠道可用。账户恢复码、DNS API 密钥和密码不进入源码仓库或普通交付文档。

## 六、报价与排期可采用的口径

以下是工程估算建议，并非云厂商官方报价：

| 工作 | 预计开发方投入 | 外部等待 | 交付物 |
| --- | --- | --- | --- |
| 域名选择、账号归属、MFA、联系人校验和采购指导 | 0.25～0.5 个工作日 | 客户提供资料、完成支付 | 账号归属与续费清单 |
| DNS、源站 HTTPS、续期与正式回调设置 | 0.5～1 个工作日 | NS/DNS 传播窗口 | 正式可访问域名和 HTTPS |
| 验证与交接 | 0.25～0.5 个工作日 | 需北美/中国实际网络测试配合 | DNS/TLS 运维清单 |
| 如需要公安联网备案 | 单独按资料准备和提交指导核定 | 主管部门审核，不能承诺固定批准时点 | 备案资料、提交凭据、受理结果 |

域名与 HTTPS 共 **1～2 个工作日**，可以纳入主项目上线工作量，避免重复收费。免费证书本身采购成本为零，但自动续期和故障处理属于运维服务。备案政府审核不等于开发方可控制工期；大陆迁移或 CDN 变更应独立变更评估。

## 七、签约/采购前必须澄清

1. 客户实际合同、网站主办、域名注册主体是中国大陆公司、美国公司还是个人？注册地和运营地点在哪？
2. 是否已有品牌域名、注册商/DNS 主账号？能否只增加 CRM 子域名？现有域名是否承担邮件？
3. CRM 是内部登录系统，还是包含面向公众的达人报名、推广与分销页面？中国大陆是否有实际用户、运营者或客户？
4. 是否计划启用大陆 CDN 或以后迁移大陆源站？若只是中国运营人员使用美国后台，可以先实测网络，不直接引入大陆 CDN。
5. 客户是否要求源站、备份、日志和第三方代理处理均留在美国？仅选择美国服务器不能自动保证 CDN、邮件和其他第三方的数据都留在美国。
6. 客户能否提供真实注册资料、可接收验证邮件的长期邮箱、付款方式、MFA 管理人员及备用管理员？
7. 域名/TLS 运维由谁承担，续费谁付款，合作终止时谁接管？运维是否按双方约定服务时段处理故障？
