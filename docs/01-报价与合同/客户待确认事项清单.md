## 专属商品与订单归因（签约前）

已确认：每位达人有自己复制出来的专属商品（商品 ID 各不相同），由运营手动复制。系统按订单商品明细中的商品 ID 判断订单属于哪位达人。以下问题决定这套方式能否顺利落地。

**1. 请提供一笔完整的测试订单，用于验证专属商品 ID 在真实购买链路中是否保留。**

说明：代购平台可能转换商品链接，或采购时改用原商品。系统只对保留专属商品 ID 的订单自动归因；不能保留的订单进入人工匹配池，替代数据来源另行确认。

需提供：用户实际点击的链接、平台采购链接（如经代购平台）、最终微店订单（截图或导出均可）。

**2. 达人专属商品放在哪个微店店铺？是否都是贵方自己的店铺？一共几个店铺？**

说明：系统通过微店开放平台读取订单，只能读取贵方自己店铺的订单。本期支持最多 3 个店铺。

**3. 如何标识一个专属商品属于哪位达人、对应哪个原商品？**

- [ ] 每位达人一个商品分类（以达人编号命名）
- [ ] 商家编码写成“原商品编码-达人编号”
- [ ] 运营从微店后台导出对应关系 Excel
- [ ] 其他（请说明）

说明：系统需要一张“专属商品 ID → 达人 + 原商品”的对应表。只有当微店接口或导出文件确实返回这个标识时，系统才能自动读取；否则需要运营整理对应关系后导入。

**4. 每位达人是否都要复制全部 2 万个商品？复制工具一次能复制多少个？**

说明：100 位达人 × 2 万个商品 = 200 万个微店商品副本。请向微店确认单个店铺的商品数量上限，以及大量相同商品是否会被判定为重复铺货。

**5. 一笔订单包含不同达人的专属商品时，按商品明细分别归属给各位达人、分别计算佣金，是否同意？**

- [ ] 同意
- [ ] 其他规则（请说明）

**6. 表格里的购买链接最终跳转到哪里？**

- [ ] 达人专属商品的微店页面
- [ ] 代购平台的商品页（请注明平台）

说明：如跳转代购平台，系统会把专属商品链接转换成该平台的链接格式。能否按商品 ID 自动归因，以第 1 题测试订单的验证结果为准。

**7. 是否已开通微店开放平台的开发者账号？**

说明：订单接口需要向微店申请开通调用权限，审批时间由微店决定，请在签约当天提交申请。开通前可先用订单 Excel 导入，但数据不会自动实时同步。
